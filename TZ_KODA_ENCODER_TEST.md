# ТЗ: Koda — тест логики encoder.c (tests/encoder_logic_test.c)

## Контекст
Проект C:\ST\boyler\Motor — STM32G474 (CMSIS-only), OEW FOC для асинхронного двигателя.
Драйвер энкодера AS5048A: src/encoder.c (258 строк) — TIM2 PWM Input Capture, скорость из
delta-угла между захватами (~920 Гц), IIR-фильтр >>3, watchdog в ENC_Update().
Уже есть тесты математики: tests/foc_math_test.c (19 проверок) и tests/vf_control_test.c
(16 проверок) — работают hosted (gcc) и на QEMU (semihosting). Моки в tests/mocks/.

## Задача
Создать tests/encoder_logic_test.c — hosted-тест ЛОГИКИ драйвера без железа.
Вызывать TIM2_IRQHandler() напрямую с поддельными значениями регистров и проверять
результат через геттеры ENC_GetSpeed_rpm() / ENC_GetAngle14() / ENC_GetError().

## Что проверить (минимум 12 проверок)

1. **Прямой ход**: последовательность duty растущая (period=1087, pulse от 1000 до 3000
   шаг ~200) → ENC_GetSpeed_rpm() > 0, величина разумная (не 0, не гигантская).
2. **Обратный ход**: duty убывающая → ENC_GetSpeed_rpm() < 0.
3. **Переход через 0° (прямой)**: angle14 идёт 16380 → 5 (wrap: delta = -16375 + 16384 =
   9) → rpm маленький ПОЛОЖИТЕЛЬНЫЙ (не ~221000! это баг unsigned-wrap, которого НЕТ).
   Точная проверка: |rpm| < 1000 при period=1087 (9 counts за период = ~9/16384*60000000/1087 ≈ 30 rpm).
4. **Переход через 0° (обратный)**: angle14 5 → 16380 (delta = 16375 - 16384 = -9) →
   rpm маленький ОТРИЦАТЕЛЬНЫЙ.
5. **Мусорный период**: period=2000 (>1500) → ENC_GetError() == ENC_ERR_BAD_PERIOD,
   ENC_GetSpeed_rpm() == 0 (после фикса arena: скорость обнуляется при BAD_PERIOD!).
6. **Восстановление после BAD_PERIOD**: после мусорного кадра подать валидный →
   скорость снова вычисляется, error == 0.
7. **pulse > period**: pulse=5000 при period=1087 → BAD_PERIOD, rpm==0.
8. **Таймаут**: ENC_Update() вызвать 5+ раз без новых захватов → ENC_GetError() ==
   ENC_ERR_TIMEOUT, ENC_GetSpeed_rpm() == 0.
9. **Восстановление после таймаута**: первый валидный захват после таймаута не даёт
   ложной скорости (first_capture), второй — даёт.
10. **IIR-фильтр**: 10 одинаковых захватов подряд (одна скорость) → rpm стабилен
    (отклонение < 5% от установившегося).
11. **Угол**: ENC_GetAngle14() следует за duty: pulse=8192 при period=16384 → angle≈8192
    (50%). Проверить с точностью ±10.
12. **Стабильность скорости**: при постоянном delta (напр. 100 counts/период) rpm в
    разумном диапазоне: rpm = 100/16384*60000000/1087 ≈ 337 rpm ± 5%.

## Как это сделать (важно!)

- **НЕ вызывать ENC_Init()** (там NVIC, GPIO, RCC — не тестируем периферию).
- TIM2_IRQHandler() — не static, вызывается напрямую.
- Нужен **мок регистров TIM2**: в tests/mocks/stm32g474xx.h (или новый файл)
  объявить структуру-мок TIM2 с полями SR, CCR1, CCR2, CR1 (volatile uint32_t) и
  макросы/указатель TIM2 → на мок. Проверить, как encoder.c обращается к TIM2
  (TIM2->SR, TIM2->CCR1, TIM2->CCR2) — нужно, чтобы эти обращения попадали в мок.
- ВАЖНО про rc_w0: TIM2->SR в encoder.c записывается как `TIM2->SR = ~(маска)`.
  Мок должен моделировать rc_w0: запись 0 в бит = очистка, запись 1 = no-op.
  Проще: перехватить через оператор присваивания НЕЛЬЗЯ в C — поэтому мок-структура
  должна иметь setter-макрос для SR, либо тест после каждого вызова IRQ вручную
  моделирует: читает SR, очищает биты, где записаны 0. РЕКОМЕНДАЦИЯ: сделать
  TIM2->SR макросом-обёрткой (например #define TIM2_SR_VALUE, и в encoder.c заменить
  обращения? НЕТ — НЕ менять encoder.c!). Лучший путь: тест инклюдит encoder.c
  (#include "../src/encoder.c") с -I tests/mocks, а мок stm32g474xx.h определяет
  struct TIM2_TypeDef {...} и static TIM2_TypeDef TIM2_mock; #define TIM2 (&TIM2_mock).
  Для SR rc_w0: определить в моке функцию-обёртку? Проще: в тесте перед вызовом IRQ
  устанавливать TIM2->SR = нужные флаги, а запись ~mask внутри IRQ просто перезапишет
  SR значением ~mask — это НЕ rc_w0! Поэтому: НЕЛЬЗЯ просто смотреть SR после IRQ.
  РЕШЕНИЕ: обернуть поле SR в моке как union { uint32_t raw; } и НЕ проверять SR после
  IRQ напрямую — вместо этого проверять ТОЛЬКО observable-результаты: ENC_GetSpeed_rpm(),
  ENC_GetError(), ENC_GetAngle14(). Флаги SR — деталь реализации, не тестируем.
  НО для последовательности захватов нужно, чтобы IRQ "видел" CC1IF: в encoder.c
  условие `if (sr & TIM_SR_CC1IF)` — если мы ставим TIM2->SR = TIM_SR_CC1IF перед
  вызовом, а IRQ делает TIM2->SR = ~(CC2IF|CC1IF), то следующий вызов должен снова
  поставить CC1IF. Это и есть модель: тест сам управляет SR.
- ENC_Update() вызывать напрямую (она не зависит от регистров — только от
  enc_capture_count).
- Глобальные static-переменные encoder.c (enc_period_us, enc_speed_rpm и т.д.) —
  доступны, т.к. тест инклюдит encoder.c. Читать ТОЛЬКО через геттеры ENC_*.
- SystemCoreClock: объявить в моке (extern uint32_t SystemCoreClock = 170000000).
