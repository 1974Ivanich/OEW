# TZ-REF-01 (DRAFT) — независимый токовый референс для квалификации масштаба

**Статус: DRAFT. Не утверждено, реализации не требует, кампанию не блокирует.**
Назначение: зафиксировать требования к измерительному тракту, который сможет квалифицировать
**масштаб тока** (то, что текущий ACS712-20A на конфигурации стенда сделать не может).

**Почему появился этот документ.** TZ-02 P0/P1 требует независимого референса; на 60 В при штатных
векторах профиля BOAR токи составили **0.13…0.91 А** (шунт-ADC, 8 точек), это 13…91 мВ на выходе
ACS712 при измеренном шумовом поле ~100 мВ pp и межсессионном уходе нуля 120 мВ. SNR ≤ 1, поэтому
60-V кампания проводится как **chain/timing qualification** (`docs/TZ2_P0_P1_BENCH_PROTOCOL.md` §7.1),
а масштаб закрывается отдельным трактом. Исходная предпосылка «на 60 В будет несколько ампер»
**опровергнута измерением** (`docs/STEP_A_ACCEPTANCE.md`).

## 1. Целевые требования (что должно быть достигнуто)

| № | Требование | Значение | Обоснование |
|---|---|---|---|
| R1 | Чувствительность тракта | ≥ 1 В/А | при 0.3 А даёт ≥ 300 мВ — уверенно выше шума |
| R2 | SNR на минимальном токе сессии | **≥ 10** (при напряжении шума ≤ 30 мВ pp) | правило §7 протокола |
| R3 | Минимальный квалифицируемый ток | ≤ 0.3 А | текущий уровень токов стенда |
| R4 | Врезка в фазную цепь | ≤ 0.5 % от сопротивления фазы (Rs ≈ 13 Ом → шунт ≤ 65 мΩ) | не менять электрический режим мотора |
| R5 | Суммарная неопределённость | ≤ 5 % от минимального тока, числом на сессию | иначе квалификация масштаба недостоверна |

## 2. Измерительный элемент (шунт)

* Номинал 10…50 мΩ, допуск ≤ 1 %, TCR ≤ 50 ppm/K, **4-проводное (Kelvin) включение**.
* Мощность: с запасом на импульсные токи до 10 А (например, 0.05 Ом × 100 А² = 5 Вт — брать ≥ 5 Вт).
* Место: в разрыв **фазного провода U и V** между инвертором и мотором (тот же тракт, что сейчас у ACS712).
* Индуктивность шунта — минимальная (безындуктивный тип), иначе выбросы на фронтах ШИМ.

## 3. Усилитель

* Дифференциальный, gain 20…200 (после выбора шунта фиксируется числом), **CMRR ≥ 100 дБ** в DC…10 кГц.
* Синфазный диапазон: для 60 В достаточно INA240-класса (CM −4…80 В); для будущих 200–400 В — **изолированный**
  вариант (AMC1300/AMC3301-класс) либо другое решение с изоляцией. Это два разных варианта тракта — решить отдельно.
* Полоса ≥ 100 кГц (чтобы фронты и «плато» точки выборки ADC были различимы), шум ≤ 100 нВ/√Гц,
  offset ≤ 100 мкВ.
* Питание — чистое, с известным напряжением (записывается в отчёт); при неизолированном варианте
  заземление согласуется с трактом скопа, силовая сторона остаётся развязанной.

## 4. Выход и регистрация

* Выходной фильтр определять явно; полоса должна сохранять соответствие точке выборки ADC
  (аналог правила «FILTER ≤ 1 нФ» для ACS712).
* Скоп: рабочий диапазон 20 мВ/дел и ниже; фиксировать полосу, AC/DC-связь, время/дел, сырой экспорт.
* ЛА: PB6-маркер обязателен (общий знаменатель времени), как в §3 протокола.

## 5. Калибровка и неопределённость

* **DC-калибровка по эталону**: 0.5 / 1 / 2 А постоянного тока через фазный провод при отключённом моторе,
  эталон — DMM (с указанием модели и класса точности); записать чувствительность и нуль.
* **Нуль в условиях сессии**: замер до/после каждого burst при рабочей температуре (обязателен, как в §2 протокола).
* **Uncertainty budget** (числом, на сессию): нуль + масштаб + нелинейность + ошибка CMRR + полоса + температурный дрейф.
* Проверка: сравнение с шунт-ADC трактом прошивки допускается только как **перекрёстная проверка**, не как источник референса.

## 6. Критерии приёмки этого ТЗ (когда оно будет реализовано)

1. SNR ≥ 10 на минимальном токе сессии (измерено, не расчётно).
2. Суммарная неопределённость ≤ 5 % на том же токе, заявлена числом.
3. Неопределённость временной привязки к точке выборки ADC заявлена в мкс.
4. Два канала (U, V) с согласованными коэффициентами; третья фаза — KCL, и это указано явно.
5. Uncertainty budget и сырые файлы калибровки вложены в возврат.

## 7. Что этим ТЗ НЕ разрешается

* поднимать `Vbus` (200–400 В) ради SNR — это меняет электрический режим, safety envelope и fault-модели;
* менять CCR/векторы профиля или вмешиваться в PWM/FOC;
* заменять тракт «по ходу» уже принятой кампании и считать это той же приёмкой;
* использовать этот тракт как доказательство чего-либо, кроме масштаба (цепочка/тайминг уже квалифицируются штатным путём).

## 10. Ссылка на артефакты Phase‑0

Тестовые артефакты Phase‑0 находятся в каталоге `docs/TZ-REF-01-<session-id>/`, где `<session-id>` – уникальный идентификатор текущей сессии (например, `2026-09-24-TAO3104A`). Внутри каталога находятся:

```
phase0_characterisation.json   ← JSON‑манифест, генерируемый `scope_acs712_capture.py --phase0`
```

Содержимое `phase0_characterisation.json` включает:
- `noise_vpp_mv` — измеренный шум в мВ·pp.
- `noise_vrms_mv` — измеренный шум в мВ·RMS.
- `zero_noise_pp_ma` — `noise_vpp_mv / sens_mv_per_a * 1000` (мА·pp, peak-to-peak).
- `zero_noise_rms_ma` — `noise_vrms_mv / sens_mv_per_a * 1000` (мА·RMS).
- `zero_drift_in_session_ma` — при необходимости измеряется отдельным скриптом (пока не реализован).
- `vcc_acs712_mv` — напряжение питания датчика, задаётся пользователем через `--vcc-mv`.
- полные метаданные канала (scale, probe, offset, sample_rate, window).

Пример расчёта SNR из `phase0_characterisation.json`:
```
I_min_App = 0.3 A * 2 = 0.6 App  (peak-to-peak, мотор работает)
zero_noise_pp_ma = noise_vpp_mv / 100 * 1000
SNR_pp = I_min_App / (zero_noise_pp_ma / 1000)
```
Если `noise_vpp_mv = 40` и `I_min = 0.3 A` (синус): `SNR_pp = 0.6 / 0.040 = 15` → `>= 10`, PASS.

Эти файлы **обязательно** включать в `manifest.json` любой сессии, где используется Phase‑0, чтобы оператор мог прочитать `noise_vpp_mv` и рассчитать `zero_noise_pp_ma` (см. гейт `SNR`).

| Gate | PASS‑условие | При невыполнении |
|------|--------------|-------------------|
| Reference independence | reference не зависит от PA0/PA1 reconstruction | `BLOCKED` для scale |
| Zero measurement | raw zero capture и drift внутри session сохранены (получено из Phase‑0) | `NOT QUALIFIED` |
| SNR | **Метрика должна быть согласована.**<br>Если signal — peak-to-peak: `SNR_pp = I_min_App / zero_noise_pp_ma`.<br>Если signal — RMS: `SNR_rms = I_min Arms / zero_noise_rms_ma`.<br>Гейт: `SNR_pp >= 3` (предпочтительно `>= 10`).<br>`zero_noise_pp_ma` = `noise_vpp_mv / sens_mv_per_a * 1000` (мА·pp).<br>Для ACS712: `noise_vpp_mv / 100 * 1000`. | только `chain/timing` (в verdict: `CHAIN_TIMING_PASS_SCALE_NOT_DEMONSTRATED`) |
| Sensitivity | slope измерен по independent current с uncertainty | `NOT QUALIFIED` |
| Polarity/mapping | U/V подтверждены физически и raw waveform | `BLOCKED` |
| Timing | trigger/sample alignment и uncertainty сохранены | `BLOCKED` |
| Repeatability | повторные точки согласуются | `NOT QUALIFIED` |
| Provenance | все raw/config/hash‑артефакты присутствуют | `BLOCKED` |
| Safety | все pre‑energise gates PASS | `FAIL` |

Для `Zero measurement` используется файл `phase0_characterisation.json`, находящийся в каталоге `docs/TZ-REF-01-<session-id>/` (см. ниже).

* доступность компонентов в РФ и ценовой режим;
* изолированный или неизолированный вариант (зависит от будущего максимума `Vbus`);
* нужен ли третий канал (измерять фазу W физически вместо KCL);
* требуемая полоса: минимум для масштаба против достаточной для формы.
