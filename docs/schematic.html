Примечания:
1. SD-защита (прямая, упрощено e600d53): MCU — только слушатель (AF-вход без подтяжки, никогда не драйвит SD). SD=0 → аппаратный BKIN → MOE=0 (даже при зависшем CPU). Единственный ПО-латч — центральный PROTECT fault; сброс только явным f при SD high. Приёмка — OEW_SD_CHECKLIST.md (T1–T4, no-HV).
2. DC-link: общий для двух инверторов, на время T1–T4 физически отсоединён, HV не подаётся.
3. aux 3.3V: сейчас приходит с шины Nucleo (J2-25/28) — для T4' (снятие aux при живом MCU) нужна развязка: отдельный источник + ключ.
4. Токовые каналы (подтверждено пользователем): I1 (PA0) — ОУ шунта DC-link инвертора №1 (сигнал дублирован на J2 pin 15/17/19), I2 (PA1) — шунт инвертора №2, Ires (PA6) — трансформаторный датчик CT, через который продеты 3 провода фаз A/B/C от инвертора №1 (нулевой ток iz OEW). Канал-правило: для статических тестов — шунт НЕ модулирующего инвертора (см. skill stm32-motor-foc-debugging).
5. ЛА: D0–D11 = 12 PWM в порядке PWMTab.CHANNELS, D13 = PB6 sync; практический лимит 8 МГц, буфер ≈0.16 с.
