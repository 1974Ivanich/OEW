Примечания:
1. SD-защита (прямая, e600d53): MCU — только слушатель (AF-вход без подтяжки, никогда не драйвит SD). SD=0 → аппаратный BKIN → MOE=0 (даже при зависшем CPU). ПО-латч — центральный PROTECT fault; сброс только явным f при SD high. Приёмка — OEW_SD_CHECKLIST.md (T1–T4, no-HV).
2. DC-link: общий для двух инверторов; на время no-HV-тестов физически отсоединён.
3. aux 3.3V (развязка внесена): J2-25/28 обоих модулей — от отдельного источника (GND общий с Nucleo), НЕ от шины Nucleo. Ключ S1 — снятие aux при живом MCU (T4').
4. Токовые каналы (подтверждено пользователем): I1 (PA0) — ОУ шунта DC-link Inv1 (дублирован на J2 pin 15/17/19), I2 (PA1) — шунт Inv2, Ires (PA6) — CT, через который продеты 3 провода фаз A/B/C от Inv1 (нулевой ток iz OEW). Канал-правило: для статических тестов — шунт НЕ модулирующего инвертора.
5. Фикстура T2/T3: PA4/PA5 → затвор BSS138/2N7002 (сток → SD, исток → GND, затвор → 100k → GND). GPIO high имитирует внешний fault; не нарушает правило «MCU — слушатель».
6. ЛА: D0–D11 = 12 PWM (PWMTab.CHANNELS), D13 = PB6 sync; лимит 8 МГц, буфер ≈0.16 с.
