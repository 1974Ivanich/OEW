# BM1109: измерение R и L обмоток от инверторов STM32G474

Статус: начальная изолированная реализация математического ядра.
Ветка: `feature/bm1109-rl-measurement`.

## Назначение

Получить измеренные параметры BM1109 при возбуждении обмоток штатными
инверторами STM32G474. Существующий OEW autotune не подключается напрямую:
он содержит допущения о топологии OEW, каналах DC-link и асинхронной машине.

## Измеряемые величины

Для доступных выводов двигателя первично сохраняются эквивалентные
межвыводные величины:

- (R_{UV}, R_{VW}, R_{WU}) — сопротивление между соответствующими
  выводами при постоянном токе;
- (L_{UV}, L_{VW}, L_{WU}) — эквивалентная индуктивность при заданных
  положении ротора и тестовом токе.

В звезде при симметричных фазах можно дополнительно привести
(R_{phase}=R_{LL}/2). Для индуктивности деление на два без модели
взаимной индукции и положения ротора НЕ допускается: основной результат —
измеренная (L_{LL}).

## Архитектура

1. **Силовой/безопасный слой**: отдельная последовательность запуска
   диагностического режима, проверка interlock/fault, ограничение тока,
   аппаратный stop и гарантированное отключение PWM при любом выходе.
2. **Слой захвата**: синхронно записывает временные метки, фактическое
   дифференциальное напряжение на проверяемой паре и ток этой пары.
3. **Математическое ядро**: `src/bm1109_rl_math.c`, не обращается к
   регистрам STM32, PWM, ADC или UART.
4. **Регистратор**: сохраняет сырые отсчёты и сводку, чтобы расчёт можно
   было повторить offline.

## Расчёт

### Сопротивление

Для точек установившегося режима выполняется линейная регрессия

`V = R I + Voffset`.

Свободный offset нужен, чтобы не приписывать падения на ключах,
dead-time и измерительный ноль сопротивлению обмотки. Входные величины
должны быть фактическими напряжением на выводах проверяемой пары и током
через неё. Результат регрессии — эквивалентное сопротивление этой пары.

### Индуктивность

Для измеренного фронта тока:

`L = integral((V - R I) dt) / delta_I`.

Интегрирование выполняется трапециями по временным меткам. Входной массив
должен содержать signed winding voltage и signed winding current с
одинаковой ориентацией знака.

## Важное ограничение измерительного тракта

На текущей OEW-плате штатные I1/I2 — датчики тока DC-шины, а не
непосредственные фазные датчики. Нельзя подавать их значения в
`BM1109_RsFit` или `BM1109_LsFromStep` как winding current без
подтверждённой реконструкции тока для конкретной коммутации и момента
выборки. Аналогично команда duty*Vbus не является точным напряжением
обмотки: необходима реконструкция фактического дифференциального
напряжения двух мостов с учётом полярности TIM8, dead-time и падений.

Перед включением силового слоя необходимо зафиксировать:
- фактическую схему соединения BM1109 (звезда/доступные концы);
- точную схему подключения двигателя к двум инверторам;
- какой датчик измеряет ток в каждом состоянии ШИМ и какова его
  калибровка/полярность;
- измеряемое напряжение: отдельный дифференциальный ADC канал или
  расчёт по верифицированным состояниям ключей;
- частоту PWM, точку выборки, временную точность и пределы ток/энергия.

## Безопасность и границы текущей версии

Этот коммит **не включает PWM и не возбуждает двигатель**. Он добавляет
только чистые функции расчёта. Нельзя запускать импульсы на BM1109, пока
не проверены физическая цепь аварийного отключения, аппаратные пределы
тока, реальная полярность датчиков и восстановление PWM в cleanup.

Для PM-мотора импульс может создать заметный момент и повернуть ротор.
Ротор должен быть механически безопасен, тестовый ток и длительность
импульса — минимальными и ограниченными независимой защитой.

## Контракт математического API

- `BM1109_RsFit`: не менее трёх точек с ненулевым разбросом тока.
  Возвращает R в mOhm и fitted voltage offset в mV.
- `BM1109_LsFromStep`: не менее двух точек с возрастающими timestamp,
  интегрирует (V-RI), возвращает L в uH.
- Все массивы содержат уже откалиброванные физические величины.
- Сырые данные должны сохраняться отдельно; результат без сырых данных
  не считается воспроизводимым измерением.
