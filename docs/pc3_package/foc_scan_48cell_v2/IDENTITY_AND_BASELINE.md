## Декод CMS/MMS/URS/RCR

| регистр | биты | значение | вывод |
|---|---|---|---|
| TIM1->CR1 | 6:5 | | CMS = |
| TIM1->CR2 | 6:4 | | MMS = (ожидается 010) |
| TIM1->CR1 | 8 | | URS = |
| TIM1->RCR | — | «не печатается» | RCR = 1 (якорь: исходник образа, `src/pwm.c:273`) |

`RCR` из `dump` получить нельзя: `PWM_DumpRegs` (`src/pwm.c:629`) читает только
PSC/ARR/BDTR/CR1/CR2/CCER. Для образа `ab1274d` RCR = 1 — фиксируется как факт исходника.
