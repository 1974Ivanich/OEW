# Шаблон возврата (заполнять как есть, без пересказа)

## 1. Идентичность и сборка
- образ/дата/чем прошит:
- `sysinfo`, `a?`, `pdump` (`@PWM:FULL`: `SYS`, `T1:PSC`, `ARR`, `CR1` — группы T1/T8), `p?` (десятичные `CR1`/`CCER`/`BDTR`/`CNT`):
- `TOOLS/check_step0.py`: вердикт шага 0 (`step0/result.json`, `verdict` = ____; в `not_measured` — RCR):
- ответ на `1` (дословно, в первой ячейке):
- `rc` ответа на `1` и его смысл (`0` — старт; `-2` нет карты; `-5` не energize-сборка;
  `-6` параметры `Rs/Ls` вне окна — дефекты B16/B17):
- параметры FOC (`mp=` + `mpapply`; без них старт даёт `rc=-6` `params_out_of_range`):
- карта секторов (`@FOC:map_id` / `map_crc32`; без неё старт даёт `rc=-2` `map_unverified`):
- если был аппаратный break (`FAULT_R=18`): `@BRK` дословно, и чем/в каком порядке снимался
  латч (`c` → `f`, вне рамок пакета), `FAULT`/`FAULT_R` после:
- инвертор/шина, прибор VBUS, лимит источника, оператор, время:
