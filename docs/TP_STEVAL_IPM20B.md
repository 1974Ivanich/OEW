# Тестовые точки STEVAL-IPM20B (UM2705): что и чем измерять

> Источник: `Steval-IPM20.pdf` в корне репозитория — **UM2705 Rev 1**.
> Таблица точек — Table 8 «Test pins», стр. 22; схема усилителей — лист 4/5, стр. 7
> (расположение элементов и связка «TP ↔ ОУ» сверены по координатам текста PDF).
> Документ аппаратный: описывает плату, а не текущую сборку/калибровку прошивки.
> Номера TP **повторяются на каждой плате** STEVAL-IPM20B — см. §4.

## 1. Точки сигналов тока (выходы ОУ)

| TP | Net | ОУ (лист 4/5) | Обвязка |
|----|-----|---------------|---------|
| **TP24** | `Current_A_amp` | U1A (TSV994) | в серии R31 = 1k0; ОС/смещение R29 = 2k1; вход R30 = 1k0 |
| **TP25** | `Current_B_amp` | U1C (TSV994) | в серии R36 = 1k0; C29 = 330p; ОС/смещение R34/R39 = 2k1; входы R35/R37 = 1k0; C27 = 100p |
| **TP26** | `Current_C_amp` | U1B (TSV994) | в серии R41 = 1k0; ОС/смещение R43 = 2k1; вход R37 = 1k0 |

Сеть каждого канала одна и та же по номиналам: входы 1k0, ОС 2k1 ⇒ **усиление 2.1**.
При шунте 0.03 Ом это **63 мВ/А** — совпадает с прошивной константой
`ADC_DC_SHUNT_UV_PER_A = 63000` (`src/adc.h:14`).

R36 = 1k0 + C29 = 330p дают полюс ≈482 кГц: на DC и на 5 кГц ШИМ это не влияет,
зонд 10 МОм делителя не образует. Позиционные обозначения различаются по каналу —
сверять по схеме листа 4/5.

## 2. Земля для щупа

Документированные земли (Table 8, «Ground»): **TP11, TP21, TP22**.

Землю щупа подключать только к ним либо к подтверждённой аналоговой земле платы.
Осциллограф с заземлённым корпусом соединяет землю щупа с PE — это надо учитывать,
когда цепь гальванически не связана с защитным заземлением.

## 3. Точки, которые нельзя использовать для измерения аналогового тока

| TP | Table 8 (дословно) | Замечание |
|----|--------------------|-----------|
| **TP23** | SD (shutdown pin) | выход ошибки драйвера, активный низкий: прикосновение/нагрузка → ложный break, MOE = 0 |
| **TP20** | TSO (TSO pin) | выход датчика температуры IPM, не ток |
| TP16 / TP18 / TP19 | Negative DC input for U/V/W phase | силовые узлы DC-звена |
| TP9 / TP10 / TP13 | phase A (U pin) / phase B (V pin) / phase C (W pin) | силовые фазы |
| TP2 / TP3 / TP4 | VBOOTw / VBOOTv / VBOOTu | буутстрапные питания |
| TP5 / TP6 / TP7 | HinU / HinV / HinW | входы управления верхними ключами |
| TP12 / TP14 / TP15 | LinU / LinV / LinW | входы управления нижними ключами |
| TP8 | VCCH | питание драйвера верхней стороны |
| TP17 | CIN | вход усилителя тока |
| TP1 | NTC (T2 pin) | термистор |

Полный список — Table 8, стр. 22 UM2705.

## 4. К какой плате и к какому каналу относится точка

- Номера TP24/TP25/TP26 есть **на обеих** платах. Прежде чем мерить, определить, к какой
  плате подключён измеряемый канал.
- В OEW жгут берёт выход **инвертора №1** (J2 pin 15, «Current phase A») на PA0 = **I1**, а
  выход **инвертора №2** (J2 pin 17, «Current phase B») на PA1 = **I2**
  (`pinout.md:28-29`, `PROJECT_OVERVIEW.md:87-88`). То есть **TP24 → I1 (PA0)**,
  **TP25 → I2 (PA1)** — при условии, что используется именно этот пин этой платы.
- PA6 (Ires) к выходу ОУ не подключён: в OEW это трансформаторный датчик (CT), а измеренный
  `offset_ires = 0` и однополярный вход подтверждают отсутствие bias 1.65 В
  (`pinout.md:30`, `docs/BENCH_SESSION_20260823.md:41`). Поэтому TP26 к прошивному `Ires`
  отношения не имеет.
- ⚠️ Утверждение «в one-shunt конфигурации сигнал дублируется на J2 15/17/19, значит TP24 и
  TP25 одной платы — один и тот же сигнал» **нельзя принимать по тексту**. Режим задают
  перемычки SW5/SW6 (замкнуты) и SW7/SW8 (разомкнуты), но фактическое соединение входов трёх
  ОУ с одним шунтом подтверждается прозвонкой конкретной платы и её схемой. До этого TP24 и
  TP25 считать независимыми каналами.

## 5. Ожидаемые значения при нулевом токе

| Канал | Нуль по прошивке | ≈ на TP |
|-------|------------------|---------|
| I1 (PA0, Inv1) | `offset_i1` = 2039 отсч (стабильно во всех 5 прогонах baseline) | 1.643 В |
| I2 (PA1, Inv2) | `offset_i2` = 2067.0…2068.0 отсч | 1.666 В |

Источник: `docs/MOPT0_BASELINE_20260918.md` (принятый baseline). Перевод: 1 отсч =
3300 мВ / 4095 = **0.806 мВ** (≈**12.79 мА** по шкале 63 мВ/А).

Разница нулей каналов ≈23 мВ — разброс bias-обвязки двух плат; снимается калибровкой `c`,
к масштабу (усилению) отношения не имеет и **причиной** расхождения отношения `|I1|/|I2|`
быть не может.

### Что мерить на TP25 и что это докажет

- При нулевом токе: постоянный уровень (ожидаемо ≈1.65 В), шум peak-to-peak, исправность
  выхода. **Масштаб этим не проверяется** — нужен известный ток.
- Под инжекцией (изолированный источник тока, ограничение напряжения ≤1 В, кельвиновы точки
  шунта) снимать одновременно три независимых числа: ток источника, напряжение на TP,
  ответ прошивки (`ci 1` / `ci 2`).
  - TP даёт 63 мВ/А, а прошивка — нет ⇒ дефект **ниже** ОУ (ADC-канал, offset/sign,
    константа/модель).
  - TP сам уходит от 63 мВ/А ⇒ дефект **аналога** (номинал шунта, усиление, обвязка платы).

## 6. Сопоставление с CLI прошивки (сверено по коду, не по описанию)

| Команда | Что делает |
|---------|-----------|
| `a` | печатает **сырые** отсчёты: `@ADC:I1=..:I2=..:Ires=..:VBUS=<raw>` (`src/cli.c:48-51`) |
| `a?` | только `offset_i1` и период стрима; `offset_i2` и `offset_vbus` не печатает (`src/cli.c:58-61`) |
| `c` | калибровка офсетов токов; требует остановленных инверторов (`src/cli.c:62-74`) |
| `cv` | калибровка смещения VBUS: `@ADC:CV:OK:offset_vbus=N`; отказ `rc=-2`, если max raw > `ADC_VBUS_OFFSET_MAX_RAW=40` отсч (≈4.03 В при 100.73 мВ/отсч) (`src/cli.c:75-88`) |
| `ci 1` | окно сбора по каналу 1 = **Inv1** (PA0): `@CI:PT{n}:...raw_i1_avg/min/max...:vbus_mv=..` (`src/cli.c:89-123`, `docs/TZ_CURRENT_SHUNT_CALIBRATION.md:54`) |
| `ci 2` | окно по каналу 2 = **Inv2** (PA1): то же по `raw_i2` (там же:56) |
| `ci 0` | два окна подряд (Inv1 и Inv2) в одном ответе `@CI:ZERO` (`src/cli.c:100-111`) |

Ограничения `ci`: только при выключенном PWM (`err: PWM running - zero/PWM-off only`);
каналы 0 и 1 берутся с **разных ADC-модулей** и не смешиваются (`src/cli.c:101`).
`ci` коэффициенты **не подгоняет** — только собирает окна; offset/sign/gain считаются
offline (`tools/ci_fit.py`) и подставляются отдельным ТЗ.

## 7. Порядок измерения (no-HV)

1. Силовой БП выключен, DC-link разряжен. Подтверждение по `a` — **в сырых отсчётах**:
   5000 мВ = 49.6 отсч при шкале 100.73 мВ/отсч (у `a` поля в отсчётах, не в мВ).
2. `p?` — MOE = 0, CCER = 0; `f`-состояние: FAULT = 0; SD1/SD2 high.
3. При выключенном силовом подключить пробник: сигнал — на TP25 (или TP24 для канала I1),
   землю — на TP11/TP21/TP22.
4. Включить только низковольтное питание (3.3 В на ОУ; без него выход висит) при выключенных
   DC-link и питании гейт-драйверов; проверить `sysinfo` — состояние безопасно.
5. Записать: DC-уровень, шум pp, осциллограмму; сверить с `a`/`a?`/`c` и, при необходимости,
   `ci 2` (и `ci 1` для второго канала).
6. Результат оформить свидетельством (осциллограмма/CSV + отчёт + sha образа), а не текстом
   в переписке — AGENTS.md («Проверка на плате»). Перед опытом — `make backup`.
