# BM1109 OEW — Measurement Run Card (проект V0.1, НЕ УТВЕРЖДЕНО)

Статус: ПРОЕКТ на согласование. Подготовлен по разрешению владельца
2026-11-26. НЕ является разрешением на выполнение измерений — каждый блок
запускается отдельным go-ahead. Frozen неизменны: h=0.5°, 33×12, стенсилы,
gates, критерий 1%, V0.4, ToR noise study.

## §0 Принцип

Лестница измерений от дешёвого и безопасного к дорогому и опасному.
Каждый блок имеет входные условия, процедуру, формат данных и критерий
перехода. Никакого HV и никакого вращения выше 3500 rpm до закрытия
механического gate. Запуск на 10 000 rpm в этом документе отсутствует
как класс.

## §1 Блок A — идентификация обмоток (no-HV, без вращения)

Вход: статор/двигатель на столе, мультиметр, маркировка.
Порядок с обязательным STOP (аудит владельца 2026-11-26):
- **A0 — документация исходного состояния (STOP перед любым размыканием)**:
  фото всей исходной звезды и каждого соединения, маркировка всех
  внешних выводов, исходные R_UV/R_VW/R_WU, температура обмотки,
  измерительный ток/метод омметра, сопротивление каждого доступного
  участка. Без завершённого A0 физическое размыкание запрещено.
- **A1** — прозвонка всех выводов; карта связности 9 катушек.
- **A2** — определение фазных групп (3 катушки/фаза — гипотеза,
  проверяется).
- **A3** — размыкание заводской звезды, вывод шести концов
  U+/U−, V+/V−, W+/W− (только после A0/A1).
- **A4** — R_phase каждой фазы, симметрия, контрольная проверка.
Оговорка аудита: R_LL = 2·R_phase — проверка СИММЕТРИЧНОЙ трёхфазной
звезды, не универсальная проверка топологии OEW; если вскрытие покажет
нестандартное последовательное/параллельное соединение катушек, формула
заменяется фактической схемой.
Выходные данные: таблица сопротивлений, схема соединений, фото/протокол.
Gate: R_A ≈ R_B ≈ R_C в пределах ±2% от среднего (фиксировано до
измерения); метрика (max−min)/mean хранится отдельно, не только PASS/FAIL.
Температурная поправка обязательна: R(T) ≈ R(T0)·(1+α(T−T0)) — часть
«асимметрии» может быть температурным эффектом. Несимметрия → стоп,
разбор причины, никакой «подгонки».

## §2 Блок B — индуктивности фаз (no-HV, без вращения или ручной поворот)

LCR-метр/метод Шеринг-моста либо step-response: L(θ) каждой фазы при
нескольких положениях ротора (ручной поворот, фиксированные углы).
Обязательная запись амплитуды тестового сигнала и частоты измерения —
L без этих двух параметров невоспроизводима. Цепочка вывода строго:
L(θ) → привязка электрического угла ротора → Ld/Lq → сравнение с ROM;
максимум/минимум измеренной индуктивности НЕ превращается в Ld/Lq
автоматически, пока не определена угловая привязка и малосигнальный
режим. Выход: L(θ) таблицы → оценка Ld/Lq анизотропии, сравнение с
допущениями синтетики. Протокол повторяемости: ≥3 независимых измерения
на точку, выборочная дисперсия с Бесселем.

## §2а Isolation pre-gate (обязателен до B/C, аудит владельца)

Перед любым подключением измерительного оборудования к разделённым
выводам проверить и задокументировать:
- отсутствие соединения каждой фазной обмотки с корпусом;
- сопротивление изоляции каждой фазы относительно корпуса;
- отсутствие межфазного КЗ;
- состояние выводов после размыкания звезды;
- отсутствие случайного соединения между двумя предполагаемыми
  OEW-концами;
- состояние эмали/изоляции в местах вывода новых концов.
После размыкания заводской звезды объект уже изменён — целостность
изменения имеет собственный gate.

## §3 Блок C — back-EMF / flux linkage (низкая скорость, no-HV на обмотках)

Вращение ротора внешним приводом на низкой, контролируемой,
документированной скорости (≪3500 rpm). Метрология скорости: стенд с
известной скоростью предпочтителен; дрель — только как резерв с
независимым тахометром, поскольку Ke = E/ω требует хорошо известной ω.
Осциллограф на разомкнутых фазах: форма и амплитуда back-EMF на каждой
паре (U+−U−, V+−V−, W+−W−).

Определение Ke фиксируется до измерения (аудит владельца): Ke — через
fundamental RMS фазной ЭДС пар обмоток, Ke = E_1st,rms/ω; одновременно
публикуются E_LL,rms, E_1st,harmonic, RPM, f_e и полный waveform (не
только рассчитанный Ke). Связь с frozen-контрактом: psi_reference_absolute
определяется по потокосцеплению фазы; фазное psi_f выводится из
fundamental ЭДС пар U+−U− и т.д. как psi = E_1st/(ω·√2) при синусоидальной
основной гармонике — с явной записью применённой конвенции; peak/RMS/
line-to-line смешивать запрещено.
Gate: симметрия back-EMF по фазам; гармонический состав задокументирован,
не «подогнан» под синус.

## §4 Блок D — механический gate (до любого HV и высоких оборотов)

1. Осмотр крепления магнитов (клей/бандаж), состояние ротора.
2. Подшипники: люфт, шум, температура при ручном вращении.
3. Вал: биение (индикатор часового типа если доступен).
4. Поиск/запрос заводского ограничения оборотов — документ или честное
   отсутствие документа (записывается как отсутствие).
   «Не нашли ограничение» ≠ «допустимо»: 10 000 rpm — отдельная
   qualification problem (магнитное удержание, бандаж, балансировка,
   критические скорости, вал, подшипники, зазор, крепление, напряжения,
   температура), не «следующий эксперимент»; блок D её не открывает.
Gate: без подтверждённой механической допустимости обороты выше 3500
запрещены категорически; 10 000 rpm — отдельное инженерное исследование
(центробежный фактор ×8.16 относительно 3500), не входит в эту карту.

## §5 Статистика и provenance (привязка к ToR)

Все повторные измерения: независимость по ToR §4 (не детерминированный
перезапуск); n, estimator, confidence level (95% one-sided t),
small-sample correction и UCB публикуются обязательно. Каждое измерение:
прибор, калибровка/класс точности, дата, условия, серийный/маркировка
экземпляра. Подмена данных расчётными — контрактно исключена.

## §6 Чего в карте НЕТ

Нет Maxwell/FEM-запуска (отдельное разрешение по ToR). Нет HV. Нет
вращения выше 3500 rpm. Нет инверторных испытаний. Нет сравнения
звезда/OEW под нагрузкой — это следующие карты после закрытия A–D.

## §7 Связь с контрактами

Измеренные R, L, Ke — физический источник параметров для будущего
реального ROM (замена синтетики); eps_real и разрешимость torque ROM —
только после отдельно разрешённой FEM/noise-кампании по frozen ToR.
Результаты блоков A–D сами по себе не изменяют ни один frozen-контракт;
их использование в ROM — отдельным согласованием.
