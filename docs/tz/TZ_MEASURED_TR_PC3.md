# ТЗ: измеренный Tr — открыть slip-модель в RUN (ПК-3)

Статус: **черновик на согласование владельцу**. Код не правится до отдельного «добро».
Дата: 2026-10-31. Автор: агент (ПК-3). Приёмщик: владелец проекта.

## 1. Цель
Получить **измеренный** `Tr` (`AT_VALID_TR` в `measured_mask`) — единственное, чего не
хватает, чтобы slip-модель открылась в RUN и привод вышел на уставку.

## 2. Основание — измеренные факты
1. Гейт slip требует измерение, а не введённое число:
   `FocSlipPolicy_TrUsable(tr_us, tr_from_measurement)` и
   `AT_TrIsFromMeasurement(g_motor_params.measured_mask)` в `src/foc.c:904,974`.
   `AT_VALID_TR` ставит только автотюн; `mp=` оператора даёт `AT_VALID_TR_MANUAL` —
   в slip не идёт (намеренно, `src/foc.c:966-975`, комментарий).
2. Фикс выборки (`19be192`) снял нулевые dq-кадры (17 % → 0 %) и раскачку PI. После
   него в RUN при ручном `Tr` slip остаётся 0 — по политике, а не по дефекту:
   `slip_raw = 0` во всех кадрах прогона `run_diag3_20261015.log` (сырое значение,
   без деления). Разгон до 60–75 об/мин при уставке 100 и срыв на 7–11 с — это
   следствие отсутствия скольжения в угле поля, а не неисправности тракта.
3. Силовые автотюны заглушены: `both_enable()` в `src/autotune.c` (~1412) выдаёт
   `@AT:ERROR:POWER_BLOCKED:no measured OEW sector/window map` и аварийно выходит;
   обход через `PWM_Enable()` удалён как второй расходящийся порядок открытия.
   **`rr` (запертый ротор → Rr/Tr) и `noload` (свободный вал → Lm) в текущей
   ревизии не запускаются вообще.**
4. Карта OEW на стенде есть и загружается: `@MAP:LOAD:OK:crc=0xF68D948B`, identity
   совпал по 11 полям. Значит, если заглушка проверяет наличие карты — предусловие
   на ПК-3 выполнено; если блокирует безусловно — предстоит понять, что она проверяет
   (первый шаг работ).

## 3. Объём работ
1. **Разобрать `both_enable()`**: что именно проверяется (наличие измеренной карты /
   готовность `CurrentRecon` / безусловный блок) и какой штатный путь открытия силового
   контура был удалён. Результат — точный перечень условий, при которых `rr`/`noload`
   разрешены, и обоснованный путь возврата.
2. **Вернуть силовой путь через штатный порядок** (`PWM_Enable` + `CurrentMap_Select`),
   не через обход: с default-deny, `LOCK_ROTOR`-предусловием для `rr`, свободным валом
   для `noload`, и снятием ШИМ при любом отказе.
3. **Квалификация на стенде** (оператор присутствует, DC-link 30 В либо согласованный):
   - `rr` ×2–3: `@AT:RR:OK`, **SNR высокий** (число не выдавлено из шума), `Rr` внутри
     окна правдоподобия паспорта (2.7…68 Ом), `Tr ≥ 1000 мкс` (`FOC_SLIP_POLICY_MIN_TR_US`),
     повторяемость.
   - `noload`: `Lm` в правдоподобном диапазоне.
   - `mp=` с полным набором оставляет `Rr/Lm/Tr` ненулевыми, и `measured_mask` несёт
     `AT_VALID_TR` (не `AT_VALID_TR_MANUAL`).
4. **Приёмка RUN**: при том же `i=2000,0`, `s=100`, 30 В — slip открывается
   (`slip_hz ≠ 0`), привод достигает и держит 100 об/мин, срыв на 7–11 с отсутствует.
   Всё — измеренные величины, не PASS/FAIL по ожиданию.

## 4. Ограничения и правила
- `src/autotune.c` — safety-модуль: правка только по отдельному «добро на правку», с
  тестами и гейтом; push в `main` — только при зелёном гейте.
- Силовой автотюн подаёт напряжение на обмотки: только на стенде, только при операторе,
  с `make backup` перед рискованным опытом (AGENTS.md).
- Инъекции в МК и принудительные значения — только на no-HV.
- Измеренный `Tr` — приёмка по повторяемости и окнам правдоподобия, а не по факту
  завершения команды.
