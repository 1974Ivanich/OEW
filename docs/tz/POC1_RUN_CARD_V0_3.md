# POC-1 Run Card v0.3 — BM1109 OEW-6T

**Назначение:** превратить POC-1 из контракта
(`TZ_FEM_BACKEND_CONTRACT_V0_1.md`, разделы «Объём POC», «Пять физических
проверок», «Приёмка») в заранее зафиксированный список расчётных состояний с
критериями PASS/FAIL, чтобы первый реальный FEM-прогон не стал серией
импровизированных экспериментов.

**Статус документа:** план. Ни один кейс этим документом не генерируется и не
запускается. `solver/getdp/cases/*.json` создаются при первом прогоне из таблицы
§6, а не заранее: файл кейса без прогона — непроверяемый артефакт.

**Изменения по версиям:**

- v0.2: `T_cog` убран как факт (9 катушек не 9 пазов); `p = 3` — только
  falsification gate; явный stencil момента; деление проверок на S/A;
  нелинейная суперпозиция — `CONFIG_ONLY`.
- **v0.3:** уточнено, **что именно** антисимметрично по току: `Te(+I) = -Te(-I)`
  и `psi(+I) = -psi(-I)` для машины с PM неверны, проверяются PM-независимые
  разности и приращения; добавлен кейс 18 (`-I` при `80°`), без которого stencil
  момента для `-I` не строится; подсчёт S-кейсов сведён явной таблицей;
  `psi_diff = 2*psi_inc` ограничен линейным материалом, а нелинейная
  взаимность вынесена из POC-1 в ROM-гейты (симметрия якобиана).
- **v0.3, ревизия 2026-11-25 (b):** нулевое состояние разделено по типу модели
  (`NO_PM` / `PM`): у модели с PM `psi(0, θ) = psi_pm(θ) != 0` — это опорный
  PM-поток (`PM_REFERENCE`), а не ошибка; `psi(0) = 0` осталось гейтом только
  для `NO_PM`. `psi_pm` определяется как `psi(0, θ)`, а `0.5*(psi(+I) + psi(-I))`
  переименовано в `psi_even`. `W'(0) = 0` — выбранная нормировка в одной
  опорной точке, а не физический гейт; критерии знака и монотонности `W'`
  переписаны для части энергии, зависящей от тока.
- **v0.3, ревизия 2026-11-25 (c):** заморожены параметры фазы 2: `eps_psi = 1e-3`
  с `psi_floor` из `manifest.json` и проверкой двух шагов `Δi`; добавлен кейс 19
  `POC1_1_zero_t040` (`psi_pm(40°)` напрямую, без `psi_even`); гейт `Te_odd`
  отнесён к классу «реализация / согласованность».

## 4. Группы S и A: что блокирует `theta_e0 = UNKNOWN`

| Группа | Что входит | Условие запуска |
|---|---|---|
| **S** — статические и геометрические | нулевое поле (`NO_PM`: `psi(0) = 0`; `PM`: `psi(0) = grad_i W'(0)`), проверки `psi(±I)` через разности, взаимность 3×3, evidence отсутствия звезды, линейная суперпозиция, `eps_psi`, нормировка `W'(0, θ_ref) = 0`, повтор | G0 PASS + `I_ref` |
| **A** — угловые | `psi(i, θ)` как функция угла, `Te(θ)` и cogging, `∂W'/∂θ`, `Te_odd` vs `I*dpsi_pm/dtheta`, замыкание цикла | G0 PASS + `theta_e0` подтверждён + `p` имеет основание |

### Подсчёт S-кейсов (сверка)

Строк с меткой `S` в матрице — 10, но кейсов группы S при `theta_e0 = UNKNOWN`
исполняется **9 полных + 1 частично**. Частичный — кейс 1:

| Кейс 1 `POC1_1_zero_t000` | Группа | Исполняется при `UNKNOWN` |
|---|---|---|
| сходимость, `max|B|` конечен | S | да |
| `psi_U = psi_V = psi_W = 0` | S | да |
| `Te(θ)` при `i = 0` (профиль cogging по кейсам 1–4) | A | нет |

Поэтому «10 строк с S» и «9 кейсов + статическая часть одного» не противоречат
друг другу: кейс 1 принадлежит обеим группам, а его угловая часть в подсчёт S
не входит.

| Величина | Число |
|---|---|
| всего кейсов | 19 |
| строк с меткой `S` | 10 |
| из них полных S-кейсов | 9 (5, 6, 9–14, 17) |
| частичный S-кейс | 1 (`POC1_1_zero_t000`) |
| строк только `A` | 9 (2, 3, 4, 7, 8, 15, 16, 18, 19) |

При `theta_e0 = UNKNOWN` гейты A1, A2, A5 получают `PARTIAL (S)`, A6 —
`PARTIAL` (повтор есть, замыкание цикла нет); кейсы группы A — `NOT RUN`.
Подстановка `theta_e0 = 0` запрещена: `UNKNOWN` остаётся `UNKNOWN`.

`T_cog = 360°/LCM(N_s, N_p)` — формула для **пазов**, а не катушек. Подтверждены
9 катушек; число пазов `N_s` неизвестно до G0.4. Поэтому `T_cog` в этом
документе не вычисляется, углы `0, 5, 10, 15°` — предварительные, и после G0.4
набор B пересматривается **до** серии.

## 7. Что именно антисимметрично по току

Ранее в v0.1/v0.2 в качестве гейтов стояли `psi(+I) = -psi(-I)` и
`Te(+I) = -Te(-I)`. Для машины с постоянными магнитами это неверно, и такие
соотношения из Run Card удалены.

**Разложение.** Для линейной системы с PM

```text
W'(i, th) = 0.5 * L(th) * i^2 + psi_pm(th) * i + C(th)
Te(i, th) = 0.5 * i^2 * dL/dth + i * dpsi_pm/dth + dC/dth
```

Слагаемые `0.5*i^2*dL/dth` (реактивное) и `dC/dth` (cogging) **чётны** по току,
`i*dpsi_pm/dth` — нечётно. Отсюда:

```text
psi(+I) + psi(-I) = 2 * psi_pm(th)            (не ноль при PM)
Te(+I)  + Te(-I)  = I^2 * dL/dth + 2 * dC/dth (в общем случае не ноль)
Te(+I)  - Te(-I)  = 2 * I * dpsi_pm/dth      (PM-момент)
```

**Что проверяется вместо этого** — только величины, в которых PM-поток
сокращается:

| Величина | Смысл | Гейт |
|---|---|---|
| `psi_diff = psi(+I) - psi(-I)` | `2 * L * I`, PM сокращается | `psi_diff > 0` |
| `psi_inc = psi(+I) - psi(0)` | `L * I`, PM сокращается | `psi_inc > 0` |
| согласованность | в линейной системе `psi_diff = 2 * psi_inc` | `|psi_diff - 2*psi_inc| <= 1e-6 * psi_scale` |
| `Te_odd = 0.5 * (Te(+I) - Te(-I))` | PM-момент | обязан быть `!= 0` только если `psi_pm(th)` зависит от угла |
| `Te_even = 0.5 * (Te(+I) + Te(-I))` | cogging + реактивный | **diagnostics, не гейт** |

`Te(+I) = -Te(-I)` как критерий **не используется**: для этой машины он
не выполняется по построению, а не из-за ошибки.

### Замечание к контракту (`CONTRACT_NOTE`)

Контракт (POC-2) формулирует `|psi_U(+I) + psi_U(-I)| <= 1e-6 * max|psi_U|`.
В сыром виде это верно только при `psi_pm(θ) = 0`. Run Card применяет требование
к разностям и приращениям, где PM-поток сокращается. Контракт **не правился**;
расхождение зафиксировано здесь и требует решения владельца контракта.

## 8. Критерии по группам

Обозначения: `psi_scale = max|psi|` по серии; `Te_scale = |Te|` в кейсе 5;
допуски относительные и фиксируются в `manifest.json` до первого запуска.

### POC-1.1 — нулевой ток

| Проверка | Критерий PASS | Класс | Группа |
|---|---|---|---|
| Сходимость | `converged = 1` во всех запущенных кейсах | реализация | S |
| Тип модели | `model_type = NO_PM` или `PM` записан в `manifest.json` до первого запуска | — | S |
| Нулевой поток, `NO_PM` | `|psi_k| <= 1e-9 * psi_scale` | реализация | S |
| Нулевой поток, `PM` | `max_k |psi_k(0, θ) - ∂W'/∂i_k(0, θ)| / max(psi_scale, psi_floor) <= 1e-3` (порог `eps_psi` из POC-1.5; кейсы 1 и 19); значение `psi(0, θ)` записывается как `psi_pm(θ)`, статус `PM_REFERENCE`; ноль **не** требуется | реализация | S |
| Отсутствие вырождения | `max|B|` конечно, нет `NaN` | реализация | S |
| Позиционный момент | `PM`: `Te(θ)` при `i = 0` не тождественный нуль (кейсы 1–4, `h = 5°`); `NO_PM`: `|Te(θ)| <= abs_floor` | физика модели | A |
| Величина cogging | `max|Te(θ)| <= 0.02 * Te_scale`; иначе находка `COGGING_SIGNIFICANT` | физика | A |
| Период cogging | не проверяется: `T_cog` не установлен (§5) | — | — |

**Абсолютный `psi`.** `psi` — потокосцепление замкнутых катушек FEM без
произвольной аддитивной постоянной; `psi(0, θ)` у `PM` — опорный PM-поток, и
DOE-2 использует его в ЭДС `ω_e J psi` без поправок. Аддитивная постоянная в
экспорте — ошибка постобработки, её ловит гейт «Нулевой поток, `PM`».

`Te(0)` считается по кейсам 1, 2, 3 с шагом `h = 5°`; это **diagnostics**, и
сравнивать его напрямую с `Te(±I)` нельзя — там другой шаг (`h = 40°`).

### POC-1.2 — одна пара выводов, `±I`

| Проверка | Критерий PASS | Класс | Группа |
|---|---|---|---|
| Положительная индуктивность | `psi_diff = psi(+I) - psi(-I) > 0` (кейсы 5, 6) | реализация | S |
| Приращение по току | `psi_inc = psi(+I) - psi(0) > 0` | реализация | S |
| Согласованность разностей | `|psi_diff - 2*psi_inc| <= 1e-6 * psi_scale` — **gate только для `LINEAR_MATERIAL`**; при `NONLINEAR_MATERIAL` — diagnostic (§8.1) | реализация | S |
| Чётная часть как diagnostics | `psi_even = 0.5*(psi(+I) + psi(-I))` записывается; ноль не требуется. С `psi_pm = psi(0, θ)` совпадает только для `LINEAR_MATERIAL`; при насыщении в неё входит и чётная по току часть насыщения | физика | S |
| `Te_odd` ненулевой | требуется, если `psi_pm(θ)` меняется: сравнить `psi_pm = psi(0, θ)` на `θ = 0` и `40°` (кейсы 1 и 19) | физика | A |
| `Te_odd` vs PM-момент | `|Te_odd - I * dpsi_pm/dtheta| <= 2 %` от `Te_scale` или `abs_floor`; `dpsi_pm/dtheta` — по кейсам 1 и 19 | реализация / согласованность: при общем stencil `40°` в линейной модели равенство тождественно, независимую проверку момента даёт только Maxwell (POC-1.5) | A |
| `Te(+I) + Te(-I)` | **не гейт**; пишется как `Te_even` | diagnostics | A |

**Область применимости `psi_diff = 2*psi_inc`.** Равенство выведено из
`psi = L*i + psi_pm` и потому верно только для линейного материала. При
насыщении и взаимодействии PM-поля с током `psi` уже не имеет вида
`L*i + psi_pm`, и остаток в общем случае не нулевой. Отсюда:

- `LINEAR_MATERIAL`: равенство — gate (`1e-6`); нарушение означает либо ошибку
  реализации, либо незаявленную нелинейность в линейной модели;
- `NONLINEAR_MATERIAL`: равенство — только diagnostic; остаток пишется в отчёт и
  **не** трактуется как FAIL. Кейс 14 относится именно к этому случаю.

Иначе корректная нелинейная модель была бы объявлена не прошедшей тест из-за
свойства, которое к ней не применяется.

### POC-1.3 — три независимых состояния, отсутствие звезды

| Проверка | Критерий PASS | Класс | Группа |
|---|---|---|---|
| Матрица `L` 3×3, линейный | `L_ab = (psi_a(i_b) - psi_a(0)) / I` (приращение, не сырое `psi`) | реализация | S |
| Взаимность, линейный | `|L_ab - L_ba| <= 1e-6 * max|L_ab|` — finite-difference gate | реализация | S |
| Взаимность, нелинейный | дифференциальный якобиан `L_inc = dpsi/di = grad_i^2 W'`, симметрия `L_inc,ab = L_inc,ba` **обязательна** для гладкой co-energy. **В POC-1 не проверяется** | ROM physics gate (обязательный) | — |

Для нелинейного материала конечные приращения `(psi_a(i_b) - psi_a(0))/I` — это
только diagnostics: равенство таких приращений не эквивалентно симметрии
дифференциальной матрицы. Проверка нелинейной взаимности требует якобиана,
построенного из одной co-energy-функции, и относится к ROM-гейтам, а не к POC-1.
Смешивать эти два объекта нельзя: симметрия конечных приращений не доказывает
симметрии якобиана, а симметрия якобиана не требует равенства приращений,
вычисленных вдоль разных траекторий.

При этом для гладкой co-energy-модели `psi = grad_i W'` якобиан
`L_inc = dpsi/di = grad_i^2 W'` **обязан** быть симметричным
(`L_inc,ab = L_inc,ba`). Несимметрия якобиана — не эффект насыщения, а признак
ошибки реализации, численного дифференцирования, несогласованности данных или
нарушения предположения о единой гладкой co-energy-функции. Поэтому симметрия
`L_inc` — обязательный ROM physics gate, а не «мягкая» проверка качества.
| Звезда не навязана | `|psi(i+t*1) - psi(i)| / psi_scale > 1e-3` (кейсы 12 против 11) | реализация (A7) | S |
| Эффект `i_0 != 0` | число `Δpsi/psi_scale` записывается; `> 1e-3` — находка `I0_EFFECT` | физика | S |

### POC-1.4 — суперпозиция

### POC-1.5 — энергия и момент

Расчёт `Te` — явный угловой stencil, отдельно для `+I` и `-I`:

```text
h   = 40 deg = 0.69813170 rad   (фиксируется до серии)
Te(th0) ~ ( -3*W'(th0) + 4*W'(th0+h) - W'(th0+2h) ) / (2*h)

Te(+I): th = 0, 40, 80 deg  -> кейсы 5, 7, 15
Te(-I): th = 0, 40, 80 deg  -> кейсы 6, 8, 18
```

Требования: одинаковые токи во всех трёх точках; угол в формуле — в радианах;
одна единица `W'` (Дж или Дж/м, зафиксировать в манифесте); та же сетка,
настройки и материал; `h` не подбирается после прогона. Чувствительность `Te` к
шагу — отдельная проверка ROM-датасета, не гейт POC-1.

| Проверка | Критерий PASS | Класс | Группа |
|---|---|---|---|
| Две ветви `psi` | `eps_psi = max_k |psi_W',k - psi_A,k| / max(psi_scale, psi_floor) <= 1e-3`; `psi_floor` фиксируется в `manifest.json` до серии и не вычисляется из результата | реализация | S |
| Шаг `Δi` | `eps_psi(Δi = 0.025 I_r) <= eps_psi(Δi = 0.05 I_r)`: ошибка центральной разности (`~Δi²/6`) убывает с шагом, ошибка экспорта — нет | реализация (качество) | S |
| `Te(+I)` по stencil | вычислен без изменения шага | реализация | A |
| `Te(-I)` по stencil | вычислен тем же шагом `h` | реализация | A |
| `Te` vs Maxwell | `<= 2 %` от `Te_scale` или `abs_floor` | реализация | A |
| Роль Maxwell | только независимая проверка, не замена энергетической производной | — | — |
| Энергия | `W'` конечна; `W'(0, θ_ref) = 0` — только выбранная нормировка (одна опорная точка), не гейт: при `PM` `W'(0, θ)` меняется с углом, и `∂W'(0, θ)/∂θ = Te_cog` | реализация | S |

| Монотонность по току | `ΔW'(t·i, θ)` не убывает по `t >= 0` | физика модели | S |

## 9. Условия остановки серии

1. любой запущенный кейс не сошёлся (`converged = 0`);
2. повтор расходится больше `1e-9` — модель или экстрактор недетерминированы;
3. `eps_psi > 1e-3` — ветви `W'` и `A` противоречат друг другу;
4. суперпозиция на линейном материале не проходит — ошибка реализации;
5. отсутствует `I_ref`;
6. для группы A: `theta_e0 = UNKNOWN` или `p` без основания — группа A не
   запускается (это не остановка серии, см. §4).

## 10. Что записывается в `manifest.json` до серии

- `I_ref`, `Δi`, список `case_id` с группой S/A и его SHA-256;
- `p`, основание (`гипотеза`/`подтверждено периодичностью`), `theta_e0` и статус;
- `N_s` с источником (G0.4) и `N_p`; правило пересчёта набора B;
- режим материала: `linear mu_r` или `BH_AVAILABLE` + ссылка; отдельно
  `BH_VALIDATED` да/нет;
- сетка `h_airgap_mm`, `h_iron_mm`, версия модели;
- stencil: точки `0, 40, 80°`, `h = 0.69813170 rad` для `+I` и `-I`, единица `W'`;
- определения `psi_diff`, `psi_inc`, `psi_pm`, `Te_odd`, `Te_even` — как в §7;
- допуски §8 (`1e-9`, `1e-6`, `1e-3`, `2 %`, `0.02`, `1e-4`);
- правило cogging: относительное (п. 1.1) или абсолютный порог с источником.

Допуск, назначенный после прогона, не принимается.

## 11. Что run card не покрывает

- **Магнитные материалы.** POC-1 с `linear mu_r` проверяет реализацию, а не
  сталь; нелинейная суперпозиция до `BH_VALIDATED` — `CONFIG_ONLY`.
- **Период cogging.** Нужны `N_s` (G0.4) и подтверждённая периодичность.
- **Подтверждение `p = 3`.** Может быть только опровергнуто.
- **Соответствие измеренной ЭДС** — отдельно, по данным обмера.
- **DOE-1.** 792/10357 кейсов не запускаются: POC-1 даёт 19.
- **ROM-гейты** (`L_inc` PD, `psi = grad_i W'` на полной сетке, чувствительность
  производных к шагу) — вне POC-1.
