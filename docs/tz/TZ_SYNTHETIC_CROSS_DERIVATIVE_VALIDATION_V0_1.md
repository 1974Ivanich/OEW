# ТЗ: Synthetic Cross-Derivative Validation v0.1

**Источник:** аудит DOE_3 (A+B+C) на Synthetic ROM, 2026-11-25. Установлено:
`∂²ψ/∂i∂θ ≡ 0` в текущем прогоне по двум независимым причинам — `c6 = 0`
(умолчание `Synthetic`) и 12 угловых точек (`harmonics_resolved = 5`), поэтому
6-я гармоника не разрешается. Статус B — `STRUCTURAL PASS / PARTIAL PHYSICS`.

**Цель:** проверить численную цепочку `ψ → ∂_θψ → ∂_i∂_θψ` на модели с
известным аналитическим ответом (oracle) и отделить полноту ROM-узлов от
покрытия физики. Реальных FEM-расчётов это ТЗ не требует.

## Объект

- `tools/bm1109_doe1.py` — `Synthetic`, `AnglePlan`, `fourier_derivative`,
  `build_cases`, CLI `grid`/`process`.
- `tools/bm1109_ctrl.py` — только читает ROM; **изменений не требуется**.
- Артефакты прогонов — в `build/doe1/synth/` (в git не входят).

## Проблема (подтверждено)

1. `Synthetic.flux_uvw`: `ψ_q += c6·i_q·cos 6θ` — единственный член, дающий
   `∂²ψ/∂i_q∂θ`; при `c6 = 0` (умолчание) он равен нулю тождественно.
2. `ψ_d += psi_cog·cos 2θ` **не зависит от тока** → `∂²ψ/∂i_d∂θ ≡ 0`
   структурно, при любых параметрах.
3. `fourier_derivative`: число различимых гармоник `N/2 − 1`; при 12 точках
   это 5, 6-я гармоника «алиасится в константу» (docstring функции, гейт
   `AnglePlan.issues()`). Проверено: 12 углов → 5, 24 → 11, 36 → 17.
4. В ROM прогона 396 строк разброс `dpsi_d/dtheta_e` по токам при фиксированном
   угле — `6.5e-18`; `max |∂M/∂i| = 1.29e-18`. То есть кросс-терм не проверен
   ничем, и `A_ii` фактически равен `−L⁻¹[R + ω_e·J·L]`.

## Требования

### 1. CLI `Synthetic` (минимальное расширение)

Добавить в `grid` аргументы с сохранением текущих умолчаний:

| Аргумент | Умолчание | Смысл |
|---|---|---|
| `--c6` | `0.0` | коэффициент `c6·i_q·cos 6θ` |
| `--psi-cog` | `0.0` | `psi_cog·cos 2θ` (от тока не зависит) |
| `--swirl` | `0.0` | неконсервативное поле (для контура) |

Умолчания не меняются: без флагов прогон воспроизводит текущий baseline.

### 2. Три прогона

| Прогон | Параметры | Ожидание |
|---|---|---|
| **S0** baseline | `c6 = 0`, 12 углов, `--stencil axes` | `∂_i∂_θψ = 0` (в пределах шума), `C_ROM = 13/33` |
| **S1** angular limit | `c6 ≠ 0` (например `1e-3`), 12 углов, `--stencil axes` | кросс-терм **не восстанавливается**: `|measured| ≤ 0.1·|oracle|` |
| **S2** full | `c6 ≠ 0`, 24 угла, `--stencil all` | `∂_i∂_θψ ≈ oracle` с точностью ≤ 2 % |

`c6 ≠ 0` — **validation-only** параметр; он не является оценкой физики BM1109
и не должен попадать в canonical ROM.

### 3. Аналитический oracle

Для `ψ_q = L_qq(i)·i_q + c6·i_q·cos 6θ`:

```text
∂ψ_q/∂θ_e   = −6·c6·i_q·sin 6θ
∂²ψ_q/∂i_q∂θ = −6·c6·sin 6θ
```

Критерий S2 по каждому внутреннему узлу:

```text
|measured − oracle| / max(|oracle|, 1e-9) ≤ 0.02
```

Узлы, где `|oracle| < 1e-6·max|oracle|` (окрестности `sin 6θ = 0`),
из относительного критерия исключаются и проверяются абсолютно:
`|measured − oracle| ≤ 1e-6·max|oracle|`.

### 4. Симметрия смешанной производной (гейт на ROM)

Две независимые ветви должны совпасть:

```text
∂_θ L   (из колонок Ldd…L00 по углам)
∂_i M   (из колонок dpsi_*_dtheta_e по узлам)
```

Критерий по точке: `‖∂_θL − ∂_iM‖_F / max(‖∂_θL‖_F, ‖∂_iM‖_F, ε) ≤ 0.05`,
где нормы — по подматрице `dq` (ось `0` исключена: `i_0 = 0` — model
constraint). Гейт `cross_derivative_symmetry`; на S0 обязан дать
`PASS` при обоих нулях (`ε`-защита), на S2 — `PASS` при выполнении п. 3.

### 5. Разделение статусов

Два независимых статуса вместо одного `ROM completeness FAIL`:

```text
C_ROM  = узлы с полным derivative data / 33 требуемых
       = 13/33 = 39.4 %  (axes)      → 33/33 = 100 % (all)

physics_coverage:
  angular_harmonics_resolved  PASS/FAIL   (N/2−1 ≥ 6)
  cross_derivative_oracle     PASS/FAIL/NOT_VERIFIED
  cross_derivative_symmetry   PASS/FAIL/NOT_EVALUATED
```

Правило: `cross_derivative_oracle = NOT_VERIFIED`, если `c6 = 0` или
`harmonics_resolved < 6` — это отказ от вывода, а не PASS.

### 6. Stencil convergence (без изменений)

Оставить `--delta 0.05 0.025` и существующий `--gate-eps-l` (0.05).
`FEM_RADIUS = 1.1` не менять: `1.0 + 2δ_max = 1.1` уже покрывает
одностороннюю схему 2-го порядка на границе `|x| = 1`.

## Что запрещено этим ТЗ

- Менять `FEM_RADIUS`, умолчания `--delta`, `--stencil` и `--points`.
- Менять `tools/bm1109_ctrl.py` (в частности, добавлять туда гейт
  `cross_derivative_symmetry` — он живёт в DOE_1) и прошивку.
- Выдавать S2 за проверку физики BM1109: это проверка numerical chain.
- Запускать реальные FEM-кейсы (`10357` при `stencil=all`, 24 угла) до
  прохождения S0–S2.

## Приёмка

1. `--c6`, `--psi-cog`, `--swirl` доступны в CLI, умолчания прежние;
   прогон без флагов побитово совпадает с текущим baseline по `L_dq0.csv`.
2. S0/S1/S2 отработали, `summary.json` каждого содержит: `c6`, `points`,
   `stencil`, `harmonics_resolved`, `C_ROM`, `eps_L`, `cross_oracle_rel`,
   `cross_symmetry_rel`, `gates`.
3. S1 даёт ожидаемый отрицательный результат (кросс-терм не виден),
   S2 — `PASS` по п. 3 и п. 4.
4. Код возврата: `0` — ожидания прогона выполнены, `1` — расхождение,
   `ERROR ≠ PASS`: отсутствие данных не превращается в `PASS`.
