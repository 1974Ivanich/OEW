# ТЗ: тайминг сэмпла тока — покрыть сектора 0/1/4/5 (ПК-3)

Статус: **черновик на согласование владельцу**. Код не правится до отдельного «добро».
Дата: 2026-10-31. Автор: агент (ПК-3). Приёмщик: владелец проекта.
Основание: `docs/FINDING_SAMPLE_TIMING_SECTOR_NULL_PC3.md`.

## 1. Цель
Устранить нулевые сэмплы тока в секторах 0/1/4/5 (измерено 14 % циклов FOC), чтобы
контур тока работал по свежим данным во всех 6 секторах.

## 2. Объём работ
1. **Разрешить развилку** (без правки, анализ/осциллограф):
   - (а) добавить **вторую** точку сэмпла (вторая инжектированная последовательность /
     второй фронт в цикле) — покрывает все сектора, но это новая логика сэмплирования;
   - (б) сдвинуть **единственную** точку (`trigger_offset_ticks`) — дёшево, но почти
     наверняка не покроет 6 секторов одновременно (нет универсального мгновения с
     ненулевым током на обоих шунтах).
   Результат — выбранный вариант с обоснованием.
2. **Правка** (по выбранному варианту): вторая точка сэмпла и привязка `window` к ней
   либо коррекция offset'а. `src/adc.c`, `src/pwm.c`, `src/current_map_selector.c` —
   safety-модули.
3. **Тест**: hosted-проверка, что для каждого сектора существует окно/точка с
   ненулевой реконструкцией (инъекция кадра с ненулевым током по всем секторам);
   полный `make test` зелёный (настоящий exit code).
4. **Приёмка на стенде**: прогон RUN — `stale`-прирост за прогон падает до ~0 (или
   обоснованно мал), распределение по секторам выравнивается.

## 3. Критерии приёмки
- `stale`-прирост за RUN < 1 % циклов (измерено полем `:stale=%lu`), либо письменно
  обосновано, почему остаток — норма.
- Нет секторов с систематическим нулём: распределение потерь равномерно.
- Гейт зелёный на каждом шаге; `ERROR ≠ PASS`.

## 4. Ограничения
- Силовой тракт: правка только по отдельному «добро на правку», с тестами и гейтом;
  push в `main` — при зелёном гейте.
- Прошивка/подача напряжения — только с разрешения владельца; `make backup` перед
  рискованным опытом.
- Не трогать: карту (`F68D948B`), энкодер, фикс `19be192`, счётчик `ead28f9`.

## 5. Что НЕ входит
- Измеренный `Tr` (отдельное ТЗ), slip-модель, усиления PI.
