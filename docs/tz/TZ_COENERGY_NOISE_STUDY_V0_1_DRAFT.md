# ТЗ: исследование численного шума co-energy (проект V0.1, НЕ УТВЕРЖДЕНО)

Статус: ПРОЕКТ на согласование владельца. Не является разрешением на
реальные FEM-расчёты. До утверждения — только методика, формулы, структура
эксперимента, требования к данным/скриптам/отчётам.

Жёсткие ограничения: без запуска Maxwell, генерации FEM-точек, изменения
физики, сетки 33×12, стенсилов, frozen h = 0.5°, порога 1% и gates.

## §1 Цель

Количественно определить, при каких настройках FEM solver и процедурах
обработки бюджет ошибки co-energy позволяет torque ROM пройти критерий
E_trunc + E_corner ≤ 1% при заданном T_peak, и сформулировать критерии
допуска будущей FEM-кампании.

## §2 Декомпозиция погрешности co-energy

Ошибка оценки W'(i, θ) раскладывается на:
- **случайную составляющую** σ_rand — воспроизводимостью не обладает,
  снижается усреднением независимых повторов (~1/√N);
- **систематическое смещение** b_sys(mesh, solver settings) — воспроизводимо
  при тех же настройках, усреднением НЕ устраняется;
- **пространственную составляющую** — зависимость ошибки от положения в
  решётке токов (края vs центр);
- **угловую составляющую** — зависимость от θ (симметрии машины, сетка
  вращения).

Все четыре оцениваются и публикуются раздельно. Запрещено маскировать
систематическую составляющую статистикой повторов.

## §3 Сходимость решателя

Зависимость W' и его ошибки от: mesh density (несколько уровней), порядка
элементов, nonlinear solver tolerance, критериев сходимости. Требуемый
результат: таблица сходимости W'(settings) с оценкой asymptotic error
(экстраполяция Ричардсона либо консервативная оценка по двум finest-уровням,
если сеточная сходимость не монотонна — фиксируется честно).

## §4 Повторяемость

Независимые повторные расчёты (одинаковые настройки): дисперсия σ²_rand,
доверительные интервалы. Повторы с изменёнными seed/настройками — оценка
чувствительности. Минимальное число повторов и метод оценки фиксируются
до эксперимента, не постфактум.

## §5 Усреднение

Усреднение N независимых повторов снижает только σ_rand. Формулы:
σ_mean = σ_rand/√N; b_sys инвариантно к N. Критерий разделения:
дисперсия среднего должна сходиться как 1/N — проверяется эмпирически;
отклонение от 1/N — признак коррелированной (квазисистематической) ошибки,
публикуется как отдельный результат.

## §6 Распространение ошибки

Связь бюджета W' с критерием C3: E_corner = eps_W/h/T_peak; при
h = 0.00872665 рад и требовании E_trunc + E_corner ≤ 0.01 получаем
допустимый eps_W(T_peak) = (0.01 − E_trunc)·h·T_peak. Для T_peak = 90 мН·м
и E_trunc = 0.411%: eps_W допустимый ≈ 3.96e-6 Дж — ровно уровень V0.3.
Численный вывод V0.4: при eps_W = 7.2e-6 Дж (текущий нормативный бюджет)
критерий недостижим ни при каком h — требуется либо снижение реального
шума FEM ниже ~4e-6 Дж, либо рост разрешаемого T_peak выше ~140 мН·м.
Важно: нормативный eps_W — потолок допущения, а не измерение; реальный
шум FEM может быть ниже — это и предстоит доказать или опровергнуть.

## §7 Критерии допуска FEM-кампании (проект)

Минимальные требования к будущей кампании:
1. provenance артефактов: каждая оценка W' сопровождается solver settings,
   mesh id, seed/повтором; подмена синтетикой исключена контрактно;
2. повторяемость: σ_rand оценён с доверительным интервалом;
3. сходимость: b_sys оценён по mesh/solver sweep;
4. итоговый бюджет eps_real = b_sys + k·σ_rand (k фиксируется до кампании)
   сравнивается с допустимым eps_W(T_peak) из §6;
5. решение о разрешимости torque ROM принимается по eps_real, а не по
   нормативному потолку.

## §8 Два раздельных результата

1. **Качество численного решения Maxwell** — сходимость, повторяемость,
   ошибки §2-§5. Критерии численной добротности FEM.
2. **Пригодность ROM для torque-расчёта** — соответствие eps_real бюджету
   §6/§7. Это связанные, но не тождественные критерии: добротный FEM может
   не пройти бюджет torque ROM, и наоборот слабый бюджет не требует
   высокой добротности. Оба результата публикуются раздельно.

## §9 План работ после утверждения ТЗ

1. Аналитическая проработка формул §2/§5/§6 на синтетике (без Maxwell).
2. Подготовка структуры данных provenance и форматов отчётов.
3. Скрипты анализа повторов/усреднения, проверенные на синтетике с
   контролируемым шумом.
4. Итоговый документ критериев допуска кампании — на утверждение.
5. Запуск Maxwell — только отдельным разрешением владельца.
