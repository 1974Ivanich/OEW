# ТЗ: POC-2 nonlinear contract v0.1 — BM1109 OEW-6T

**Назначение:** единственное нормативное место для нелинейных проверок POC-2
(P2-N1, P2-N2, P2-N3). Run Card POC-1 и FEM backend contract содержат только
ссылки на этот документ и не дублируют его математику.

**Ревизии:** v0.1 (2026-11-25) — исходная редакция; (b) 2026-11-25 — порог N1
через бюджет ошибки приращения `e`, перенос через `T`, предпосылка
`field_increment_consistency` (решение владельца).

**Источник:** аудит DOE-1/DOE-2/DOE-2C и решения владельца 2026-11-25: двух
точек `±I` недостаточно ни для симметрии полного якобиана, ни для согласованности
с co-energy, поэтому нелинейный POC-2 разделён на три независимых гейта.

**Границы:**

- линейные строки POC-2 (`TZ_FEM_BACKEND_CONTRACT_V0_1.md`, раздел POC-2) не
  меняются;
- DOE-3 (`tools/bm1109_ctrl.py`) этим документом не затрагивается и физически
  согласованным с OEW-6T не считается до отдельного аудита;
- новые FEM-кейсы этим документом не вводятся: P2-N1 работает на уже
  существующей сетке DOE-1.

## 1. Три независимых гейта

| Гейт | Утверждение | Статус документа |
|---|---|---|
| **P2-N1** | диагональ `L_inc` в UVW положительна: `∂psi_a/∂i_a > 0` | нормативно (§2) |
| **P2-N2** | дифференциальная взаимность `L_inc,ab = L_inc,ba` | нормативно (§4) |
| **P2-N3** | cross-scale интегральная согласованность `L→ψ` на масштабе решётки | нормативно (§5) |

Гейты не подменяют друг друга: N1 не проверяет взаимность и не проверяет
положительную определённость всей матрицы `L_inc`; собственные значения `L_inc`
после N2 — только диагностика.

## 2. P2-N1 — положительность собственной дифференциальной индуктивности

### 2.1 Определение

Для каждой фазы `a ∈ {U, V, W}`:

```text
L_aa(i_U, i_V, i_W, theta_e) = ∂psi_a/∂i_a |_(i_b, i_c, theta_e)
L_UVW = T^T * L_dq0 * T,   T = Park(theta_e) * Clarke (ортонормальные)
```

`L_dq0 = ∂psi_dq0/∂i_dq0` при фиксированном `theta_e`. PM-поток не вычитается и
знак не определяет: проверяется наклон, а не значение `psi`. Критерий одинаков
для `NO_PM` и `PM`.

### 2.2 Источник данных

- `L_dq0` — строки `process` DOE-1 (`tools/bm1109_doe1.py`): центральная
  разность по FEM-кейсам, на границе `Omega_FEM` — односторонняя 2-го порядка;
  шаг `Δi = deltas[0] * I_r` (по умолчанию `0.05 * I_r`).
- Это не независимый якобиан: повторная конечная разность по тем же
  FEM-данным — проверка реализации (класс `implementation`/`diagnostic`), а не
  подтверждение физики.

### 2.3 Область

- все базовые узлы DOE-1 (33 точки в нормированной сфере × углы плана), в
  которых строка ROM содержит полную матрицу `L_dq0`;
- узел без полной матрицы — `ROM_DOMAIN_INCOMPLETE`; интерполяция и
  экстраполяция запрещены;
- угловая сетка — равномерная по `theta_e` на полном выбранном электрическом
  периоде (по умолчанию 12 точек, шаг 30° эл.). Пока `p` и `theta_e0` не
  подтверждены, соответствие этой сетки механическому периоду — гипотеза:
  результат несёт `angle_grid_status = HYPOTHESIS_P`.

### 2.4 Порог: бюджет ошибки приращения потока

Ревизия 2026-11-25 (b): порог через полный `psi_scale` удалён из N1. Он
масштабировал ошибку постоянным по току PM-потоком и при `psi_pm >> L*I`
делал гейт неразрешимым, хотя `L_aa` от PM не зависит. PM-поток по-прежнему
нигде не вычитается из физического `psi` перед вычислением `L_inc`.

**Ошибка отсчёта** (замороженный бюджет, не подбирается после прогона):

```text
e = eps_psi * max(psi_delta_scale, psi_delta_floor)
psi_delta_scale = max_(theta, k, узлы) |psi_k(i, theta) - psi_k(0, theta)|,  k ∈ {d, q, 0}
```

- `eps_psi = 1e-3` — тот же замороженный допуск; для `field_consistency` и
  нулевого состояния он по-прежнему относится к абсолютному `psi`;
- `psi_k(0, theta)` — нулевой токовый узел DOE-1 при том же `theta`. Это
  определение масштаба ошибки, а не преобразование исходных потокосцеплений;
- `psi_delta_floor` (Wb) обязателен: задаётся `grid --psi-delta-floor` в
  манифесте сетки до серии и не вычисляется `process` из результата; нет
  значения — `NOT_EVALUATED`.

**Ошибка производной по оси `n`.** Для `L_n = sum_k w_k psi_k / Δi` при
`|δpsi_k| <= e` граница `δL_n <= (sum_k |w_k| / Δi) * e`:

| Схема по оси `n` (фактическая в данной точке) | Веса | `W_n` |
|---|---|---|
| центральная | `(-1, +1) / 2` | `1/Δi` |
| односторонняя 2-го порядка DOE-1 | `(-3, +4, -1) / 2` | `4/Δi` |

**Перенос в UVW.** Для `L_aa = sum_mn T_ma L_mn T_na`:

```text
delta_L_aa = (sum_m |T_ma|) * (sum_n |T_na| * W_n) * e
```

Это консервативная граница худшего случая (worst-case absolute bound), а не
оценка статистической погрешности. Порог считается отдельно в каждой точке
по фактическим схемам `stencil_d`, `stencil_q`, `stencil_0` этой точки.

**Обязательная предпосылка `field_increment_consistency`:**

```text
max_(k, узлы) |[psi - grad_i W'](i, theta) - [psi - grad_i W'](0, theta)|
      / max(psi_delta_scale, psi_delta_floor) <= eps_psi
```

Постоянная по току ошибка экспорта (в том числе в PM-части) здесь сокращается,
ошибка токозависимой части остаётся — именно она определяет достоверность
приращения, на котором построен бюджет `e`. База — нулевой токовый узел того
же `theta`.

### 2.5 Статусы

| Уровень | Условие | Статус |
|---|---|---|
| точка | `L_aa >= delta_L_aa` | `PASS` |
| точка | `L_aa <= -delta_L_aa` | `FAIL` |
| точка | `-delta_L_aa < L_aa < delta_L_aa` | `DIAGNOSTIC` |

| `field_increment_consistency` | P2-N1 |
|---|---|
| `PASS` | `PASS`/`FAIL` по точкам |
| `FAIL` | `NOT_EVALUATED` (точка `FAIL` остаётся `FAIL`) |
| `NOT_EVALUATED` | `NOT_EVALUATED` (точка `FAIL` остаётся `FAIL`) |

Гейт: есть точка `FAIL` → `FAIL` при любом состоянии предпосылок —
отрицательный наклон не скрывается плохой предпосылкой. `PASS` — только если
все точки `PASS`, `field_increment_consistency = PASS`, область полна,
`psi_delta_floor` задан и диапазон B-H доказан; иначе `NOT_EVALUATED` с
перечнем блокеров.

`DIAGNOSTIC` — не FAIL и не подтверждение положительности: численная
неопределённость сопоставима с самим `L_aa`. Гейт определяется худшей точкой, не
средним и не медианой.

### 2.6 Диапазон B-H

FEM-выход пока не содержит `max|B|` по регионам, поэтому N1 сам не доказывает,
что все узлы лежат внутри B-H-огибающей. `PASS` возможен только при
`bh_range_status ∈ {IN_RANGE, LINEAR_MATERIAL}` в манифесте сетки; иначе гейт
`NOT_EVALUATED` с блокером `BH_RANGE_UNPROVEN` (не `PASS` и не
`OUT_OF_BH_RANGE`). `FAIL` остаётся `FAIL` независимо от диапазона.
Добавление `max|B|` в контракт FEM-выхода — отдельная работа.

## 3. P2-N1b — секущая монотонность в UVW (будущее)

Отдельная физическая проверка, не замена N1: явные UVW-состояния
`i_a ∈ {-I, -I/2, 0, +I/2, +I}`, `(i_b, i_c) ∈ {-I, 0, +I}^2`, 12 углов,
секущая `(psi_a(i_a^(k+1)) - psi_a(i_a^k)) / (i_a^(k+1) - i_a^k) > 0` на каждом
интервале. Это 81 уникальное состояние × 12 углов = 972 FEM-кейса — только после
A0–A7, как часть DOE, не POC.

## 4. P2-N2 — дифференциальная взаимность

### 4.1 Определение

Для гладкой co-energy модели `L_inc = ∇²ᵢ W'` симметричен, поэтому в каждой
существующей точке DOE-1 после преобразования `L_UVW = Tᵀ L_dq0 T` проверяются
три независимые пары:

```text
L_UV = L_VU,   L_UW = L_WU,   L_VW = L_WV        (a, b ∈ {U, V, W}, a ≠ b)
```

Диагональ — область N1, здесь не проверяется. Это проверка локального
дифференциального якобиана, а не равенства конечных разностей по разным
траекториям: `Δpsi_a/Δi_b = Δpsi_b/Δi_a` не является универсальным nonlinear
reciprocity condition и как гейт не используется.

N1 и N2 независимы: диагональ может быть положительной при нарушенной
взаимности (N1 PASS, N2 FAIL). N2 не проверяет положительную определённость
всей матрицы — это отдельный возможный гейт, здесь не вводится.

### 4.2 Источник и область

- тот же якобиан DOE-1, что в N1 (§2.2); не независимая FEM-валидация;
- `N2 domain = N1/DOE-1 domain` (§2.3): никаких новых FEM-точек, интерполяции,
  экстраполяции, дополнительных UVW-секущих;
- узел без полной матрицы `L_dq0` — `ROM_DOMAIN_INCOMPLETE`;
- проверка выполняется в UVW после преобразования, включая coupling'и
  `d↔0`, `q↔0` внутри `T`; заранее блок-диагональная структура dq0-якобиана
  не предполагается. Математический факт: `T` ортонормирована, поэтому
  `L_UVW` симметрична ⟺ симметрична `L_dq0`; UVW-форма сохранена для
  единообразия с N1. Тест «симметричный `L_dq0` → симметричный `TᵀLT`» —
  implementation smoke-test преобразования, а не физическая проверка.

### 4.3 Допуск из бюджета ошибки DOE-1 (решение владельца 2026-11-25, вариант A)

`eps_rec`/`L_rec_floor` как frozen-параметры не вводятся: допуск наследуется
из того же бюджета ошибки приращения потока, что в N1 (§2.4). Элемент
`L_mn = ∂psi_m/∂i_n` имеет границу погрешности `e_L,mn = W_n · e` (`W_n` —
вес фактической схемы по оси дифференцирования `n` в данной точке). После
переноса через `T`:

```text
e_L,ab <= (sum_m |T_ma|) * (sum_n |T_nb| * W_n) * e
delta_rec,ab = e_L,ab + e_L,ba
```

Критерий пары: `|L_ab - L_ba| <= delta_rec,ab`. Это консервативная граница
худшего случая, а не статистическая оценка. В реализации сравнение допускает
относительную поправку `1e-12` на шум округления у границы: точное равенство
порогу в floating point физически бессмысленно, и `1e-12` на 9 порядков меньше
самого допуска.

`field_increment_consistency` не является отдельным гейтом N2, но бюджет `e`
обоснован только при её `PASS`: без этого `delta_rec` невычислим и точка
`NOT_EVALUATED` (условие вычислимости допуска, а не повторная проверка поля).

Нормированная величина

```text
eps_rec_ab = |L_ab - L_ba| / max(L_scale, L_floor),
L_scale = max_(узлы, пары a,b) |L_ab|
```

— только диагностика в артефакте, не критерий гейта: `L_scale` считается по
тому же домену, поэтому для гейта была бы circular. `L_floor` для
диагностики не вводится — при нулевом масштабе метрика `NaN` без влияния на
статус.

### 4.4 Статусы

`DIAGNOSTIC` в N2 не вводится: проверка симметрии бинарна по консервативному
допуску.

| Уровень | Условие | Статус |
|---|---|---|
| точка | все три пары `\|L_ab - L_ba\| <= delta_rec,ab` | `PASS` |
| точка | хотя бы одна пара превышает допуск | `FAIL` |
| точка | нет полного якобиана, не-finite `T`/`L`, бюджет `e` недоступен | `NOT_EVALUATED` |

Гейт: есть точка `FAIL` → `FAIL` (нарушение взаимности не скрывается плохими
предпосылками); все точки `PASS` и область полна → `PASS`; иначе
`NOT_EVALUATED` с перечнем блокеров (`field_increment_consistency`,
`psi_delta_floor`, `ROM_DOMAIN_INCOMPLETE`). B-H-статус на N2 не влияет:
взаимность — свойство гладкости модели, а не диапазона материала.

`summary.json` → `poc2_nonlinear.P2_N2`:

  `L_WU_H`, `L_VW_H`, `L_WV_H`, `delta_L_UV_H`, `delta_L_UW_H`,

### 4.6 Обязательные тесты

1. искусственная асимметрия: симметричный `L_dq0` → UVW, изменение одного
   элемента `L_UV += Δ` → `FAIL`; без изменения → `PASS`;
2. граница допуска: `|ΔL| = delta_rec` → `PASS`, `delta_rec + ε` → `FAIL`;

## 5. P2-N3 — cross-scale интегральная согласованность L→psi на масштабе решётки

### 5.1 Определение

N3 — grid-scale cross-scale consistency gate, а не чистый тест exactness.
Локальный якобиан `L`, вычисленный на stencil-масштабе `Δi = 0.05·I_r`,
интегрируется на масштабе базовой решётки и сравнивается с измеренным
изменением потокосцепления:

```text
∫_grid L di  ≈  Δψ_FEM
```

Это принципиально не N2: N2 проверяет локальную взаимность `L_ab = L_ba`,
N3 — что локальный `L` воспроизводит конечное изменение реального `psi` на
существенно большем масштабе. Именно cross-scale переход даёт N3
самостоятельную диагностическую силу. stencil-scale реконструкция запрещена:
она вырождается в телескопическое тождество центральной разности и не имеет
различающей силы.

### 5.2 Формулировка (заморожена решением владельца 2026-11-25)

Базовая решётка DOE-1 — куб `{-0.5, 0, +0.5}³` плюс осевые концы `±1.0`
(нормированные координаты). Для каждой доступной коллинеарной тройки узлов
вдоль оси `a ∈ {d, q, 0}` с шагом `h = 0.5·I_r` (узлы `x−h·e_a`, `x`,
`x+h·e_a` присутствуют как базовые) и каждого компонента `m ∈ {d, q, 0}`:

```text
Δψ_data,m  = ψ_m(x + h·e_a) − ψ_m(x − h·e_a)
Δψ_L,m     = (h/3) [L_ma(x − h·e_a) + 4·L_ma(x) + L_ma(x + h·e_a)]   (Simpson)
r_N3,m     = Δψ_data,m − Δψ_L,m
```

`L_ma = ∂psi_m/∂i_a` — элемент якобиана DOE-1 в узле; интегрирование по
действительному току (амперы). Используются только существующие базовые узлы
и существующий полный `L_dq0`; диагональные точки, интерполяция, новые FEM,
stencil-scale loop, trapezoid и свободный `eps_N3` запрещены. Трапеция
исключена численно: на гладкой синтетике её residual `1.02·10⁻⁴` Wb в 53
раза превышает budget `1.92·10⁻⁶` Wb.

### 5.3 Допуск и его честная семантика

```text
точка (линия × компонент) PASS, если |r_N3,m| <= e; FAIL иначе
```

где `e = eps_psi · max(psi_delta_scale, psi_delta_floor)` — тот же frozen
budget, что в N1/N2, без новых свободных параметров. В реализации сравнение
допускает относительную поправку `1e-12` на шум округления, как в N2.

В контракте фиксируется прямо: `r_N3` содержит как несогласованность
`psi↔L`, так и ошибку численного интегрирования `E_quad = O(h⁵·psi⁽⁵⁾)` на
масштабе `0.5·I_r`. FAIL означает, что ROM на данном grid-scale не может
одновременно быть согласована с локальным якобианом и с измеренным FEM flux
increment в пределах frozen budget — причина может быть в данных, в
недостаточном разрешении решётки или в их комбинации. Таким образом N3
одновременно consistency gate для `psi↔L` и grid-resolution adequacy gate.
Это честнее, чем искусственное разделение составляющих, для которого в
данных нет информации. Контракт, psi_floor, psi_delta_floor и допуск не
подстраиваются под прохождение синтетической фикстуры; фикстура,
нарушающая budget, корректируется или используется как намеренный
boundary/FAIL-случай.

### 5.4 Статусы

`DIAGNOSTIC` не вводится.

| Статус | Семантика |
|---|---|
| `PASS` | grid-scale интеграл локального `L` согласуется с `Δψ` в frozen budget во всех линиях и компонентах |
| `FAIL` | несогласованность превышает budget хотя бы в одной линии/компоненте (причина — `ψ/L`-несогласованность, grid resolution или комбинация) |
| `NOT_EVALUATED` | нет полного набора реальных grid-scale точек, budget недоступен, не-finite данные |

Гейт: есть хотя бы одна точка `FAIL` → `FAIL`; все точки `PASS`, область
полна и `field_increment_consistency = PASS` (бюджет `e` обоснован) →
`PASS`; иначе `NOT_EVALUATED` с перечнем блокеров. PM-поток не вычитается —
N3 работает с полным физическим `psi`, включая coupling с 0-осью. N3 не
проверяет torque, B-H и не меняет их статусы.

### 5.5 Артефакт

`summary.json` → `poc2_nonlinear.P2_N3`, на каждую линию: `theta_e_deg`,
`axis`, `center` (нормированные координаты), `case_id` трёх узлов,
`residual_d_Wb`, `residual_q_Wb`, `residual_0_Wb`, `residual_norm_Wb`,
`tolerance_Wb`, `quadrature_method = SIMPSON`, `grid_step_A`,
`quadrature_indicator_Wb`, `status`.

`quadrature_indicator` — оценочная диагностика квадратурной составляющей
(разность Simpson- и trapezoid-реконструкций), **не** основание для
изменения PASS/FAIL и не вычитание квадратурной ошибки из residual: истинная
ошибка Simpson неизвестна, иначе вариант A незаметно превратился бы в B.

Агрегат: `status`, `worst_case`, `worst_line`, `max_residual_Wb`,
`max_normalized_residual`, `pass_count`, `fail_count`,
`not_evaluated_count`, `domain_status`, `blocking`.

### 5.6 Обязательные тесты

1. quadratic co-energy с симметричным `L` → `PASS`;
2. то же + линейный PM-term → `PASS` (PM не вычитается);
3. нелинейная аналитическая синтетика → `PASS` в пределах budget;
4. искажённый flux в одном stencil-узле → `FAIL`;
5. нарушение reciprocity, видимое на grid-scale → `FAIL`;
6. неполный domain → `NOT_EVALUATED`;
7. отсутствующий budget (`psi_delta_floor`) → `NOT_EVALUATED`;
8. boundary: residual ровно на допуске → `PASS`, выше → `FAIL`;
9. проверка охватывает все три оси и все три компонента `dq0`, включая
   coupling с 0-осью;
10. nonzero `I0` в согласованной модели → `PASS`.
