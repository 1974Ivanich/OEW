# ТЗ: POC-2 nonlinear contract v0.1 — BM1109 OEW-6T

**Назначение:** единственное нормативное место для нелинейных проверок POC-2
(P2-N1, P2-N2, P2-N3). Run Card POC-1 и FEM backend contract содержат только
ссылки на этот документ и не дублируют его математику.

**Ревизии:** v0.1 (2026-11-25) — исходная редакция; (b) 2026-11-25 — порог N1
через бюджет ошибки приращения `e`, перенос через `T`, предпосылка
`field_increment_consistency` (решение владельца).

**Источник:** аудит DOE-1/DOE-2/DOE-2C и решения владельца 2026-11-25: двух
точек `±I` недостаточно ни для симметрии полного якобиана, ни для согласованности
с co-energy, поэтому нелинейный POC-2 разделён на три независимых гейта.

**Границы:**

- линейные строки POC-2 (`TZ_FEM_BACKEND_CONTRACT_V0_1.md`, раздел POC-2) не
  меняются;
- DOE-3 (`tools/bm1109_ctrl.py`) этим документом не затрагивается и физически
  согласованным с OEW-6T не считается до отдельного аудита;
- новые FEM-кейсы этим документом не вводятся: P2-N1 работает на уже
  существующей сетке DOE-1.

## 1. Три независимых гейта

| Гейт | Утверждение | Статус документа |
|---|---|---|
| **P2-N1** | диагональ `L_inc` в UVW положительна: `∂psi_a/∂i_a > 0` | нормативно (§2) |
| **P2-N2** | дифференциальная взаимность `L_inc,ab = L_inc,ba` | не определён (§4) |
| **P2-N3** | согласованность с co-energy на расширенном наборе точек | не определён (§5) |

Гейты не подменяют друг друга: N1 не проверяет взаимность и не проверяет
положительную определённость всей матрицы `L_inc`; собственные значения `L_inc`
после N2 — только диагностика.

## 2. P2-N1 — положительность собственной дифференциальной индуктивности

### 2.1 Определение

Для каждой фазы `a ∈ {U, V, W}`:

```text
L_aa(i_U, i_V, i_W, theta_e) = ∂psi_a/∂i_a |_(i_b, i_c, theta_e)
L_UVW = T^T * L_dq0 * T,   T = Park(theta_e) * Clarke (ортонормальные)
```

`L_dq0 = ∂psi_dq0/∂i_dq0` при фиксированном `theta_e`. PM-поток не вычитается и
знак не определяет: проверяется наклон, а не значение `psi`. Критерий одинаков
для `NO_PM` и `PM`.

### 2.2 Источник данных

- `L_dq0` — строки `process` DOE-1 (`tools/bm1109_doe1.py`): центральная
  разность по FEM-кейсам, на границе `Omega_FEM` — односторонняя 2-го порядка;
  шаг `Δi = deltas[0] * I_r` (по умолчанию `0.05 * I_r`).
- Это не независимый якобиан: повторная конечная разность по тем же
  FEM-данным — проверка реализации (класс `implementation`/`diagnostic`), а не
  подтверждение физики.

### 2.3 Область

- все базовые узлы DOE-1 (33 точки в нормированной сфере × углы плана), в
  которых строка ROM содержит полную матрицу `L_dq0`;
- узел без полной матрицы — `ROM_DOMAIN_INCOMPLETE`; интерполяция и
  экстраполяция запрещены;
- угловая сетка — равномерная по `theta_e` на полном выбранном электрическом
  периоде (по умолчанию 12 точек, шаг 30° эл.). Пока `p` и `theta_e0` не
  подтверждены, соответствие этой сетки механическому периоду — гипотеза:
  результат несёт `angle_grid_status = HYPOTHESIS_P`.

### 2.4 Порог: бюджет ошибки приращения потока

Ревизия 2026-11-25 (b): порог через полный `psi_scale` удалён из N1. Он
масштабировал ошибку постоянным по току PM-потоком и при `psi_pm >> L*I`
делал гейт неразрешимым, хотя `L_aa` от PM не зависит. PM-поток по-прежнему
нигде не вычитается из физического `psi` перед вычислением `L_inc`.

**Ошибка отсчёта** (замороженный бюджет, не подбирается после прогона):

```text
e = eps_psi * max(psi_delta_scale, psi_delta_floor)
psi_delta_scale = max_(theta, k, узлы) |psi_k(i, theta) - psi_k(0, theta)|,  k ∈ {d, q, 0}
```

- `eps_psi = 1e-3` — тот же замороженный допуск; для `field_consistency` и
  нулевого состояния он по-прежнему относится к абсолютному `psi`;
- `psi_k(0, theta)` — нулевой токовый узел DOE-1 при том же `theta`. Это
  определение масштаба ошибки, а не преобразование исходных потокосцеплений;
- `psi_delta_floor` (Wb) обязателен: задаётся `grid --psi-delta-floor` в
  манифесте сетки до серии и не вычисляется `process` из результата; нет
  значения — `NOT_EVALUATED`.

**Ошибка производной по оси `n`.** Для `L_n = sum_k w_k psi_k / Δi` при
`|δpsi_k| <= e` граница `δL_n <= (sum_k |w_k| / Δi) * e`:

| Схема по оси `n` (фактическая в данной точке) | Веса | `W_n` |
|---|---|---|
| центральная | `(-1, +1) / 2` | `1/Δi` |
| односторонняя 2-го порядка DOE-1 | `(-3, +4, -1) / 2` | `4/Δi` |

**Перенос в UVW.** Для `L_aa = sum_mn T_ma L_mn T_na`:

```text
delta_L_aa = (sum_m |T_ma|) * (sum_n |T_na| * W_n) * e
```

Это консервативная граница худшего случая (worst-case absolute bound), а не
оценка статистической погрешности. Порог считается отдельно в каждой точке
по фактическим схемам `stencil_d`, `stencil_q`, `stencil_0` этой точки.

**Обязательная предпосылка `field_increment_consistency`:**

```text
max_(k, узлы) |[psi - grad_i W'](i, theta) - [psi - grad_i W'](0, theta)|
      / max(psi_delta_scale, psi_delta_floor) <= eps_psi
```

Постоянная по току ошибка экспорта (в том числе в PM-части) здесь сокращается,
ошибка токозависимой части остаётся — именно она определяет достоверность
приращения, на котором построен бюджет `e`. База — нулевой токовый узел того
же `theta`.

### 2.5 Статусы

| Уровень | Условие | Статус |
|---|---|---|
| точка | `L_aa >= delta_L_aa` | `PASS` |
| точка | `L_aa <= -delta_L_aa` | `FAIL` |
| точка | `-delta_L_aa < L_aa < delta_L_aa` | `DIAGNOSTIC` |

| `field_increment_consistency` | P2-N1 |
|---|---|
| `PASS` | `PASS`/`FAIL` по точкам |
| `FAIL` | `NOT_EVALUATED` (точка `FAIL` остаётся `FAIL`) |
| `NOT_EVALUATED` | `NOT_EVALUATED` (точка `FAIL` остаётся `FAIL`) |

Гейт: есть точка `FAIL` → `FAIL` при любом состоянии предпосылок —
отрицательный наклон не скрывается плохой предпосылкой. `PASS` — только если
все точки `PASS`, `field_increment_consistency = PASS`, область полна,
`psi_delta_floor` задан и диапазон B-H доказан; иначе `NOT_EVALUATED` с
перечнем блокеров.

`DIAGNOSTIC` — не FAIL и не подтверждение положительности: численная
неопределённость сопоставима с самим `L_aa`. Гейт определяется худшей точкой, не
средним и не медианой.

### 2.6 Диапазон B-H

FEM-выход пока не содержит `max|B|` по регионам, поэтому N1 сам не доказывает,
что все узлы лежат внутри B-H-огибающей. `PASS` возможен только при
`bh_range_status ∈ {IN_RANGE, LINEAR_MATERIAL}` в манифесте сетки; иначе гейт
`NOT_EVALUATED` с блокером `BH_RANGE_UNPROVEN` (не `PASS` и не
`OUT_OF_BH_RANGE`). `FAIL` остаётся `FAIL` независимо от диапазона.
Добавление `max|B|` в контракт FEM-выхода — отдельная работа.

### 2.7 Артефакт

`summary.json` → `poc2_nonlinear.P2_N1`:

- на каждую точку: `case_id`, `phase`, `theta_e_deg`, `I_U_A`, `I_V_A`,
  `I_W_A`, `L_aa_H`, `delta_L_H`, `stencil_d`, `stencil_q`, `stencil_0`
  (`central`/`fwd2`/`bwd2`), `status`;
- агрегат: `L_min_H`, худшая точка (фаза, угол, полный токовый state),

  `field_increment_consistency` (статус и значение), `blocking`,
  `angle_grid_status`, `bh_range_status`.

### 2.8 Односторонние узлы

Закрыт ревизией (b): вес схемы входит в `W_n` (§2.4), отдельного множителя нет.

## 3. P2-N1b — секущая монотонность в UVW (будущее)

Отдельная физическая проверка, не замена N1: явные UVW-состояния
`i_a ∈ {-I, -I/2, 0, +I/2, +I}`, `(i_b, i_c) ∈ {-I, 0, +I}^2`, 12 углов,
секущая `(psi_a(i_a^(k+1)) - psi_a(i_a^k)) / (i_a^(k+1) - i_a^k) > 0` на каждом
интервале. Это 81 уникальное состояние × 12 углов = 972 FEM-кейса — только после
A0–A7, как часть DOE, не POC.

## 4. P2-N2 — дифференциальная взаимность

требование гладкой монотонной B-H.
