# FINDING: одна точка сэмпла тока не покрывает сектора 0/1/4/5

Дата: 2026-10-31. Автор: агент (ПК-3). Стенд: Nucleo-G474RE + 2× STEVAL-IPM20B.

## Наблюдение (измерено)
- Счётчик `stale` (циклы с нулевой реконструкцией тока) за прогон RUN: **4200 за ~5.7 с
  ≈ 14 % циклов FOC** (5 кГц). Лог `run_stale_20261015.log`.
- Разложение по секторам (из того же лога):
  ```
  sector 0: +1128   sector 1: +852   sector 4: +797   sector 5: +1415
  sector 2:   +5    sector 3:   +3          ← чисто
  ```
  **99.8 % потерь — в секторах 0/1/4/5; сектора 2/3 чисты.** Внутри сектора 0:
  `window=1` → 0 нулей за 8 кадров, `window=0` → 1128.

## Причина (подтверждена кодом)
Кадр строится в `adc_commit_injected_frame()` (`src/adc.c`): читает инжектированный
результат `ADC1->JDR1` (idc1), `ADC2->JDR1` (idc2) и считает
`calc_dc_shunt_ma(raw, offset)` — **ноль тогда и только тогда, когда `raw == offset`**,
то есть сэмпл физически попал в момент нулевого тока через DC-link шунт.

Точка сэмпла **одна и фиксированная**:
- `adc_jsqr()` → `JEXTSEL = TRGO`, `JEXTEN = rising edge` (нарастающий фронт TRGO);
- `adc_set_sample_time()` → `SMPR = 7`, единый для всех каналов, без per-sector.

`sector`/`window` выбираются в `CurrentMap_SelectNextContext()` (`src/current_map_selector.c`)
по границам `region.mu_min/mu_max` и передаются в `ADC_SetExpectedWindow()` → это
**только метка** реконструкционной матрицы `recon[sector][window]` и валидности;
**сэмпл они не двигают**. Поэтому в секторах, где фиксированный момент попадает в
нулевой вектор (оба шунта ≈ 0), реконструкция даёт ноль, и никакая матрица это не
исправляет: `0 × x = 0`.

## Вывод
Дефект **тайминга сэмпла**, структурный: при одной точке сэмпла OEW-двухшунтовая
топология не покрывает все 6 секторов (4 из 6 попадают в нулевой вектор). Поле
`window` (2 на сектор) в карте указывает на задуманные **две** точки сэмпла, но вторая
в прошивке **не реализована** — ADC берёт один инжектированный фронт.

## Следствие
14 % циклов управления работают на устаревшем токе (фикс `19be192` удерживает последний
валидный вектор). Это систематическая ошибка контура и источник срыва момента; мешает
и будущей slip-модели после измеренного `Tr`.

## Исключено
- Гонка с JEOS (потери были бы равномерны по секторам) — **исключено**.
- Данные карты (матрица не может сделать ноль ненулевым) — **исключено**; identity
  карты сходится по 11 полям.
- Энкодер, шунты, масштаб тока — проверены отдельно, исправны.

## Рекомендация
ТЗ на правку тайминга сэмпла (вторая точка сэмпла либо обоснованный сдвиг); первым
пунктом — разрешить развилку «вторая точка vs сдвиг единственной» (анализ/осциллограф).
