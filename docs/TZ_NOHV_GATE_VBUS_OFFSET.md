# ТЗ: гейт no-HV по (raw_vbus - offset)

Ветка: `ai2/nohv-gate-vbus-offset` (от `origin/main` `103c17b`). Объект: host-инструменты
стенда, а не прошивка (порог `PROTECT_VBUS_MIN_MV` — отдельная единица, U1).

## 1. Причина

Канал VBUS имеет аддитивное смещение порядка 20..23 сырых отсчётов (~2.2 В), которое
измеряется командой `cv` при нулевом входе (U1: `@ADC:CV:OK:offset_vbus=NN`).
Критерий отсутствия высокого напряжения в инструментах стенда до сих пор считался по
**сырым** отсчётам:

```text
median(raw_vbus) <= 9      # при смещении 22 недостижим в принципе
max(raw_vbus)    <= 200
```

При приборно-подтверждённом нуле на шине канал даёт 20..23 отсч, поэтому такой гейт
даёт FAIL на исправном стенде (зафиксировано сессией 28.09.2026).

## 2. Контракт

```text
offset = измеренное смещение канала VBUS (cv при 0 В), в сырых отсчётах
критерий: median(raw_vbus) - offset <= 9
          max(raw_vbus)    - offset <= 200
```

* **Смещение обязательно.** Без него статистический гейт no-HV **не проходит**
  (fail-closed): в результате появляется отдельный признак `preflight_vbus_offset_declared`,
  а сам гейт возвращает `false`. Молчаливое `offset = 0` запрещено: это дало бы FAIL
  на исправном стенде и PASS на шине под напряжением при большом смещении.
* Смещение — только измеренная величина, не оценка и не «типичное значение».
* Источник смещения: `--vbus-offset N`. В `bench_test2_preflight` дополнительно
  допускается разбор строки `@ADC:CV:OK:offset_vbus=N` из UART-транскрипта, если она
  там есть.

## 3. Что сделано в этом пакете

| файл | изменение |
|---|---|
| `tools/bench_test2_capture.py` | `evaluate_test(..., vbus_offset_raw=...)`; критерий медианы и жёсткого предела считается по `raw - offset`; признак `preflight_vbus_offset_declared`; смещение в метаданных вердикта и в `expected_nohv_contract`; тот же критерий в боевом пути запуска; CLI `--vbus-offset`; хелпер `vbus_offset_from_texts()` для разбора `@ADC:CV:OK` |
| `tools/bench_test2_preflight.py` | `validate_uart_responses(..., vbus_offset_raw=...)`; критерий по `raw - offset`; при отсутствии флага смещение берётся из транскрипта, иначе гейт не проходит; текст критерия и детали обновлены; CLI `--vbus-offset` |
| `tests/test_bench_test2_capture.py` | хелпер передаёт смещение 0 (синтетика уже на нуле); новые классы: `VbusOffsetGateTests` (fail-closed без смещения, FAIL на сырых стендовых 22 отсч, PASS при смещении 22, смещение в вердикте) и `VbusOffsetParsingTests` (разбор строки `cv`) |
| `tests/test_bench_test2_preflight.py` | offline-вызовы передают явное смещение 0 |

## 4. Что осознанно не сделано

* **Терминальная проверка** `terminal_raw_vbus_nohv` (`status.raw_vbus <= 9`) не изменена:
  она относится к инжектированному fault-сценарию, а не к статистическому доказательству
  нуля, и её перевод на смещение — отдельное решение с собственным доказательством.
* **Observation allow-list preflight** не расширен командой `cv`: сейчас смещение
  приходит флагом. Если нужно, чтобы строка калибровки попадала в транскрипт автоматически,
  расширение allow-list оформляется отдельно (это же снимает необходимость в флаге).
* Остальные носители того же критерия (критерий обязан совпадать во всех):
  `tools/bench_test3_capture.py`, `tools/bench_test3_preflight.py`,
  `tools/mopt0_capture.py`, `tools/bench_test2_rerun_verdict.py` и их тесты,
  а также тексты `tools/bench_test2_capture.md`, `tools/bench_test2_preflight.md`,
  `tools/mopt0_capture.md`, `docs/MOPT0_PREFLIGHT_PC3.md`. Это следующие единицы той же
  серии: правка механическая, но каждая единица — свой SHA и своя приёмка.
* Прошивка не затрагивается: смысл `vbus_mv` меняет U1, здесь — только критерий host-гейта.

## 5. Критерий приёмки

1. `py -3 -m pytest tests/test_bench_test2_capture.py tests/test_bench_test2_preflight.py -q` — зелёный.
2. Полный `pytest tests` — без новых падений (кроме известного окружностного `test_tao3104a_unit.py`
   при отсутствии `numpy` в локальном интерпретаторе; в CI он есть).
3. CI `build-test` — зелёный.
4. Поведенческие утверждения: без смещения гейт не проходит; при смещении 22 и медиане 22 —
   проходит; при смещении 0 те же 22 отсч — не проходят.
