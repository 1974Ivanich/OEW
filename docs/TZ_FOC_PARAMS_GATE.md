# TZ: гейт параметров двигателя в `FOC_Start()`

## 1. Проблема

`FOC_Start()` проверяет clock/fault, готовность карты реконструкции,
initial sample context и валидность offset'ов — но **ничего** не проверяет
о параметрах, на которых живут observer и токовые контуры.

`motor_L_uH` по умолчанию:

```c
#define FOC_DEFAULT_L_UH 100   /* 100 мкГн (дефолт; уточнить автотюном!) */
```

Валидатор автотюна (`src/autotune_math.h`):

```c
#define AT_MATH_SANE_LS_MIN_UH 500
#define AT_MATH_SANE_LS_MAX_UH 500000
```

**100 мкГн лежит вне собственного диапазона проекта.** Значение, которое
`AT_SaneLs()` отверг бы как мусор, допускается в `FOC_Start()` без всякой
проверки.

Дефект формулируется так: *в FOC допускается индуктивность, которую система
сама объявляет невалидной.*

Последствия при старте с дефолтом:

- `foc_lsigma_uH = motor_L_uH` (`FOC_Init`, L287) → observer на `Lσ = 100 мкГн`;
- `BEMF_Init(&observer, motor_R_mOhm, foc_lsigma_uH, ...)` (`FOC_Start`, L549);
- `FOC_ComputePIGains(r, l, vdc, ...)` → Kp/Ki из неверной L/R.

Для ACIM-стенда это не «чуть хуже разгон»: EMF-observer на Lσ, заниженной в
десятки раз, даёт систематическую ошибку потока, а PI-контуры рассчитаны на
другую постоянную времени.

Достигаемость реальна: автотюн не требует mapcap, поэтому путь
«прогнал `ch/chu/chv/chw` → загрузил карту → стартовал, автотюн не делал»
полностью легален и нигде не блокируется.

## 2. Отклонённое решение: гейт по `FOC_IsParamsApplied()`

Обсуждался вариант `if (!FOC_IsParamsApplied()) return ...`. **Отклонён, не
возвращать.**

Флаг взводится в двух местах (`src/foc.c`):

```c
int FOC_SetMotorParams(...)  { ...; params_applied = 1; }   /* L470 */
int FOC_SetPIGains(kp, ki)   { ...; params_applied = 1; }   /* L481 */
```

`FOC_SetPIGains` — ручная команда GUI (`p=`), она ставит флаг, **не трогая
`motor_L_uH`**. Одна команда `p=100,10` обходит флаг-гейт, и FOC стартует с
дефолтной L. Флаг означает «кто-то что-то записал», а не «параметры измерены».

Гейт по флагу создал бы ложное ощущение закрытия. `params_applied` остаётся
тем, чем является — индикатор для GUI (`cli.c:210`, `@AP:%d`). Делать из него
interlock нельзя: это смешение диагностики и защиты.

## 3. Решение: проверка значения по существующему валидатору

В `FOC_Start()`, после гейта initial context и **до** `FOC_Init()` /
`ADC_SetControlAdmission()`:

```c
if (motor_L_uH < AT_MATH_SANE_LS_MIN_UH || motor_L_uH > AT_MATH_SANE_LS_MAX_UH) {
    return FOC_START_PARAMS_NOT_MEASURED;   /* -6 */
}
```

Свойства:

- не обходится через `p=` — проверяется именно L;
- использует существующий валидатор, нового источника истины нет;
- по Rs ничего не ломает: дефолт `FOC_DEFAULT_R_MOHM = 13000` проходит
  `AT_MATH_SANE_RS_*` (10…100000) и действительно измерен — ложных отказов нет;
- fail-closed: PWM/EN/ADC не трогаются, `assert_power_path_off()` выполняется.

### Порядок относительно других гейтов

Гейт ставится **после** map/initial-context гейтов, **до** `FOC_Init()`:

- map-гейт остаётся первым — контракт Gate 1 в
  `tests/foc_start_gate_test.c` не меняется;
- до `FOC_Init()` — иначе отказ происходит уже после инициализации observer
  (сейчас при первом старте `BEMF_Init` вызывается дважды: в `FOC_Init` и в
  `FOC_Start`; гейт ниже L542 этого каскада не видит).

## 5. Вне объёма (зафиксировано, не делается)

**Tr = 60 мкс из автотюна.** Проверено: `FOC_SLIP_POLICY_MIN_TR_US = 1000`,
`FocSlipPolicy_ComputeDelta()` при `Tr < 1000` возвращает 0 → zero-slip,
θe только с энкодера. Поведение **fail-safe**, это не safety-дыра.
Остаток — наблюдаемость: в телеметрии не видно, что slip-модель выключена.
Отдельная задача (флаг в `@FOC`-строку), приоритет ниже.

**Guard Lσ в `FOC_SetMotorParams` проверен и работает корректно:** при
Lm=32936, Tr=60, Rr=951796 получается `Lσ = Ls − Lm²/Lr < 0`, условие
`lsigma >= l_uh/10` не выполняется, `foc_lsigma_uH` остаётся = Ls. Мусор не
пропускается.

**Если когда-нибудь понадобится «измерено vs вписано руками»** — правильный
путь: отдельный флаг, который взводит только путь публикации автотюна
(`AT_VALID_*` mask), а не `FOC_Set*`. Сейчас не нужно: проверка значения
закрывает риск полностью.
