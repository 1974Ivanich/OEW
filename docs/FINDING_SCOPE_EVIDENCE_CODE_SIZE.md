## Вывод

При 500 мВ/дел одна выборка = 108 мА, а вся измеряемая величина — 0.1…0.7 А, то есть
**1…5 кодов на импульс**. Средние по окнам — квантованный шум (±1 код на сигнале
400 мА = ±27 %), а не измерение. Один код (108 мА) сравним с самим гейтом KCL ingest'а
(`kcl_limit_ma` = 100 мА — допуск консистенции фаз), то есть квантование одного
канала съедает этот допуск целиком. Записать это в `scope_region_*.csv` как `ref_u_ma`
с `scope_qualified=1` — значит выдумать опору; слой `scope/` остаётся на
`--scope-waiver` (решение G0 v4, `docs/templates/grid_campaign_boar/README_BOAR_CAPTURE_PC3.md` §4b).

Что этот же файл честно несёт: **независимое (вторым прибором) подтверждение
длительности burst'а** — 1.667 мс против документированных 8 × 200 мкс. Тайминговое
свидетельство принимается, аналоговые каналы того же файла — нет.

## Почему шкалу нельзя поднять

- Шаг сетки задаётся прибором (25 кодов на деление), а не настройкой: строка `Depth: F(8-bit)`
  на экране — статус, а не управление, и `:ACQuire:DEPMEM?` на этой прошивке не отвечает.
- Мелкая шкала (100…200 мВ/дел) недоступна: ACS712 сидит на 2.65 В постоянки, а
  вертикальный сдвиг прибора нормируется в делениях и до базовой линии не достаёт.
- AC-связь отклонена: она снимает и постоянную составляющую тока, то есть ту самую
  величину, которую калибровка слоя вычитает как `v0`.

## Открытый вопрос (не проверен)

У прибора есть усреднение: `:ACQuire:MODE?` = `SAMPle`, `:ACQuire:AVERage:NUM?` = 4.
Если экспорт сохраняет усреднённое до округления до 8 бит, шум входа работает как
дизеринг и под-кодовое разрешение восстанавливается (108/√N мА). Проверяется без
энергии: включить Acquire → Average (N=64), экспорт любого сигнала, и посмотреть,
ушли ли значения с сетки 20 мВ. Если не ушли — рычаг закрыт, вопрос снят.

## Решение: щуп на INA240A1 (не изменяет `src/`)

На стенде есть 3× INA240A1 (gain 20 В/В, CM −4…80 В, enhanced PWM rejection) и
3 шунта с маркировкой `R100` = 0.1 Ом. Схема на одну фазу: шунт в разрыв фазного
провода, измерительная пара с выводов, `VOUT = 0.5 В + 2·I(А)` (REF1≈1.0 В, REF2=GND).

- номинал шунта ограничен с двух сторон: `20·R·Imax ≤ 4 В` ⇒ R ≤ 0.28 Ом; `20·R ≥ 0.2 В/А` ⇒ R ≥ 0.05 Ом;
- при R = 0.1 Ом sens = **2000 мВ/А** ⇒ на 500 мВ/дел код **10 мА**, на 200 мВ/дел — 4 мА;
- выход при нулевом токе стоит на 0.5 В, а не на половине питания — мелкая шкала
  становится доступной **без AC-связи**, измерение остаётся абсолютным;
- три ампера → CH1/CH2/CH3 = U/V/W, PB6 → CH4; шина с CH3 снимается, она есть в логах (`vbus`).

Приёмка щупа: (1) шина снята, PWM off — все три канала на своём REF (это же даёт `v0`
каждого канала); (2) шина 60 В, PWM off — выходы не сдвинулись (проверка CMRR);
(3) одна энергетизированная точка — сверка с шунтами МКУ, которая калибрует фактическое
усиление щупа (винтовая клемма двухвыводного шунта даёт масштабную ошибку от контактного
сопротивления).

Калибровка щупа пишется отдельным файлом того же формата
(`{sensors: {U/V/W: {v0_mv, sens_mv_per_a}}}`), `acs712_calibration.json` не изменяется.

## Отвергнутый кандидат

ADS1115 (16 бит) — максимум 860 SPS = **1.2 мс на выборку** против окна 200 мкс:
усредняет ~6 окон и опоры «по окну» не даёт. Годится только для стационарной
характеризации (другой метод, отдельное ТЗ).
