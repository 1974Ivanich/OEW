# Диагностический чек-лист: Devin CLI на ПК-2
# Выполнять по порядку, результаты записывать (что вывела каждая команда).

## Шаг 1. Установлен ли Devin CLI?
node --version            # нужно >= 18
npm --version
devin --version           # если "command not found" → Devin НЕ установлен

## Шаг 2. Если не установлен — поставить
npm i -g @devin/cli       # или: npm i -g @devinai/cli (проверить актуальное имя)
devin --version           # проверить, что появился

## Шаг 3. Логин (интерактивный, нужен человек!)
# ВАЖНО: первый запуск devin открывает browser для авторизации.
# Запускать вручную в терминале, НЕ через агента/скрипт:
devin                     # REPL — если попросит логин → пройти device-flow
# Если логин уже был — REPL просто стартует. Выйти: /exit

## Шаг 4. Проверка авторизации (главный тест!)
devin -p "Ответь ровно одним словом: ок"
# ОЖИДАЕМ: модель отвечает и процесс завершается (exit 0)
# ПРОБЛЕМЫ:
#   "Login required" / "Unauthorized" / "401" → логин не сохранён → повторить Шаг 3
#   Зависает > 60 c без вывода → нужен PTY-режим (см. Шаг 5)
#   Ошибка про кредиты/лимит → проверить аккаунт Devin (подписка/кредиты)

## Шаг 5. Проверка PTY-зависимости (если Шаг 4 завис)
# Devin — интерактивное приложение, без псевдо-терминала (PTY) может висеть.
# Из агента Hermes запускать ОБЯЗАТЕЛЬНО так:
#   terminal(command="devin -p 'задача'", pty=true, background=true)
# Вручную проверить:
script -q -c "devin -p 'Ответь одним словом: ок'" /dev/null
# (в git-bash: winpty devin -p "Ответь одним словом: ок")

## Шаг 6. Работа внутри репозитория (контекст проекта)
cd C:/ST/boyler/Motor     # или путь проекта на ПК-2
git status                # убедиться, что это git-репозиторий (Devin читает AGENTS.md)
devin -p "Прочитай AGENTS.md и скажи, какой это проект, одним предложением"

## Шаг 7. Проверка кредитов/тарифа
# Devin CLI работает на кредитах аккаунта (не бесплатно, как Koda).
# Проверить в веб-панели Devin: https://app.devin.ai → Usage / Billing
# или в CLI: devin /credits (если есть такая команда)
# Если кредиты = 0 → задачи будут падать с ошибкой лимита.

## Шаг 8. Реальная задача (пробный прогон)
cd C:/ST/boyler/Motor
git pull                  # правило двух ПК: сначала pull!
devin -p "Найди в src/foc.c функцию FOC_Run и одним предложением опиши, что она делает"
# ОЖИДАЕМ: осмысленный ответ про FOC, без ошибок
# После: git status / git diff — убедиться, что Devin ничего не сломал

## ЧТО ПРИСЛАТЬ Hermes (ПК-1) после выполнения
# 1. Вывод `devin --version`
# 2. Вывод Шага 4 (успех или текст ошибки)
# 3. Если ошибка — её точный текст
# 4. Если зависание — сколько секунд ждали и что было в выводе

## ВЕРОЯТНЫЕ ПРИЧИНЫ (если что-то не работает)
# 1. "Login required" → логин не выполнен/слетел → Шаг 3
# 2. Зависание → нет PTY → Шаг 5 (или devin ждёт интерактивного ввода)
# 3. Ошибка кредитов → кончился баланс Devin → Шаг 7
# 4. "command not found" → не установлен/не в PATH → Шаг 2
# 5. Таймаут сети → Devin API может быть недоступен из РФ без VPN → проверить VPN
