# ПК-3, Record A: локализация источника TIM8 BIF при 60 В

**Первоисточник протокола — `docs/RUNCARD_PD2_BKIN_60V.md`.** Этот файл — операционная
обёртка (чек-лист + что заполнить). При любом расхождении между файлами действует run-card.

**Цель:** одним физическим прогоном отличить «PD2 реально получает короткий FAULT-импульс»
от «BIF взводится без наблюдаемого фронта на BKIN». Классифицировать по H1/H2/H3.

**Прошивку не менять.** Образ = `87169b3` (как в логах сессии 5). Никаких правок
`pwm.c`/`foc.c`/`protect.c`, никакого BKF. Правки `src/` до закрытия Record A запрещены.

## Ключевые ограничения (не обсуждаются в рамках прогона)

- **BKF на TIM8 не активен** (запись `0xF<<12` в `AF1` — это `BKCMP3P/BKCMP4P/ETRSEL`,
  а фильтр в `BDTR[19:16]`; доказательство — `bd=9CC0/1CC0` во всех `@BRK`). Отчёт
  `SESSION_5_BKF_SD.md` с выводом «устранены фильтром» **ошибочен** — см. KB v3.9 §3.2.
- Класс события обязан быть **A** (break в работе ШИМ: `ce≠0`, `cnt≠0`). Класс B
  (`ce=0,0`/`cnt=0,0`) — артефакт пуска, прогон неинформативен.
- Основной прибор — **аналоговый осциллограф TAO3104A**; LA — цифровой дубль. Порог LA
  (~1.6 В) близок к порогу GPIO, «чисто на LA» не доказательство.

## Вход (записать в `metadata.txt` до начала)

- [ ] Образ подтверждён: коммит/SHA256 прошитого bin; `p?` — `CCER=0`, `MOE=0`, `FAULT=0`.
- [ ] `bd` из `@BRK`/dump: ожидаем `9CC0`/`1CC0` (BKF=0) — иначе образ не тот.
- [ ] Прозвонка **минус DC-link ↔ земля корпуса TAO3104A** (оммы). Без подтверждения
      CH3 к минусу шины **не подключать** (иначе КЗ по земле осциллографа).
- [ ] Точка CH3 — та же, что `sd_cap4` (`A3 VBUS`), щуп 10:1. На PC4 не вешать (делитель 1:125).

## Шаг 0 — подтяжка PD2 (без высокого напряжения)

См. run-card, «Шаг 0». Итог (число вольт + вердикт) обязателен в `metadata.txt`.

| Результат | Действие |
|---|---|
| PD2 (TP23) ≈ 3.3 В при обесточенной STEVAL-2 | идём к прогону A |
| PD2 < 2 В или «плывёт» | прогон **запрещён**: сначала чинить шлейф/подтяжку |

## Разводка (полная таблица — в run-card)

TAO3104A: **CH1 = PD2 (у ножки MCU, TP23) · CH2 = SD2 (сторона STEVAL-2) · CH3 = VBUS
(DC-link, 10:1) · CH4 = SD1 (PB12-сторона)**.

> ⚠️ **Tok не измеряется** ни на одном канале (CH4 занят SD1). H1 подтверждается только
> косвенно (совпадение CH1/CH2). Вопрос 5-го канала — оператору, см. «Вопросы по стенду».

LA (fx2lafw), ровно 4 сигнала `D0–D3`: **D0 = PB6 (TRIG) · D1 = PD2 · D2 = SD2 · D3 = PC6
(TIM8_CH1, маркер «ШИМ жив»)**. 24 МГц только в ≤8-канальном режиме; каналы сверх четырёх
не включать. `EN1/EN2` (PB4/PB5) не брать.

## Прогон A — single-shot по фронту (обязан дать класс A)

1. 60 В, `f` (снять latch), дождаться чистого состояния.
2. Осциллограф: триггер **falling edge на CH1 (PD2)**, single-shot, весь буфер.
3. `vf=40`, UART-лог в файл параллельно.
4. Сохранить waveform + uart-лог, конфигурацию не трогать.

Зафиксировать: уровень провала PD2, длительность, положение относительно CH2/CH3/CH4,
`@BRK` (sr/bd/ce/cnt) — класс A или B.

## Прогон B — запуск по моменту команды (обязателен, даже если A сработал)

Нужен, чтобы «PD2 чист» не стало ложным: без привязки к моменту команды нельзя отличить
«импульса не было» от «не туда смотрели».

1. LA: триггер **rising edge на D0 (PB6)**, pre 1–2 мс, post 20–50 мс.
2. Порядок: `f` → вооружить LA и TAO → `vf=40`. Фронт PB6 возникнет сам (внутри обработки
   команды, `src/cli.c:451`).
3. Свести по времени: PB6-фронт ↔ `@TRIG:tick` ↔ последняя активность ШИМ на D3 ↔ `@BRK`.

## Вердикт (только эти формулировки, см. decision tree run-card)

| Вердикт | Признак |
|---|---|
| **H1 Real OCP** | CH1 провал + CH2 провал одновременно (косвенно: Tok не меряется) |
| **H2 Glitch/EMI** | CH1 провал, CH2 чист |
| **H3 No-drive BIF** | CH1 чист при корректно покрытом событии |
| **НЕ вердикт** | класс B (`ce=0,0`/`cnt=0,0`) или окно не покрывает событие (нет `@TRIG:tick`-привязки / гибели ШИМ на D3 / `@BRK` в том же прогоне) — повторить, выводы не делать |

## Критерии немедленного аборта

`FAULT≠0` до команды · SD держится низким > ~1 с · VBUS по прибору ниже защитного порога ·
дым/нагрев/странный звук · непрерывный `commit=0`. Остановка: `vf=0` → снять питание.

## Вопросы по стенду (уточнить ДО прогона)

1. **Tok**: TAO3104A 4-канальный, свободных аналоговых каналов нет. Варианты: брать Tok на
   LA `D4` (в ≤8-канальном режиме 24 МГц это допустимо, но LA видит только «есть/нет», не
   амплитуду) или менять CH4 SD1→Tok. Без Tok H1 остаётся косвенной. Решение — записать в
   `metadata.txt`.
2. **Точка подтяжки SD2/PD2** по схеме платы (для SD1 известен R28, для SD2 в репозитории
   не указан).
3. **Номер разъёма PC6** на колодке Nucleo — взять из схемы платы и прозвонить до подключения.
4. Единообразие земли: минус DC-link ↔ ПК ↔ корпус TAO (пункт входа выше).
