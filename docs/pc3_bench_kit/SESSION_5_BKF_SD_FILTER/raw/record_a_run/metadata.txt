  Correlated run: breakdiag confirms src=TIM1 while scope on SD1 does not
  trigger. This strongly indicates that the TIM1 break is NOT caused by a
  visible external low pulse on SD1/PB12. The remaining possibilities are:
    - a sub-microsecond (<~100 ns) external spike that is below the scope/ LA
      detection window (unlikely to be a real IPM fault pulse);
    - an internal break path to TIM1_BKIN (e.g. COMPx_OUT, although BKCMP
      is not configured in the current firmware);
    - an EMI-induced BIF that does not appear as a sustained low level on
      the monitored SD1/PB12 node.
