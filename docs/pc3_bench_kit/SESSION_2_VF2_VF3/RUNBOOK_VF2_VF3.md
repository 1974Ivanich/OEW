# Runbook VF-2A → VF-2B → VF-3 (первый физический прогон, VBUS 60 В)

Машина: **ACIM**, pp = **3** (шильдик «6 полюсов»), boost 15 %, rated 50 Гц (дефолты;
`vfk=15,50` — no-op, но можно задать явно).

## 0. Предполётная проверка

| Что | Как | Ожидание |
|---|---|---|
| Образ | energize-сборка `-DOEW_HS1_COMMISSIONING_RELEASE=1` | иначе `vf=` → rc=−8 (`pwm_enable/interlock`) |
| Полюса | `pp=3` | `p?` в этом образе — статус PWM, а не полюса; иначе `n↔f` и `vmag` врут |
| Latch после подачи 60 В | `f`, затем в `@FOC` `FAULT=0:FAULT_R=0` | иначе `vf=` → `rc=-3` (fault latched); на стенде наблюдалось `FAULT_R=18` |
| Образ на плате | уже прошит и сверен побайтово (readback = `96e97470…`) | перепрошивать не нужно; `c`/`ch`/`iv` не запускать (fail-closed) |
| Логирование | `vflog=40` | 25 Гц, строка 40 мс |
| Шина | 60 В, **общая** для обоих инверторов | иначе дифференциальный тест невалиден |
| Защита | EM_STOP (SD1/SD2) под рукой, аппаратный | — |
| Осциллограф | CH1 — выход инвертора 1 фазы U, CH2 — выход инвертора 2 **той же фазы**, math CH1−CH2, DC | — |

## 1. VF-2A — инверсия TIM8 / дифференциал (d → (2d−1)·Vbus)

**Статически это сегодня не командуется:** `bench=` форсирует no-output
(`PWM_BenchAperture*`, `src/pwm.c:505-599`), а `vf=0` — это **стоп**, не «нулевая цель»
(`src/cli.c:331`). Поэтому VF-2A выполняется на медленном векторе, и его таблица
воспроизводится точками:

```text
vf=50          (2.5 Гц при pp=3 → vmag = 100*2.5/50 + 15 = 20 %)
  ↓ ~10 с (рампа экспоненциальная, tau = 2000 мс)
читать @VFLOG: du/dv/dw, vmag, commit
```

| Точка в логе | Ожидание на обмотке (CH1−CH2, mean) |
|---|---|
| `du ≈ 50 %` (переход) | **≈ 0 В** |
| `du ≈ 40 %` (минимум) | **−12 В** |
| `du ≈ 60 %` (максимум) | **+12 В** |
| знак | совпадает со знаком `(du − 50 %)` |

**Докажет:** второй инвертор действительно инвертирует PWM (OCxM=7 при тех же CCR),
т.е. дифференциальный закон OEW на реальном железе.
**Не докажет:** ничего про момент, ток и качество замкнутого контура.

## 2. VF-2B — реальный V/f-вектор

```text
vf=40          (2 Гц, vmag 19 %, V_фазы peak 11.4 В, duty 40.5…59.5 %)
  ↓ ~10 с
```
Сверить: `du/dv/dw` из лога ↔ осциллограмма; период огибающей duty = 1/f_e (0.5 с при 2 Гц);
фазовый сдвиг между du/dv/dw = 120° эл.; `vmag` = амплитуда огибающей.
**Докажет:** трёхфазный вектор формируется корректно (частота/фаза/амплитуда).

## 3. VF-3 — устойчивое вращение, ступени

```text
vf=40 → ~10-15 с → vf=100 → ~10-15 с → vf=200 → ~10-15 с → vf=300 → стоп
```

| команда | f_e (уст.) | vmag | V_фазы peak | I_peak (\|Z\|, Rs=15 Ω, Ls=20 мГн) |
|---|---|---|---|---|---|
| `vf=40` | 2 Гц | 19 % | 11.4 В | 0.76 А |
| `vf=100` | 5 Гц | 25 % | 15.0 В | 1.00 А |
| `vf=200` | 10 Гц | 35 % | 21.0 В | 1.40 А |
| `vf=300` | 15 Гц | 45 % | 27.0 В | 1.79 А |

Разбор лога:

```bash
py -3 SESSION_2_VF2_VF3\TOOLS\vflog_step_report.py session.log --pp 3 --settle-ms 10000
```

Инструмент режет лог по `target`, выбрасывает первые 10 с каждой ступени (рампа),
печатает `f_e / fslip / vmag / rpm / i1 / i2 / vbus / commit=0 / drp` и вердикт на ступень.

**Аборт немедленно:** SD/EM_STOP активен (`sd1`/`sd2` = 0), `fault ≠ 0`, VBUS < 8 В,
stall-watchdog (2 с от старта при |rpm| < 5), любой шум/запах/перегрев.
**`commit=0` — НЕ критерий аборта** (~0.2 % тиков на переходах фаз). Непрерывный
`commit=0` = структурный отказ: смотреть `vmag` против потолка апертуры ~73 %.

**Докажет:** низковольтный прогон устойчив, энкодер даёт правдоподобные rpm, лог пригоден
для решения «нужен ли процентный slip / voltage compensation».
**Не докажет:** момент, нагрев, поведение под нагрузкой сверх того, что даст ступень.

## 4. Известные ограничения (важно для интерпретации)

1. **`fslip` в телеметрии — целые Гц** (`return p_hz + vfc_slip_int_mhz / 1000;`,
   `src/vf_control.c`): интегратор в мГц в лог не выходит. Различить «0…4 Гц» и «упёрся
   в ±5 Гц» — можно; измерить фактическое скольжение 0.3 Гц — нет.
2. **Мёртвая зона speed-PI ±49 rpm**: `p_hz = (328·error)>>16 = 0` при |error| ≤ 199 rpm,
   а инкремент интегратора `(1311·error)>>16 = 0` при |error| ≤ 49 rpm. Внутри ±49 rpm
   `f_slip` вообще не меняется. Для VF-3 это не блокер (значение просто держится).
3. **Рампа экспоненциальная** (tau = 2000 мс): ~63 % за 2 с, ~95 % к 6 с, полная к ~10 с.
   `f_e < f_cmd` в первые секунды — не неисправность.
4. **Потолок `vmag` ≈ 73 % шины** (контракт апертуры CCR 135…999): выше — селектор
   отвергает каждый тик, CCR удерживается (`commit=0` непрерывно).
