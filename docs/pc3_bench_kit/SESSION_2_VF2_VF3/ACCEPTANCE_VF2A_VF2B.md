# Гейт приёмки VF-2A / VF-2B: PASS только по конъюнкции

Ни один из пунктов по отдельности не даёт PASS. VF-2A/VF-2B считаются пройденными, только если
выполнены **все** условия ниже. Заполняется по факту, по логу и осциллограммам, без «на глаз».

## VF-2A (`vf=50`; f_e = 2.5 Гц при pp=3, vmag ≈ 20 %, duty фазы 40…60 %)

| # | Условие | Чем подтверждается | Отметка |
|---|---|---|---|
| A1 | команда принята, возбуждение разрешено | `vf=` вернул `rc=0` (не −3/−7/−8), в логе есть `@VFLOG` | |
| A2 | телеметрия формирует ожидаемый профиль | в `@VFLOG`: `vmag≈20`, `du/dv/dw` в 40…60 %, `fe≈2.5`, период огибающей duty ≈ 0.4 с | |
| A3 | **силовой тракт** даёт дифференциальное напряжение | осциллограф CH1−CH2 фазы U: ≈0 В при `du≈50 %`, −12 В при `du≈40 %`, +12 В при `du≈60 %` (VBUS 60 В) | |
| A4 | знак совпадает | знак CH1−CH2 совпадает со знаком `(du − 50 %)` | |
| A5 | защита и режим не нарушены | `fault=0`, `sd1=1`, `sd2=1`, stall-watchdog не сработал, `commit` не в непрерывном 0. **VBUS — только по осциллографу/БП либо по отсутствию VBUS-latch:** колонка `vbus` в `@VFLOG`/`@FOC` непригодна (в `@VFLOG` это сырые отсчёты инжектированного канала, загрязнённые переключениями; в `@FOC` — 0 когда кадр не получен) | |
| A6 | частота/фаза соответствуют осциллограмме | измеренный период огибающей = 1/f_e = 0.4 с (±10 %), сдвиг между `du/dv/dw` = 120° эл. | |

## VF-2B (`vf=40`; f_e = 2 Гц, vmag ≈ 19 %)

| # | Условие | Чем подтверждается | Отметка |
|---|---|---|---|
| B1 | то же, что A1 | `rc=0`, поток `@VFLOG` идёт | |
| B2 | `du/dv/dw` из лога = фактические duty | осциллограмма совпадает по форме и амплитуде огибающей (период 0.5 с) | |
| B3 | 120° между фазами | сдвиг между каналами/фазами измерен | |
| B4 | защита и режим не нарушены | `fault=0`, `sd1=sd2=1`, VBUS в окне, без stall | |

## Что означает частичный результат (диагностика, не вердикт)

| Наблюдение | Что это значит |
|---|---|
| A1/A2 выполнены, A3 — нет (на выходе нет дифференциала) | проблема в силовом тракте/дифференциальной схеме (TIM8-инверсия, EN/SD, мёртвое время), а не в V/f-математике |
| A3/A4 выполнены, A2 — нет | телеметрия/формат расходятся с железом: смотреть `du/dv/dw`, формат `@VFLOG`, бюджет строки |
| A2 верна, но частота на осциллографе не 1/f_e | расхождение шкалы n↔f: проверить `pp=3` и `vfk=15,50` |
| всё выполнено, но `commit=0` непрерывно | выход за контракт апертуры CCR (потолок ≈ 73 % шины) — фиксировать и остановиться |

## Обязательные части процедуры

* **`vf=0` в конце VF-3 — часть процедуры, не «по желанию»**: после него проверить, что PWM закрыт
  (`p?` / `pdump`: `MOE=0`, `CCER=0`, `CEN=0`), и только потом снимать питание.
* **`c`, `ch`, `iv` в эту сессию не добавлять.** `iv` — в первую очередь: его физическая семантика
  (что именно он измеряет на железе) пока не установлена, и его результат нельзя интерпретировать.
* VF-3 запускается **только** после конъюнктивного PASS по VF-2B.

## Что эта сессия не доказывает

VF-2A/2B — про дифференциальный тракт и соответствие телеметрии железу. VF-3 — baseline-характеризация
V/f. Карта токов, FOC, точность токовой шкалы и admission-гейты этим не утверждаются.
Решение «нужен ли отдельный CH-маршрут до появления карты» принимается **после** разбора этой сессии.
