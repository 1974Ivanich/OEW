# Test №2 — быстрая проверка перед запуском

Эта памятка предназначена для личного no-HV запуска. Она не заменяет осторожность оператора и не разрешает подачу DC-link.

## 1. DC-link и питание

1. Отключить обе силовые шины DC-link физически.
2. Измерить DMM каждую шину относительно согласованной точки измерения. Обе должны быть `<1 V`.
3. Убедиться, что на PC4/VBUS не подключены внешний источник, имитатор или лабораторное питание.
4. Подать только разрешённое низковольтное aux-питание.
5. Убедиться, что harness датчиков подключён штатно и оператор может немедленно снять aux-питание.

**Не продолжать**, если любая шина выше `<1 V`, состояние проводки неясно или есть внешний источник VBUS.

## 2. Прошивка

Использовать только default-deny production build `main`. Перед UART-проверкой выполнить flash и verify именно целевой платы. Не использовать Test №3 diagnostic/synthetic image.

## 3. Минимальная UART-проверка

Открыть фактический MCU VCP и отправить только:

```text
sysinfo
p?
pdump
c
a
```

Проверить:

- `sysinfo` отвечает от ожидаемой платы;
- `p?`/`pdump` показывают PWM disabled/default-deny и отсутствие активного MOE;
- `c` возвращает `offset_i1`, `offset_i2`, `offset_ires` без ошибки;
- `a` возвращает I1, I2, Ires и VBUS;
- VBUS остаётся в no-HV baseline, ориентир — raw `≤9`;
- нет rail/saturation-кодов, timeout или повреждённых ответов.

Для полного Test №2 команду `a` повторить ещё 9 раз, сохранив все ответы. Не очищать fault и не отправлять команды управления.

## 4. Немедленный STOP

Остановить проверку при активном/неоднозначном PWM, неожиданном reset/fault, неверной board identity, VBUS выше baseline, неполном UART, ADC saturation/rail, потере связи, запахе/нагреве или любом сомнении.

После STOP оставить DC-link отключённым. Не подавать DC-link, не запускать FOC/V/f/autotune, `mcarm`, `mapcap run` или Stage A.

## 5. Минимальный результат

Для личной работы достаточно устно или в заметке зафиксировать: `PASS`/`FAIL`, значения двух DMM, ответ `sysinfo`, состояние PWM, результат `c` и десять ответов `a`. Формальные G0/approval/archive-пакеты для личного Test №2 не нужны, если не требуется официальная приёмка проекта.
