## 1. Коэффициент OEW/звезда — четыре разных числа, а не одно

Речь об амплитуде основной гармоники фазного напряжения при одной DC-шине. Смешивать эти
четыре числа нельзя, поэтому они приводятся раздельно:

| Сравнение | Звезда | OEW | Коэф. |
|---|---|---|---|
| линейный режим, обе конфигурации с SVPWM | `V_DC/√3` = 23,09 В | `V_DC` = 40 В | **1,73** |
| шестиступенчатый (перемодуляция) | `2V_DC/π` = 25,46 В | `4V_DC/π` = 50,93 В | **2,00** |
| **текущий код**: звезда без инжекции, OEW с VM 0,90 | `V_DC/2` = 20,0 В | `0,90·V_DC` = 36,0 В | **1,80** |
| гипотетическая звезда с SVPWM против OEW с VM 0,90 | 23,09 В | 36,0 В | **1,56** |

Обоснование, которого не было в v1:

1. **`2·V_DC/√3 = 1,155·V_DC` — не линейный предел.** Это 90,7 % шестиступенчатого предела
   (`4·V_DC/π`), то есть точка внутри перемодуляции. В линейном режиме опорное напряжение каждой
   фазы обязано лежать в `[0,1]` по скважности, а напряжение обмотки есть разность плеч
   `u = V_DC·(d₁ − d₂)`, поэтому амплитуда основной гармоники ≤ `V_DC`.
2. **Инжекция нулевой последовательности в OEW сокращается.** Именно она даёт звезде выигрыш
   `V_DC/√3` вместо `V_DC/2`, но в разности мостов общая добавка каждого моста вычитается
   (`(u₁+z) − (u₂+z) = u₁ − u₂`). Поэтому OEW от инжекции не получает **ничего** — отсюда √3, а не 2.
   Другое дело разность `z₁ − z₂`: она управляет ZSC/CMV (см. §3), но αβ-амплитуду не поднимает.
3. **`1,80` — это коэффициент текущей прошивки.** `InvClarke_Transform` (`src/foc.c:73-79`) —
   чистый обратный Кларк без min-max/SVPWM-инжекции, значит звезда на этом коде получает только
   `V_DC/2`. `1,73` относилось бы к звезде, в которой инжекция реализована — это правка кода,
   а не свойство топологии.
4. Потолок VM — `FOC_VM_VMAX_Q15 = 29490` = 0,90 (`src/foc.c:212`), жёсткий клэмп модуляции —
   `FOC_MOD_MAX_Q15 = 32112` = 0,98 (`src/foc.c:238`), модель напряжения —
   `V_phase ≈ mod·Vbus`, `mod = vu·98/100` (`src/foc.c:1135,1140`).

## 2. Dead time в OEW: дифференциальная ошибка ровно вдвое

Для плеча `Δv = −(t_д/T_ш)·V_DC·sign(i_плеча)`. В OEW через обмотку идёт **один** ток, входящий
в один мост и выходящий из другого, то есть направления токов плеч противоположны:

```
Δu_обм = Δv₁ − Δv₂ = −k·sign(i) − k·sign(i) = −2k·sign(i),   k = (t_д/T_ш)·V_DC
```

`sign(i)` у обоих мостов меняется вместе, поэтому ошибки складываются **всегда**, а не «могут
сложиться или частично скомпенсироваться». Штатной компенсации в дифференциальной составляющей
не существует.

Числа при `V_DC` = 40 В, `t_д` = 1,5 мкс, `f_ш` = 5 кГц (`src/pwm.c:13,14`; `t_д = 1,5 мкс`,
`f_PWM = 5000`):

| Величина | Значение |
|---|---|
| `k` — ошибка одного моста | 0,300 В |
| дифференциальная ошибка обмотки OEW | **0,600 В** |
| нулевая последовательность `(2/3)·k` | 0,200 В |
| её 3-я гармоника `(4/π)·(2/3)·k` | **0,255 В** на `3·f_e` |
| её 9-я гармоника | 0,085 В |

Последние две строки — не украшение: сумма знаков трёх сбалансированных токов принимает только
значения ±1 (`period` = 120°), поэтому `Δu₀` — квадратная волна периода `T/3`, чья первая
(то есть 3-я по отношению к основной) гармоника равна `(4/π)·(2/3)·k`. Проверено численно.
Это и есть механизм из `OEW_BRANCH.md:71` («dead time дают 3-ю гармонику `i₀` даже без задания»),
теперь с предсказанным значением — гейт O3 должен показать именно ~0,26 В на `3·f_e`.

**Процедура G6 (заменяет «умножить прежнее значение на два»):**

1. измерить ошибку напряжения каждого моста отдельно, на обоих направлениях тока;
2. измерить результирующую ошибку напряжения обмотки;
3. ожидаемое отношение — **2:1** при равных `t_д` и общей шине;
4. отклонение от 2:1 — диагностический признак; это может быть разброс `t_д`, различие драйверов
   и задержек, различие коммутационных режимов или фактических токов, а не обязательно `t_д`.

## 3. Нулевая последовательность: ресурс ZSC/CMV/момента, не напряжения

Разность `z₁ − z₂` не увеличивает αβ-амплитуду, но создаёт путь `i₀` и тем самым реализует
третью гармонику момента (`1 + (E₃/E₁)²`) — при одновременном выполнении четырёх условий:
есть `E₃`/потокосцепление, есть замкнутый путь `i₀`, управляемы фаза и амплитуда `i₀`,
допустимы потери и напряжения обоих мостов. Формула остаётся модельной: для 3-выводной звезды
`E₃` вообще не наблюдаема (нейтраль недоступна), что и делает G9 предусловием.

## 4. Энергетика — сценарный расчёт, а не BM1109

> **Правка 20.11.2026 — ошибка атрибуции.** `R_LL` = 15 Ω взят из
> `docs/MOTOR_PARAM_BASELINE_20261014.md:66` (попарное) — это **другой мотор**; самого документа в
> рабочем каталоге уже нет. К BM1109 цифра не относится (`docs/BM1109_CONFIG_PASSPORT.md` §3.1).
> Таблица ниже сохранена как **сценарий с `R_ф` = 7,5 Ω**: она показывает механизм (выигрыш
> пропорционален меди), но числа в ней — **не энергетика BM1109** и в отчётах так называться не
> могут.

Сценарий: `R_LL` = 15 Ω (попарное), звезда → `R_ф` = 7,5 Ω, `I` = 2 А — амплитуда
(`I_rms` = 1,414 А):

| Величина | Значение |
|---|---|
| медь `3·I_rms²·R_ф` | **45 Вт** |
| добавка второго инвертора (оценка `V_CE`·Σ\|i\|, 2 прибора на путь) | **+6,7 Вт** |
| выигрыш от ZSC при `E₃/E₁` = 0,35 | 5,5 Вт → баланс **−1,2 Вт** |
| при `E₃/E₁` = 0,20 | 1,8 Вт → баланс **−4,9 Вт** |
| при `E₃/E₁` = 0,10 | 0,5 Вт → баланс **−6,2 Вт** |

Вывод для этого сценария (7,5 Ω): OEW-маршрут отрицателен даже при сильной третьей гармонике,
а при реалистичных `E₃/E₁` проигрывает в 4–13 раз. Оценка инвертора — ±30 %, её нельзя
«доказывать» даташитом; проверяется измерением.

**Что меняется после снятия атрибуции.** Для 48-вольтовой машины класса 600–1000 Вт ожидаемое
`R_ф` — 0,075–0,30 Ω (`BM1109_CONFIG_PASSPORT.md` §3.1): при той же амплитуде 2 А медь даёт
**0,45–1,8 Вт** вместо 45 Вт. Тогда:

- доступный выигрыш от ZSC при `E₃/E₁` = 0,35 — 12,25 % меди, т.е. **0,06–0,22 Вт** (ток здесь —
  амплитуда 2 А; при `I_rms` = 2 А, как в §К3 аудита v1, те же числа вдвое больше: 0,09–0,35 Вт);
- надбавка второго моста — 0,5–1,5 Вт как параметр (оценки по даташиту ключей пока нет), т.е.
  в 2–25 раз больше выигрыша; при оценке `V_CE·Σ|i|` ≈ 6,7 Вт — в 30–110 раз;
- значит **отрицательный вывод сохраняется и усиливается**, но по другой причине: не «выигрыш
  мал относительно меди», а «медь слишком мала относительно стоимости второго моста»;
- порог по `E₃/E₁` (`OEW_BRANCH.md` §7.3, `r₃` ≈ 0,4…>1) тоже нельзя пересчитывать от 7,5 Ω:
  единственный допустимый вход — **измеренное** `R_ф`.

**Процедура проверки (ΔP_DC):**

```
ΔP_DC = P_DC(OEW) − P_DC(звезда)   при одинаковых оборотах, нагрузке, температуре и токе
```

Границы применимости этой процедуры (важно, чтобы не выдать её за большее):

- «одинаковый ток» — это одинаковый **фундаментальный αβ-ток**; полный RMS отличается на `i₀`,
  и это надо указывать явно;
- разность включает не только инвертор и ZSC, но и изменение потерь в стали, роторе и добавочных:
  `ΔP_DC = ΔP_инверторы + ΔP_мотор`;
- поэтому опыт даёт полную энергетическую разницу режимов, а выделение «стоимости второго
  инвертора» требует подтверждения сопоставимости магнитного режима (контрольный прогон на двух
  токах в одной конфигурации даёт чувствительность).

## 5. G9: модель напряжения прошивки зависит от конфигурации

`mod = 2d−1` и `V_phase ≈ mod·Vbus` (`src/foc.c:1135,1140`, одинаковый CCR в `TIM1` и `TIM8`)
верны для **дифференциального** включения двух мостов. Для одного моста (3-выводная звезда):

```
V_phase = Vbus·(d − mean(d)) = mod·Vbus/2
```

то есть модель завышает приложенное напряжение **в 2 раза**. Это не «отображение» — от этого
зависят наблюдатель потока, оценка полосы G5, остаток dead time G6 и любой гейт по напряжению.
Поэтому G9 обязан подтверждать не только число выводов, но и то, какая из двух моделей действует.
