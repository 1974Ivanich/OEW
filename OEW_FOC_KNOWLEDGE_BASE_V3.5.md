## 1. Аппаратная платформа и топология

### 1.1. MCU и плата
- **STM32G474RE** (Cortex-M4F, 170 МГц, FPU, CORDIC);
- **Nucleo-G474RE** (ST-Link V4, SWD);
- Логический анализатор: Saleae Logic через sigrok-cli (fx2lafw, 8 каналов, до 8 МГц).

### 1.2. Силовая часть — OEW dual-inverter
- Два инвертора **STEVAL-IPM20B** (IGBT 3-phase, single DC-link shunt per inverter, max 10A);
- Общий DC-link;
- Двигатель с открытыми обмотками (Open-End Winding): каждая фаза подключена между двумя инверторами.

```text
DC-link
   │
Inv1 ─── winding U/V/W ─── Inv2
```

Это не стандартная трёхфазная машина со звездой без нейтрали. В OEW сумма фазных токов может быть ненулевой из-за гомополярной составляющей ($i_z \neq 0$).

### 1.3. Тип двигателя: Asynchronous Induction Machine (IM)
> ⚠️ **Подтверждено:** Проект работает с **асинхронной машиной**, а не PMSM/BLDC.

Последствия:
- Параметры модели: $R_s, L_{ls}, R_r', L_m, T_r = L_r'/R_r'$.
- Момент: $M = \frac{3}{2} p \frac{L_m}{L_r'} \psi_R i_{Sq}$.
- Управление требует оценки потока ротора $\hat{\psi}_R$ (через MRAS или интегрирование ЭДС).
- Насыщение магнитопровода влияет на $L_m$, что критично для autotune.

## 2. Критически важные исправления топологии измерений

### 2.1. I1/I2 — НЕ фазные токи (Commit `222860c`)

> ⚠️ **Установленный факт:** I1 и I2 — это **токи DC-link шунтов двух инверторов**, а не прямые измерения фазных токов двигателя.

Каждый канал видит суммарный ток возврата всех трёх фаз своего инвертора в конкретное коммутирующее состояние PWM. Поэтому:

- `I1 ≠ I2` в любой момент времени — нормально для OEW;
- соотношение меняется с вектором PWM — тоже нормально;
- ожидание `I1 ≈ 2·I2` или `sign(I1) = -sign(I2)` как проверки симметрии фаз — **некорректно**;
- реконструкция фазных токов обязательна и делается через `Current_Reconstruct()` с использованием карты апертур.

**Канал-правило для статических тестов:** использовать шунт НЕ модулирующего инвертора (он видит только возвратный ток, легче интерпретировать).

### 2.2. Ires — CT суммы фаз, не «третий фазный ток»

Ires измеряет сумму трёх фазных токов от Inv1. В звёздной схеме без нейтрали она была бы нулём. В OEW она показывает гомополярную составляющую `iz`, которая может быть ненулевой из-за:
- 3-й гармоники ЭДС;
- dead-time эффектов;
- несимметрии управления.

Использовать Ires как «третий вход Clarke» нельзя.

### 2.3. Старые комментарии adc.h устарели

В справочном `adc.h` могут оставаться комментарии типа «PA0 = I1 — фазный ток A». Игнорировать их. Актуальная топология подтверждена коммитом `222860c`.

## 3. Архитектура защиты и известные проблемы

### 3.1. Программная защита (`PROTECT_Check`)

Вызывается в ISR (`ADC1_2_IRQHandler`) **только при `FOC_IsRunning() == 1`**.

Следствие: во время любого силового импульса вне FOC (align-check `al`, autotune `ch`/`iv`/`oew`, open-loop ramp) программная защита **структурно слепа**. Единственные ограничители энергии:
1. Внешний current limit лабораторного источника;
2. Аппаратный break TIM1/TIM8 (SD/BKIN), если активен.

Пороги:
- `PROTECT_I_MAX_MA = 12000 мА` (программный предел тока);
- `AUTOTUNE_MAX_CURRENT_MA = 8000 мА` (предел внутри autotune-тестов).

Не смешивать эти величины при разборе логов.

### 3.2. Проблема TIM8 BIF / SD2 (Session 5, Commit `87169b3`)

> 🔴 **Установленный факт:** Все наблюдаемые остановки FOC/V/F связаны с аппаратным `FAULT_R=18` (BIF TIM8), вызванным кратковременным провалом SD2 (PD2).

Рабочая гипотеза цепочки событий:
```text
VBUS/regeneration 
    → кратковременный силовой пик в Inv2 
        → внутренний OCP STEVAL-IPM20B №2 
            → SD2 = LOW на наносекунды–микросекунды 
                → TIM8 BKIN latch → BIF = 1 
                    → MOE(TIM8) = 0 
                        → FOC_Stop()
                            → ΔJEOS = 1 или короткий burst + стоп
```

Подтверждения:
- Только TIM8 получает BIF (TIM1 чист);
- SD уже HIGH при программном опросе (импульс короче времени чтения);
- Малый ADC-ток (пик существует между двумя injected-измерениями);
- Воспроизводимость на ~60 В;
- Никакого аппаратного фильтра BKFLT в BDTR нет.

Решение принято: **полностью отказаться от использования TIM8 BKIN** для запуска FOC. Оставить PD2/SD2 только как диагностический GPIO (мониторинг состояния). Защита строится на жёстком внешнем лимите источника + программном контроле токов.

TIM1 BKIN не трогать автоматически (это второй независимый защитный канал).

## 4. Конфигурация PWM и таймеров

### 4.1. Production identity
- **PSC = 16**, **ARR = 999**;
- Timer clock = 170 МГц / (16+1) = **10 МГц**;
- Center-aligned mode 3 (**CMS = 3**);
- PWM frequency = 10 МГц / (2 × (999+1)) = **5 kHz**;
- Update event генерируется дважды за PWM-период (из-за CMS=3), но это не удваивает частоту PWM, только частоту триггеров JEOS.

### 4.2. Синхронизация TIM1 ↔ TIM8
Для дифференциального вектора OEW оба таймера должны иметь согласованные PSC/ARR/CMS. Проверять перед любым физическим прогоном.

### 4.3. Коммутационный вектор `al` (Align Check)
Статический вектор для проверки создания дифференциального напряжения:
```text
CCR_U = 470
CCR_V = 515
CCR_W = 515
ARR   = 999
```
Приблизительно: `U ≈ -6%`, `V ≈ +3%`, `W ≈ +3%`. Сумма мод = 0 (сбалансированный вектор).

Физика: благодаря разной полярности OCxM (TIM1 PWM1 vs TIM8 PWM2) одинаковые значения CCR создают противоположные направления напряжений на выходе каждого инвертора.

### 4.4. Коррекция Non-Idealities (Из A Vector Modulation Strategy & Warmuth)
Будущий переход к замкнутому контуру потребует учета падений напряжения на ключах ($V_{ce(sat)}$, $V_f$ диодов) и влияния Dead-Time. Для STEVAL-IPM20B это критично:
- IGBT имеют существенное падение (~2–3 В при номинальном токе);
- Dead-time 1.5 мкс при PWM 5 кГц составляет ~0.75% периода — достаточно для заметной ошибки реконструкции;
- Без этой коррекции карта апертур даёт систематический bias в Id/Iq.

**Практический вывод:** При переходе от ПК-3 к первому FOC необходимо добавить в `PWM_SetDuty1/2()` или в блок SVPWM поправку на эффективное напряжение, иначе PI-регулятор тока будет компенсировать ошибку модуляции вместо реального тока.

### 4.5. Стратегии контроля $i_z$ (Из IET 2012 Pre-print & EPSR 2018)
Выбор метода модуляции определяет компромисс между потерей напряжения, качеством тока и вычислительной сложностью:

| Метод | Контроль $i_z$ | Потеря напряжения | Пульсации момента | Сложность реализации | Бюджет ISR |
|---|---|---|---|---|---|
| **Conventional SVM** | Нет | 0% | Высокие | Минимальная | Низкий |
| **Z-SVM** | Да (жёсткий) | ~5% | Низкие | Средняя | Средний |
| **ZSHD** | Да (адаптивный) | <2% | Очень низкие | Высокая | Высокий |
| **SPWM + Zero Injection** | Да (адаптивная) | ~0–5%* | Низкие | **Низкая** | **Очень низкий** |

*\*Зависит от коэффициента инжекции.*

**Рекомендация по развитию:** Начинать с Conventional SVM или простого SPWM с инжекцией нуля. Если после первого FOC обнаружатся неприемлемые пульсации или перегрев одного IPM — следующий шаг Z-SVM. ZSHD рассматривать только при необходимости максимального использования напряжения DC-link.

### 4.6. Настройка PI-регуляторов с учётом задержки (Новое: Из HAL Diss §2.3 & Warmuth)

#### 4.6.1. Модель системы с задержкой
В реальном приводе всегда присутствует задержка $T_d$, включающая время обработки МК и время обновления ШИМ. Для нашей архитектуры (JEOS-driven control loop @ 5 kHz):
$$ T_d \approx 1.5 \times T_{samp} = 1.5 \times 200\mu s = 300\mu s $$
*(Примечание: автор диссертации использует 75 мкс для 20 кГц, т.е. $1.5/f_s$. Для нас $f_s=5$ кГц, значит $T_d=300$ мкс).*

Передаточная функция объекта регулирования становится:
$$ G(j\omega) = \frac{K_i e^{-j\omega T_d}}{R_s + j\omega L_{eq}} $$
где $L_{eq}$ — эквивалентная индуктивность оси ($\Sigma$ или $\delta$, аналог $d/q$ в нашем случае).

#### 4.6.2. Влияние задержки на устойчивость
Задержка вызывает быстрый спад фазы ($\arg(G)$) при приближении частоты к частоте дискретизации. Это накладывает **жёсткое ограничение сверху** на частоту среза $\omega_c$:
- Без задержки: $\omega_c$ может быть высоким (до сотен рад/с).
- С задержкой $T_d$: чтобы сохранить запас по фазе $\phi_\Delta = \pi/3$ (60°) и запас по усилению 10 дБ, $\omega_c$ должен быть существенно ниже.

Для диссертации (20 кГц): $\omega_c \le 6283$ рад/с (~1 кГц).
Для нашего стенда (5 кГц): Безопасная граница $\omega_c \approx \frac{\pi}{2 T_d} \approx 5235$ рад/с (~830 Гц). Однако, учитывая шум и неидеальности IPM, рекомендуется начинать с консервативного значения **$\omega_c \approx 2000-3000$ рад/с** (300-500 Гц).

#### 4.6.3. Алгоритм расчёта Kp и Ki (для `Autotune_CalcPI`)
Текущая реализация в `autotune.c` использует модульный оптимум (Антиучебник §3.4):
```c
// FOC_ComputePIGainsBW() в foc.c
// a = 1/(2·bw·Ts), clamp [1,100]
// kp = L_uH * 3276800000 / (2 * a * Ts_us * Vdc_mV)
// ki = kp * Ts_us * R_mOhm / (L_uH * 1000)
```
При `bw_hz=500` → `a=5`, при `bw_hz=1250` → `a=2` (default в `FOC_SetMotorParams`).

**Необходимая модификация (будущее):**
Ввести коэффициент коррекции задержки $k_{delay}$, зависящий от отношения $\omega_c T_d$:
$$ K_p^{real} = \frac{K_p^{ideal}}{|1 + j\omega_c T_d|} \quad \text{(упрощённо)} $$
Или использовать более точный метод последовательной коррекции (см. anti_2_20.pdf §3.5), где интегральная постоянная $T_i$ выбирается так, чтобы компенсировать полюс объекта, а пропорциональный коэффициент $K_p$ обеспечивает нужный запас устойчивости с учётом фазового сдвига от $e^{-j\omega_c T_d}$.

**Практическое правило для первого запуска:**
Использовать заниженные gains (например, 50% от рассчитанных по формуле выше) и постепенно увеличивать их, наблюдая за осциллограммой тока на предмет появления высокочастотных колебаний (признак потери запаса по фазе).

### 5.4. Интерпретация параметров `mp=` (Из anti_2_20.pdf & autotune.h)
Параметры двигателя в команде `mp=` не являются константами:
- **Rs_mOhm**: Сопротивление статора. Измеряется в `AT_MeasureRs_IV()`.
- **Ls_uH**: Индуктивность рассеяния статора ($L_{ls}$). Измеряется в `AT_MeasureLs_OEW()` через дифференциальный импульс обоих инверторов.
- **Rr_mOhm**: Приведенное сопротивление ротора. Измеряется в `AT_MeasureRr_rr()` через lock-in метод.
- **Lm_uH**: Индуктивность намагничивания. Измеряется в `AT_MeasureNoLoad()`. Зависит от насыщения!
- **Tr_rotor_us**: Постоянная времени ротора ($T_r = L_r'/R_r'$). Вычисляется как производная величина. Критична для контура намагничивания.
- **Ke_mV_per_rpm**: Коэффициент трансформации / ЭДС холостого хода.
- **pole_pairs**: Число пар полюсов. Определяется в `AT_DetectPairs()`.
- **J_kg_m2_x1e6**: Момент инерции.

**Предостережение:** Не следует слепо доверять одному набору параметров `mp=` для всего диапазона скоростей/моментов. Первый запуск FOC должен быть консервативным, чтобы избежать выхода в зону сильного насыщения или рассогласования временных constant.

## 6. Методология первых физических прогонов

### 6.1. ПК-3 (First Physical Align Test)
Цель: подтвердить создание OEW-вектора через независимые датчики ACS712-5A на фазах U/V/W.

Главный критерий PASS:
```text
sign(ΔU) противоположен sign(ΔV)
sign(ΔV) = sign(ΔW)
|ΔV| ≈ |ΔW|
нет runaway/fault
```
где ΔX = mean(CHx) - V0_x (средний уровень относительно нуля канала).

Запрещено использовать I1/I2 для PASS/FAIL. Отношение 2:1:1 — наблюдение, не критерий. UNDETERMINED — штатный исход при неразличимом сигнале, не FAIL.

Safety anchors:
- Максимальное удержание `al`: 15 секунд;
- Аварийный порог: устойчивый ток ≥ 2 А (≈370 мВ для ACS712-5A);
- Обязательный `al off` и post-check (MOE=0, токи вернулись к нулю, новый fault отсутствует).

**Интерпретация формы сигнала:** Согласно Sandulescu & Meinguet (2013), наличие 3-й гармоники ЭДС приводит к росту пикового фазного тока до **+31%** относительно основного компонента. При анализе осциллограмм ПК-3 нужно ожидать сигнал с заметными гармониками и пиками, превышающими расчетные средние значения. Эти пики сами по себе не являются неисправностью драйвера, пока структура знака среднего уровня корректна.

### 6.2. E2 Diagnostic Run (OPA Shunt Probe)
Отдельный прогон для объяснения поведения I1/I2. Подключение: CH1→выход ОУ I1, CH2→выход ОУ I2. Разделяет проблему на:
- A: аналоговый тракт различается → аппаратный уровень;
- B: аналог одинаков, ADC различается → firmware/ADC routing;
- C: отношение меняется с PWM → физика DC-link токов + aperture timing.

Не смешивать с ПК-3.

### 6.3. Record A (Physical Trigger Diagnosis)
Единственный следующий шаг перед любыми изменениями кода защиты.

**Цель:** Определить природу `FAULT_R=18` (TIM8 BIF).

**Подключение осциллографа (Single-shot):**
| Канал | Точка | Что фиксируем |
| :--- | :--- | --- |
| CH1 | PD2 (MCU input) | Уровень входа BKIN TIM8 |
| CH2 | SD2 (IPM output) | Сигнал Fault от STEVAL-2 |
| CH3 | VBUS | Напряжение шины |
| CH4 | Tok Inv2 (или ACS712) | Ток инвертора №2 |

**Триггер:** Falling edge SD2.

**Интерпретация:**
- **Сценарий 1 (Real OCP):** Пик тока > лимита IPM совпадает с падением SD2. BKIN работает штатно. Проблема в силовой части/уставках.
- **Сценарий 2 (Noise/Glitch):** Ток чистый, SD2 имеет короткие провалы. Проблема целостности сигнала (EMI, монтаж). BKIN оставляем, добавляем фильтр/debounce.
- **Сценарий 3 (Internal Error):** Ни SD2, ни PD2 не меняются, но BIF возникает. Баг конфигурации TIM8 или ISR.

**До получения результатов Record A запрещены любые изменения `src/pwm.c`, `src/protect.c`, `src/foc.c`.**

### 7.1. SANDULESCU.pdf (SOFRACI Project)
Диссертация описывает структуру SOFRACI: 6 плеч (три фазы × два инвертора), питающие трёхфазную машину с открытыми обмотками. Это наша топология.

Ключевые выводы для нас:

### 7.2. Performance_Analysis_Dual-Inverter-Fed.pdf (Zerdani et al., Symmetry 2024)
Статья посвящена анализу производительности Dual-Inverter Fed Open-End Winding Induction Machine Drive с акцентом на **Asymmetric Space Vector PWM (ASVPWM)**.

Ключевые выводы для нас:
- **Расширение линейного диапазона:** ASVPWM позволяет эффективнее использовать напряжение общего DC-link двух инверторов, снижая риск преждевременного насыщения по напряжению. Для нашего стенда с ограниченным VBUS это потенциально даёт больший ток/момент без повышения напряжения шины.
- **Управление нулевым током ($i_z$):** Асимметричная модуляция позволяет целенаправленно управлять гомополярной составляющей, балансируя потери между Inv1 и Inv2 или минимизируя пульсации момента.
- **Чувствительность реконструкции:** В двойном инверторе ошибка калибровки параметров машины ($R_s$, $L_s$) влияет на реконструкцию фазных токов сильнее, чем в обычной схеме, так как ошибка накапливается через два независимых контура регулирования напряжения. Это подтверждает необходимость точного этапа `mp=` / autotune перед первым замкнутым FOC.
- **Спектральный анализ:** При интерпретации данных E2 (OPA shunt probe) полезно смотреть не только на знак среднего уровня, но и на спектральный состав PWM-ripple. Высокий уровень 3-й гармоники или побочных частот может указывать на проблемы с картой апертур или синхронизацией TIM1/TIM8.

**Ограничения применения:** Статья рассматривает асинхронную машину (IM), тогда как наш проект ориентирован на PMSM/BLDC. Уравнения ротора и потока отличаются. Использовать идеи модуляции и реконструкции можно, но формулы Id/Iq напрямую переносить нельзя. Также сложные математические аппараты декомпозиции векторов избыточны для текущего MVP; начинать следует с базовой симметричной SVM + возможно простое смещение нуля (zero-sequence injection).

### 7.3. L2EP_VPPC_2019_VU.pdf (Vu et al., IEEE VPPC 2019)
Конференц-доклад группы L2EP (Laboratoire d'Électrotechnique et d'Électronique de Puissance de Lille), представляющий аппаратную реализацию платформы SOFRACI и методы управления гомополярными токами в OEW.

Ключевые выводы для нас:
- **Подтверждение топологии:** Явное описание структуры "Two inverters feeding one machine with independent windings". Подтверждает, что проблема нулевого тока ($i_z \neq 0$) является фундаментальной особенностью OEW, а не артефактом нашей прошивки.
- **Методы реконструкции токов:** Обсуждение способов восстановления фазных токов из шинных токов с использованием информации о состоянии ключей (switching states). Это теоретическое обоснование необходимости нашей карты апертур (`CurrentMap_SelectNextContext`). Мы не просто берем сырые значения ADC, мы должны знать, *какой вектор* был активен в момент выборки, чтобы правильно перевести $I_{DC1}/I_{DC2}$ в $i_u/i_v/i_w$.
- **Влияние dead-time и падений напряжения:** Анализ показывает, что ошибки реконструкции усиливаются из-за non-idealities switches. Для нас это означает, что при настройке `Current_Reconstruct()` необходимо учитывать влияние DTG (dead-time) на длительность валидных окон выборки.
- **Стратегии подавления $i_z$:** Предложены алгоритмы инжекции нуля последовательности напряжения для контроля гомополярной составляющей. Хотя сейчас мы не внедряем сложные схемы, понимание того, что $i_z$ можно активно управлять, снимает страх перед его наличием. Если после ПК-3 выяснится, что $i_z$ велик и вызывает перегрузки одного из IPM (например, SD2), у нас будет готовый путь решения через модификацию SVPWM, а не только через замену железа.
- **Экспериментальные данные по насыщению:** Показано, как 3-я и 5-я гармоники влияют на пульсации момента и тепла. Помогает интерпретировать шум на осциллографах ACS712. Если мы видим высокочастотные пульсации сверх PWM, это может быть связано с резонансами контура тока или гармониками машины, а не с багами прошивки.

### 7.4. L2EP_SPEEEDAM_2022_RIBIERE.pdf (Ribiére et al., SPEE 2022)
Доклад по проектированию электрических машин для гибридных/электрических приводов. Полезен для понимания тепловой нагрузки и критериев эффективности.

Ключевые выводы для нас:
- **Критерий качества момента:** $k_m = T_{em} / \sqrt{P_{Cu}}$. Показывает способность машины производить момент при минимальных потерях в меди. Для OEW важно следить за балансом потерь между Inv1 и Inv2, особенно если есть значительная гомополярная составляющая $i_z$.
- **Разделение потерь:** Автор разделяет потери на роторные ($P_{rot}$: магниты + железо ротора) и статорные ($P_{stat}$: медь + железо статора). Для нашего стенда с STEVAL-IPM20B (ограниченный радиатор) основной риск перегрева связан с $P_{stat}$ в обмотках и ключах IPM. Это обосновывает жесткие временные лимиты (15 с для `al`) и контроль тока.
- **Контекст применения:** Фокус на EV/heavy-duty подтверждает актуальность топологии Dual-Inverter OEW для мощных применений, где требуется высокая надёжность и гибкое управление напряжением/током. Наша платформа является уменьшенным прототипом таких систем.

**Полезность для текущего этапа:** Не содержит алгоритмов управления FOC или специфики STM32, но дает физическое обоснование лимитов тока/времени и понимание причин деградации характеристик при работе в режиме насыщения или высокой гомополярной составляющей.

### 7.5. L2EP_IECON_2020_VU.pdf (Vu et al., IEEE IECON 2020)
Конференц-доклад группы L2EP, фокусирующийся на **стратегиях активного управления гомополярной составляющей ($i_z$) для минимизации потерь и пульсаций момента** в многофазных OEW приводах (на примере 5-фазной машины, принципы применимы к 3-фазной OEW).

Ключевые выводы для нас:
- **Стратегии управления $i_z$:** Статья подробно разбирает различные стратегии инжекции нулевой последовательности напряжения ($u_0$ или $\Delta u_h$):
    *   **Минимизация потерь в меди:** Выбор такой компоненты $u_0$, которая минимизирует сумму квадратов фазных токов при заданном моменте. Это напрямую связано с критерием $k_m = T_{em} / \sqrt{P_{Cu}}$ из Ribiére et al.
    *   **Балансировка нагрузки между инверторами:** В OEW с двумя инверторами один может быть перегружен больше другого. Управление $i_z$ позволяет перераспределять ток так, чтобы оба IPM работали в более равномерном режиме. Для нас это потенциальное решение проблемы SD2/OCP Inv2, если она вызвана несимметрией нагрузки, а не ringing.
    *   **Снижение пульсаций момента:** Использование третьей гармоники ЭДС (если она есть в нашем моторе) через управление $i_z$ может компенсировать пульсации момента от других гармоник.
- **Модель машины в координатах Park/Clarke + Homopolar:** Авторы используют расширенную модель, где вектор напряжения раскладывается на три ортогональные плоскости:
    1.  Плоскость $\alpha-\beta$ (основная, создает момент);
    2.  Плоскость $x-y$ (обычно игнорируется в 3-фазных машинах без нейтрали, но в OEW важна);
    3.  Плоскость $h$ (гомополярная, создает нулевой ток $i_z$).
    
    Для нас это подтверждает теоретическую базу нашей карты апертур и `Current_Reconstruct()`: мы должны контролировать не только $I_\alpha/I_\beta$, но и понимать влияние на $i_z$. Если наша прошивка сейчас просто подавляет $i_z$ до нуля (или игнорирует его), эта статья показывает, как его *активно использовать*.
- **Экспериментальные результаты по эффективности:** Сравнение разных стратегий модуляции (SVM, DPWM, ASVPWM) с точки зрения КПД и качества тока. Полезный вывод: простая симметричная SVM не всегда оптимальна для OEW. Асимметричные методы могут дать выигрыш в использовании напряжения DC-link и снижении потерь ключей.

**Ограничения применения:**
1.  **Сложные оптимизационные задачи.** Авторы решают задачу минимизации потерь численно или аналитически с учетом ограничений. Для STM32G474 в реальном времени это избыточно сложно на этапе первого запуска.
2.  **Фокус на многофазных машинах (5-phase).** Хотя принципы похожи, у нас 3-фазная OEW. Некоторые формулы декомпозиции отличаются размерностями матриц Парка/Кларка.

**Полезность для текущего этапа:**
| Тема | Полезность | Комментарий |
| --- | --- | --- |
| Управление $i_z$ | ⭐⭐⭐⭐ | Ключ к балансу Inv1/Inv2 и снижению потерь. Потенциальное решение проблемы SD2, если причина — перегрузка. |
| Модель машины | ⭐⭐⭐⭐⭐ | Подтверждает необходимость учета трех плоскостей ($\alpha\beta, xy, h$) в реконструкции и управлении. |
| Стратегии модуляции | ⭐⭐⭐ | Ориентир для будущего улучшения КПД и снижения пульсаций. Не критично для первого пуска. |
| Экспериментальные данные | ⭐⭐⭐ | Помогает калибровать ожидания по качеству тока и тепловым режимам. |

### 7.6. L2Ep_2013_Sandulescu_meinguet_Power_electronics_fw_open_end_winding.pdf (Sandulescu & Meinguet, IEEE Trans. Power Electron., 2013)
**Название:** *Control Strategies for Three-Phase Open-End Winding Drives Operating in Flux Weakening Region.*

Это ключевой теоретический источник, фокусирующийся на конкретной проблеме: **как управлять OEW-приводом в режиме ослабления поля (flux-weakening), когда ток нейтрали ($i_0$ или $i_z$) становится критическим ограничением.**

Ключевые выводы для нас:
- **Проблема напряжения при контроле $i_z$:** Стандартные методы модуляции (например, Z-SVM — Zero-sequence SVM) позволяют увеличить диапазон линейного напряжения за счет инжекции нулевой последовательности. Однако есть цена:
    *   При активном контроле $i_z \approx 0$ максимальное напряжение в плоскости $\alpha-\beta$ снижается примерно на **5%** по сравнению с идеальным случаем без ограничений по току нейтрали.
    *   Для нас это важно, потому что STEVAL-IPM20B имеет ограничение по напряжению шины. Если мы хотим выжать максимум момента на высоких скоростях, нам придется жертвовать либо качеством тока нейтрали (риск перегрева обмоток/IGBT), либо диапазоном скорости.
- **Сравнение стратегий:**
    1.  **Conventional Modulation:** Игнорирует $i_z$. Риск больших пульсаций тока и нагрева. (Наш текущий этап).
    2.  **Z-SVM (Zero-sequence SVM):** Активно подавляет $i_z$, но теряет ~5% напряжения.
    3.  **Proposed Strategy (ZSHD - Zero Sequence Harmonic Detection):** Использует детектор гармоник нулевой последовательности для более точного контроля $V_{dq,max}$ в зависимости от частоты вращения $\omega_e$.
- **Влияние 3-й гармоники ЭДС на пиковый ток:** Наличие 3-й гармоники в反-ЭДС приводит к росту пикового фазного тока до **+31%** относительно основного компонента. Это объясняет возможные "выбросы" на ACS712 и риски срабатывания OCP IPM, даже если средний ток мал.
- **Архитектура регулятора $i_z$:** Предложена схема с отдельным PI-регулятором нулевой последовательности и адаптивным ограничением вектора напряжения ($V_{dq,max} = f(\omega_e, V_0)$). Это прямое руководство к действию, если мы решим внедрять активный контроль $i_z$ в прошивку STM32G474 позже.

**Рекомендация по развитию:** Начинать с базовой SVM (игнорирование $i_z$) для первого запуска. Переход к Z-SVM или ZSHD рассматривать только при необходимости расширения диапазона скоростей или решения проблем с тепловым балансом Inv1/Inv2.

### 7.7. AVectorModulationStrategyNoFormat.pdf (*A Vector Modulation Strategy for Open-End Winding Drives*)
Практическая реализация стратегии пространственного вектора для OEW с акцентом на декомпозицию напряжения между двумя инверторами и учёт non-idealities силовых ключей.

Ключевые выводы для нас:
1. **Декомпозиция вектора:** Описан детерминированный метод распределения $V_{ref}$ между Inv1 и Inv2 с контролем $i_z$, альтернативный чистой Z-SVM. Может быть реализован на нашем MCU.
2. **Коррекция на $V_{sat}$/dead-time:** Эффективное напряжение на обмотке отличается от идеального $d \cdot V_{bus}$ из-за падений на IGBT/диодах и мёртвого времени. Без поправки карта апертур и PI-регуляторы работают с систематической ошибкой.
3. **Бюджет времени:** Алгоритм рассчитан на выполнение в реальном времени within one PWM period — совместимо с нашей архитектурой JEOS-driven control loop.

**Ограничения применения:** Не содержит специфики DC-link shunt reconstruction, аппаратной защиты IPM или калибровки аналоговых трактов. Использовать как донора алгоритма модуляции после подтверждения базовой физической работоспособности тракта (ПК-3 PASS).

### 7.8. anti_2_20.pdf (Учебник по электроприводу)
Фундаментальный учебник по электроприводу (курс лекций/методичка школы Эйхенвальда/Доливо-Добровольского). Содержит базовую теорию векторного управления асинхронными двигателями (АД).

Ключевые выводы для нас:
- **Математическая модель АД:** Подробный вывод уравнений равновесия статора и ротора в координатах $\alpha\beta$ и $dq$. Источник истины для формул в `foc.c` и `autotune.c`. Момент $M = \frac{3}{2} P Z K_{tr} \psi_R i_{Sq}$.
- **Влияние насыщения магнитопровода:** Индуктивность намагничивания $L_m$ постоянна только при малых токах. При пуске или высоких нагрузках происходит насыщение. Объясняет, почему autotune может давать разные результаты при разных уровнях напряжения/тока.

- **Структура подчиненного регулирования:** Разбор каскадов: Контур тока (внутренний) → Контур скорости → Контур положения. Подтверждает правильность архитектуры ISR: JEOS (ADC) вызывает обновление токовых уставок, которые затем формируют напряжения через SVPWM. Задержки в этом каскаде критичны для стабильности.

**Ограничения применения:**
1.  **Специфика СПМ/PMSM:** Большая часть текста про АД. У нас, скорее всего, BLDC/PMSM. Формулы момента и ЭДС отличаются ($E = k_e \omega$ vs $E = j \omega \psi_f$). Использовать его формулы для расчета Ke нельзя.
2.  **Старые методы реализации:** Текст написан в эпоху аналоговых регуляторов или ранних DSP. Наши алгоритмы цифровые, дискретные, с учетом dead-time и quantization effects.

### 7.9. 2012_IET_in_press_Flux-weakening_operation_of_open-end_winding_drive.pdf (Pre-print Sandulescu & Meinguet)
Ранняя версия статьи IEEE TPEL 2013. Содержит расширенную блок-схему ZSHD, детальное описание детектора гармоник 3-го порядка ($\phi_{1,3}, \phi_3$) и сравнительную таблицу трёх стратегий модуляции (Conventional / Z-SVM / ZSHD) с количественными оценками потерь напряжения и сложности. Final IEEE TPEL версия сокращена; полная информация доступна только здесь.

Ключевые дополнения к §7.6:
- **Границы flux weakening:** Более явное описание ограничения $V_{dq}$ при наличии контроля $i_z$. Без контроля: $V_{max} = V_{bus}/\sqrt{3}$. С контролем $i_z \approx 0$: $V_{max} \approx 0.95 \cdot V_{bus}/\sqrt{3}$ (~5% потеря).
- **Детализация ZSHD:** Блок-схема включает фазовый детектор огибающих ($\phi_{1,3}, \phi_3$) и вычисление угла нулевой последовательности через `atan2`. Это подтверждает, что даже при идеально синусоидальной модуляции наличие 3-й гармоники ЭДС создаёт пульсирующую нулевую компоненту, требующую активной компенсации.
- **Практическая ценность:** Выбор между Z-SVM (~5% потеря, средняя сложность) и ZSHD (<2% потеря, высокая сложность) при переходе от базового FOC к оптимизированному управлению $i_z$.

### 7.10. 1-s2.0-S0378779618304218-main.pdf (EPSR 2018)
**Название:** *Neutral current control in open-end winding drives using sinusoidal pulse-width modulation (SPWM).*

Статья предлагает использование классической синусоидальной ШИМ с инжекцией нулевой последовательности для управления током нейтрали $i_z$ в OEW, избегая сложной декомпозиции пространства векторов SVM.

Ключевые выводы для нас:
- **SPWM как альтернатива SVM:** Классическая синусоидальная ШИМ с инжекцией нуля может обеспечить контроль $i_z$ без сложных операций секторной декомпозиции.
- **Аналитические формулы для инжекции нуля:** Приведены явные выражения для расчёта компоненты $V_0$, минимизирующей $i_z$:
  $$V_0 = -\frac{1}{3}(V_a + V_b + V_c)_{desired}$$
  Для STM32G474 это требует лишь трёх сложений и деления на 3 — значительно проще, чем полная декомпозиция секторов SVM или детектор гармоник ZSHD. Бюджет времени ISR будет выполнен с большим запасом.
- **Сравнение методов по потерям ключей:** SPWM имеет фиксированную частоту переключения каждого плеча; SVM оптимизирует порядок коммутации. Но в OEW с двумя инверторами преимущество SVM частично теряется из-за необходимости согласования двух независимых мостов. Для STEVAL-IPM20B при 5 кГц и малых токах разница несущественна.
- **Компенсация 3-й гармоники:** Статья подтверждает findings Sandulescu & Meinguet (2013): наличие 3-й гармоники ЭДС создаёт пульсирующий $i_z$. Однако авторы показывают, что SPWM с адаптивной инжекцией нуля может компенсировать эту гармонику лучше, чем жёсткий Z-SVM, благодаря естественной подстройке под instantaneous values фазных напряжений.

**Ограничения применения:**
1.  Предполагает полные датчики тока на фазах (не применимо напрямую к нашей dual-shunt topology без модификации реконструкции).
2.  Не рассматривает flux weakening или dead-time compensation явно.

**Полезность для текущего этапа:**
| Аспект | Полезность | Комментарий |
|---|---|---|
| SPWM как альтернатива SVM | ⭐⭐⭐⭐ | Упрощает реализацию первого FOC. Подходит для бюджета времени ISR STM32G474. |
| Формулы инжекции нуля | ⭐⭐⭐⭐⭐ | Явные выражения для $V_0$, готовые к имплементации в float math. |
| Сравнение потерь ключей | ⭐⭐⭐ | Подтверждает, что для наших условий (5 кГц, <2 А) простота важнее эффективности. |
| Компенсация 3-й гармоники | ⭐⭐⭐⭐ | Адаптивная инжекция нуля в SPWM может быть эффективнее жёсткого Z-SVM. |

### 7.11. Диссертация по Dual Three-Phase Machines (HAL ID: hal-03628531)
**Название:** *Multiport Energy Routers and Dual Three-Phase Machines.* (Автор неизвестен, HAL archive).

Хотя статья фокусируется на PMSG (синхронных генераторах) и энергорутерах, её разделы по моделированию и декомпозиции векторов содержат полезные концепты для нашей OEW IM.

Ключевые выводы для нас:
- **VSD vs Σδ Transformation:**
    *   **VSD (Vector Space Decomposition):** Декомпозирует 6-мерный вектор на три ортогональные плоскости: $\alpha-\beta$ (fundamental), $z_1-z_2$ (5th harmonic), $0_1-0_2$ (homopolar/zero sequence). Широко используется в мультифазных машинах.
    *   **Σδ Frame:** Прямое расширение Clarke transformation. Разделяет вклад двух наборов обмоток на "сумму" ($\Sigma$) и "разницу" ($\delta$). Более удобна для балансировки мощности между инверторами, так как ось $\delta$ напрямую регулирует разницу токов между наборами.
    *   **Для нас:** Матрицы VSD/Σδ **не применимы напрямую** к OEW (так как у нас одна обмотка, а не две независимые группы). Однако принцип разделения на "полезный момент" ($\alpha-\beta$) и "нулевую последовательность" ($i_z$) остаётся верным. Управление $i_z$ через инжекцию нуля (как в EPSR 2018) является практической реализацией этой идеи для OEW.
- **Aliasing Effects in Current Sampling (§2.2.3):**
    *   Статья подробно анализирует, как момент выборки тока относительно PWM-периода приводит к появлению алиасированных гармоник. Это напрямую касается нашей проблемы с `Current_Reconstruct()` из DC-link шунтов (I1/I2). Если мы выберем неправильное окно (aperture), шум переключения или гармоники ЭДС «маскируются» под низкочастотные составляющие тока, что может выглядеть как нестабильность контура или ложные пики.
    *   **Действие:** Изучить рисунки 2.7, 2.9, 2.10 и Приложение C (Fig C.2) для настройки карты апертур в прошивке.
- **PI Controller Design with System Delay (§2.3.2):**
    *   Показывает, как системная задержка (ISR latency + PWM update) влияет на устойчивость контура тока. Для нашего STM32G474 с бюджетом ISR ~200 мкс это критично.
    *   **Действие:** Учитывать задержку при расчете PI gains (`pi=N`) после успешного прохождения ПК-3.
    *   **Новое знание (детализация):** Задержка $T_d \approx 1.5/f_s$ ограничивает частоту среза $\omega_c$. Для обеспечения запаса устойчивости 60° и усиления 10 дБ необходимо снизить $\omega_c$ по сравнению с идеальным случаем. Резонанс функции чувствительности к возмущениям $S_G$ неизбежен на высокоскоростных осях (аналог $\delta$ или $q$-ось в нашем случае), что приводит к усилению вторых гармоник тока при определённых рабочих частотах. Это объясняет возможную нестабильность при быстром изменении нагрузки или скорости.

**Ограничения применения:**
1.  Фокус на PMSG (синхронные генераторы), а не IM (асинхронные двигатели).
2.  Режимы DAB (Dual Active Bridge) и Power-Sharing at Zero Speed не применимы к нашему случаю запуска двигателя.
3.  H∞ Controllers (§2.4) избыточны для текущего MVP.

### 7.12. Warmuth et al. (KAI GmbH): Novel Control Methodologies of Back-to-Back B6 Bridges
**Название:** *Novel Control Methodologies of Back-to-Back B6 Bridges for an Application-Related Stress Test Setup.*

Статья описывает управление топологией Back-to-Back (B2B), структурно идентичной нашей OEW Dual-Inverter схеме. Цель — воспроизведение сложных форм тока для стресс-тестирования.

Ключевые выводы для нас:
- **Four-Quadrant Switching vs Diagonal Full-Bridge:**
    *   Диагональное переключение (Full-Bridge) вызывает высокие пульсации тока, так как ток постоянно растёт или падает под действием напряжения шины.
    *   Four-Quadrant подход разрешает состояния циркуляции (оба верхних ключа выключены, оба нижних включены, или наоборот), где энергия хранится в индуктивности нагрузки. Это **значительно снижает пульсации тока**.
    *   **Для нас:** В OEW аналогом является грамотное использование нулевых векторов (Zero Vectors) и контроль $i_z$. Стратегии модуляции, эффективно использующие состояния циркуляции (Z-SVM, SPWM Zero Injection), дадут лучшее качество тока, чем грубая симметричная SVM.
- **Analytical Dead-Time Compensation:**
    *   Представлена точная формула (Eq. 8) для расчета времени включения $t_{on}$ с учетом направления тока и его производной. В B2B цепи ошибка dead-time удваивается, так как участвуют два последовательно соединенных моста.
    *   **Для нас:** Необходимо внедрить упрощенную версию (линейная аппроксимация) в блок SVPWM после подтверждения базовой работоспособности тракта. Учитывать удвоение ошибки dead-time в цепи Inv1 + Inv2.
- **Open-Loop Precalculation for E2:**
    *   Метод feed-forward расчета duty cycles для воспроизведения эталонного тока является мощным диагностическим инструментом. Позволяет разделить проблемы силовой части/модели параметров от проблем алгоритма обратной связи (PI/Reconstruction).
    *   **Для нас:** Рекомендуемый следующий шаг после ПК-3 PASS: выполнить серию static tests с pre-calculated CCR и сравнить с измерениями ACS712. Если Open-Loop дает чистый сигнал, а Closed-Loop FOC — шумный, проблема точно в алгоритме регулирования или реконструкции.

### 7.13. tmp-7145-000019_version_finale.pdf (Shi et al.): Method for Quantifying Availability
**Название:** *Method for Quantifying Availability of Electrical Machines under Fault Conditions.*

Документ предлагает формальный метод количественной оценки доступности ($\alpha$) электрических машин при отказе.

Ключевые выводы для нас:
- **Определение Доступности ($\alpha$):**
    $$ \alpha = \frac{T_{fault}}{T_{nominal}} $$
    *   $\alpha = 1$: Норма.
    *   $\alpha = 0$: Полный отказ.
    *   $0 < \alpha < 1$: Деградированный режим.
- **Сравнение топологий при обрыве фазы:**
    *   Звезда без нейтрали: $\alpha = 0\%$ (ограничение Кирхгофа делает невозможным создание кругового поля только двумя фазами).
    *   Звезда с нейтралью: $\alpha \approx 50\%$ (можно создать эллиптическое поле).
    *   **Open-Winding (OEW):** $\alpha > 50\%$ (до 100%). Отсутствие соединения нейтралей позволяет независимо управлять каждой фазой через два инвертора. Нет жесткого ограничения Кирхгофа на сумму токов статора.
- **Применение к проекту:**
    *   Подтверждает архитектурное преимущество нашей Dual-Inverter OEW схемы. Если диагностика Record A выявит необратимый дефект одного IPM, система может быть переведена в деградированный режим управления, используя методы контроля $i_z$ (см. §7.5–7.6 KB), чтобы сохранить движение с пониженным моментом, а не останавливаться полностью.
    *   Эта статья валидирует выбор топологии и задает вектор развития для Phase 2 (Research & Development). Она превращает нашу платформу из "стенда для проверки FOC" в "исследовательский полигон для методов отказоустойчивого электропривода".

### 7.14. 0103-epe2025-full-05045297.pdf (EPE 2025): Enhanced Model Predictive Current Control
**Название:** *Enhanced Model Predictive Current Control with Virtual Voltage Vectors for Two-Level VSI.*

Статья описывает применение FCS-MPC с виртуальными векторами для снижения THD тока в стандартных трехфазных инверторах.

Ключевые выводы для нас:
- **Неприменимость к текущему этапу:**
    *   Метод конфликтует с архитектурой FOC+SVPWM, требует ресурсов DSP, недоступных на Cortex-M4F в рамках текущего бюджета ISR, и игнорирует специфику реконструкции токов в OEW dual-inverter topology.
    *   MPC каждый такт предсказывает будущее состояние тока для всех возможных состояний ключей. Для STM32G474 при 5 кГц это съест весь свободный процессорное время.
- **Урок:** Подтверждает, что улучшение качества тока возможно без повышения частоты ШИМ, но ценой высокой вычислительной сложности, которая недопустима на этапе стабилизации базового контура управления АД.
- **Перспектива:** Концепция **Pre-selection of vectors** (предварительный отбор кандидатов по сектору) может быть полезной в будущем, если мы решим перейти к более продвинутым методам (Direct Torque Control или simplified MPC). Но это уровень "Research & Development Phase 2".

## 8. Текущий статус и следующие шаги

### 8.1. Зафиксированные решения
- TIM8 BKIN убран из цепочки защиты (оставлен как мониторинг);
- Внешний current limit источника является первичным ограничителем энергии;
- Прошивка `87169b3` (или новее) содержит BKF-фильтр (для обработки ложных событий, не предотвращения установки BIF) и рампу тока;
- Frozen scan protocol (`FOC_SCAN_48CELL_PROTOCOL.md`) остаётся историческим артефактом; текущий путь — короткие физические прогоны ПК-3/E2;
- Тип машины подтвержден: **Induction Machine (IM)**;
- Код `autotune.c` и `adc.c` уже соответствует модели IM (параметры Rs, Ls, Rr, Lm, Tr).

### 8.2. Ближайшие действия
1.  **Record A:** Диагностика природы TIM8 BIF (осциллографирование SD2/PD2/VBUS/Tok). **Без изменений кода.**
2.  **ПК-3:** Выполнить first physical align test по замороженной инструкции v2.2/v2.3;
3.  Получить сырые данные ACS712 (осциллограмма + логи);
4.  Если PASS → переход к параметрам двигателя (`pp=3`, `mp=` или autotune route B) и минимальному FOC startup;
5.  Если UNDETERMINED → повтор с более глубоким усреднением или шагом VBUS внутри коридора;
6.  Если FAIL/STOP → разбор конкретного симптома, без возврата к большой квалификации.

### 8.3. Стратегия развития после первого запуска
Если после ПК-3 выяснится, что вектор создается верно, но токи шумят или нестабильны, следующим шагом будет внедрение элементов **асимметричной модуляции (управление $V_{z}$)** согласно подходам Zerdani et al. и Vu et al. (VPPC 2019, IECON 2020), вместо попытки «починить» симметричную схему.

Если же проблема окажется в несимметрии нагрузки между Inv1 и Inv2 (например, перегрузка Inv2, провоцирующая SD2), следующим шагом будет внедрение простой стратегии инжекции $u_0$ для балансировки, согласно подходам Vu et al. (IECON 2020), а не замена железа.

Если потребуется расширение диапазона скоростей (flux weakening), рассматривать переход от Conventional SVM к Z-SVM или ZSHD согласно Sandulescu & Meinguet (2013/IET 2012), учитывая компромисс между потерей ~5% напряжения и контролем $i_z$.

Для реализации базового контура тока рассмотреть алгоритм декомпозиции векторов и коррекцию non-idealities ключей согласно *A Vector Modulation Strategy for Open-End Winding Drives*, адаптировав его под бюджет времени ISR STM32G474.

**Новая рекомендация (EPSR 2018 & HAL Diss & Warmuth):** Если после ПК-3 и первого FOC окажется, что SVM слишком сложен для надёжной работы с нашей картой апертур и DC-link shunts, переход к **SPWM с инжекцией нуля** станет следующим логичным шагом упрощения, сохраняющим контроль $i_z$. Аналитические формулы для $V_0$ требуют минимальных вычислений, что идеально подходит для бюджета времени ISR STM32G474. Также рекомендуется изучить разделы по Aliasing Effects и PI Design with Delay из диссертации HAL для тонкой настройки ISR. Используйте метод Open-Loop Precalculation (Warmuth) для диагностики E2.

**Важно помнить:** Параметры двигателя (`mp=`) не являются константами; они зависят от рабочей точки (насыщение, температура). Первый запуск FOC должен быть консервативным, чтобы избежать выхода в зону сильного насыщения или рассогласования временных constant.

### 8.4. Что НЕ делать сейчас
- Не менять firmware/map/geometry до получения физического ответа (Record A);
- Не запускать новые qualification campaigns;
- Не калибровать I1/I2 коэффициентами под ACS712;
- Не возвращаться к 48-cell scan как основному инструменту;
- Не добавлять новые administrative gates;
- Не усложнять алгоритм модуляции до подтверждения базовой работоспособности тракта;
- Не внедрять VSD/Σδ матрицы напрямую (они для Dual Three-Phase, а не OEW);
- Не внедрять MPC (EPE 2025) — вычислительно невозможно на текущем железе.
