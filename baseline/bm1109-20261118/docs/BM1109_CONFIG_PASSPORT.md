# BM1109 — паспорт фактической конфигурации (гейты G8 и G9)

Статус: **шаблон, заполняется по факту**. Подготовлено: 18.11.2026.
Этот паспорт — артефакт гейта **G8** (идентичность конфигурации) и одновременно носитель
факта для гейта **G9** (число силовых выводов и схема соединения); нумерация гейтов — по
`docs/BM1109_LOSS_OPTIMAL_CONTROL.md`.
Назначение: однозначно установить, какие ограничения относятся к BM1109, а какие относятся к
стенду, на котором велась разработка (топология этого стенда без G9 не утверждается).
До заполнения ограничения стенда (частота ISR, число каналов тока, карта апертур, dead time)
**не приписываются** BM1109.

Правило: значение без источника (файл, документ, измерение, commit/образ) — недействительно
и записывается как `не подтверждено`, а не «по паспорту двигателя».

## 2. Четыре факта, которые решают вопрос о применимости ограничений

1. **Число силовых выводов обмотки (3 или 6).** Три вывода — только одиночный инвертор.
   OEW (два инвертора: `TIM1` + `TIM8`, `EN_1`/`EN_2` в `main.c`) требует доступа к обоим
   концам каждой обмотки. `motor_params.md` §1 предполагает 3 силовых вывода, но поле
   **не измерено**. Если выводов 3 — OEW-часть программы к этому мотору не относится.
2. **Схема обмоток.** От неё зависят `1ᵀi = 0`, смысл линейных ЭДС и вид целевой функции.
   До подтверждения оптимизационная модель не выбирается.
3. **Число каналов тока.** Два канала (i1/i2) — это двухшунтовая реконструкция с картой
   апертур. Одношунтовая конфигурация даёт другие ограничения на синтез несинусоидального
   профиля. Требует подтверждения по схеме платы, а не по телеметрии.
4. **Образ прошивки.** Ограничение «вектор модуляции в поясе r ≈ 8192 (амплитуда ≈ 0,25,
   покрытие ≈ 2,5 %)» — свойство гейта карты в конкретном образе, а не мотора. Без sha256
   и commit нельзя сказать, действует ли оно на данном стенде.

## 3. Порядок заполнения

1. Шильдик и маркировка мотора — текстом (не фото).
2. Вскрытая крышка: схема соединения, распиновка Холлов, маркировка платы.
3. Сверка платы с BOM: шунты, усилители, делитель шины.
4. Фиксация образа: ветка, commit, sha256, дата CI-рана.
5. Осциллограмма мёртвого времени на затворах (фактическое t_д против расчётного).
6. Только после п. 1–5 — заполнение `motor_params.md` (R, L, Ke, p, фазировка).
