# OEW-ветка: топология, нулевая последовательность, литература

Статус: **справочная ветка, не относится к BM1109** до подтверждения электрической топологии
самого двигателя (гейт G9 в `docs/BM1109_LOSS_OPTIMAL_CONTROL.md`).
Подготовлено: 18.11.2026.

Назначение: держать отдельно всё, что относится к двухинверторным (open-end winding)
системам, чтобы эти материалы не смешивались с исследованием BM1109 (ветка BLDC/PMSM,
одиночный инвертор).

---

## 0. Границы: что доказано, а что нет

| Утверждение | Статус | Источник |
|---|---|---|
| Плата рассчитана на два инвертора: `TIM1` + `TIM8`, по три комплементарных канала, две линии разрешения `EN_1`/`EN_2` | **доказано** | `main.c`: `TIM8_Init`, `TIMPWM`, тест фазы U включает ключ `TIM1` и нижние ключи `TIM8` |
| Плата **может** работать в конфигурации OEW | следствие, требует схемы подключения | — |
| BM1109 имеет **6** силовых выводов | **не доказано** | `motor_params.md` §1 предполагает 3, поле не измерено |
| Целевая архитектура проекта — OEW именно для BM1109 | **не установлено** | — |
| Математика §1 применима к BM1109 | **только после G9** | — |

**Логическая ошибка, которую нельзя повторять:** «на плате два инвертора ⇒ BM1109 является
OEW-машиной». Два инвертора могут управлять другой машиной, другой конфигурацией, либо
существовать как второй вариант стенда. Топология платы и топология мотора — независимые
факты, и связывать их можно только после проверки цепочки
**мотор → соединение обмоток → силовые выводы → плата → конфигурация PWM → измерение токов**.

---

## 1. Что меняется в математике (для OEW как топологии)

В OEW оба конца каждой обмотки подключены к инверторам, поэтому ограничение `1ᵀi = 0`
**отсутствует**: существует физический контур нулевой последовательности через общую шину.

Идеальная граница по меди — проекция на **полный** вектор ЭДС, а не на `e⊥`:

**i\* = P·e/‖e‖²,  L_min = R·P²/‖e‖²**

Третья (и кратные трём) гармоника ЭДС перестаёт быть «мёртвой»: с током `i₀` она даёт момент
(«zero-sequence torque»). Отношение к той же машине в звезде, где `i₀ = 0` вынужденно:

**L_star/L_OEW = 1 + (E₃/E₁)²**   (синусоида + 3-я гармоника)

| E₃/E₁ | Выигрыш по потерям | По RMS-току |
|---|---|---|
| 0,05 | 0,25 % | 0,12 % |
| 0,20 | 4 % | 2 % |
| 0,35 | 12 % | 6 % |

## 2. Условия формулы (обязательны; без них это не «коэффициент преимущества OEW»)

1. три одинаковые фазные обмотки;
2. равные фазные сопротивления;
3. физически допустимый путь для тока нулевой последовательности;
4. синфазный ток не блокируется схемой питания и управления;
5. нет активных ограничений по напряжению и току;
6. оптимизируются только потери в меди при равной электромагнитной мощности;
7. гармоники ортогональны на рассматриваемом периоде.

Нарушение п. 5 меняет задачу: у границы по напряжению выигрыш приходит из другого механизма
(освобождение запаса по `i_d`) и по величине не совпадает с `1 + (E₃/E₁)²`.

## 3. Реализуемость `i₀` — отдельный гейт, а не следствие формулы

Возможность **создать** `i₀` не означает способности **удерживать** нужную его форму:

- контур нулевой последовательности имеет малую `L₀` → пульсации от синфазного напряжения
  прямо превращаются в добавочные потери;
- нужно проверить напряжения **обоих** мостов и допустимое синфазное напряжение (CMV);
- ток переключения и dead time дают 3-ю гармонику `i₀` даже без задания.

Отсюда правило: ZSC и CMV оптимизируются **только совместно** (вывод обзора Zerdani), а
формула §1 остаётся **идеальной оценкой**, не гарантией выигрыша конкретной машины.

## 5. Приоритеты внутри ветки

Порядок величины коммутационных потерь при 24–48 В, ~2 А, 5–10 кГц:
`0,5·U·I·(t_r+t_f)·f ≈ 0,05 Вт` на ключ, т.е. **единицы десятых ватта на мост** (уточнить по
даташиту ключей). Медные потери при тех же токах и Rs ≈ 13–15 Ω — десятки ватт.

Гейты ветки (выполняются по порядку, до любого алгоритма):

| № | Гейт | Критерий |
|---|---|---|
| O1 | Топология мотора | G9 (BM1109-документ) выполнен и дал **6** силовых выводов; схема соединения зафиксирована. При 3 выводах ветка закрывается |
| O2 | Конфигурация шины | общая шина или плавающий конденсатор — установлено по схеме, не по литературе |
| O3 | Контур ZSC | измерены `L₀`, `R₀`; измерен фактический `i₀` от dead time и CMV |
| O4 | CMV | допустимый уровень CMV задан (изоляция, подшипники, ЭМС) |
| O5 | Алгоритмы | только после O1–O4; число переключений — последним |

## 6. Что нельзя переносить на BM1109

- вывод «два инвертора ⇒ OEW-мотор» (§0);
- формулу §1 без условий §2 и без гейта §3;
- проценты из литературы: все они получены на других машинах, других мощностях и против
  других баз сравнения;
- приоритет «оптимизация PWM — высокий»: для нашего класса мощности это доли процента.
