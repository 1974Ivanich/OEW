# BM1109 — потенциал снижения потерь в меди (исправленный разбор)

Статус: **аналитическая часть зафиксирована, измерения не начаты**. Документ заменяет
устный разбор от 18.11.2026 и содержит исправления двух ошибок того разбора (см. §2.3 и §10).
Подготовлено: 18.11.2026.

Назначение: определить, есть ли у конкретного BM1109 **измеримый** потенциал снижения потерь
в меди относительно синусоидального FOC при одинаковых скорости и полезном моменте, и при
каких условиях этот потенциал вообще может быть измерен.

Связанные документы: `motor_params.md` (карточка B1.2), `NO8_FOC_MAPVEC_SPEC.md`,
`NO8_BENCH_RUN_PROTOCOL.md`, `docs/BM1109_CONFIG_PASSPORT.md` (гейты G8 и G9), `docs/OEW_BRANCH.md` (OEW — отдельная ветка).

## 1. Что именно оптимизируется

### 1.1 Формулировка

При равных сопротивлениях фаз, линейной машине (нет насыщения, нет реактивного момента) и
отсутствии ограничений по току и напряжению минимум суммы квадратов фазных токов при
заданной мгновенной мощности:

**i\*(θ) = P·e⊥(θ) / ‖e⊥(θ)‖²,  P = T_ref·ω_m,  e⊥ = e − ((e_a+e_b+e_c)/3)·1**

Свойства (использовать как справочные):

| Величина | Выражение |
|---|---|
| Минимальные потери в меди при данной мощности | L_min = R·P²/‖e⊥‖² |
| Норма тока | ‖i\*‖ = \|P\|/‖e⊥‖ |
| Момент на ампер (размерно корректно) | T/‖i‖ = ‖e⊥‖/ω_m = p·‖dλ/dθ_e‖ |
| Профиль в единицах «ЭДС на единицу скорости» | i\*(θ) = T_ref·ê⊥/(p·‖ê⊥‖²), ê = dλ/dθ_e |

Форма через `ê` предпочтительна: скорость сокращается, таблица не зависит от оборотов,
`p` выходит явно.

### 1.2 Что формула НЕ решает

1. **Сингулярность.** При ‖e⊥‖→0 требуемый ток стремится к бесконечности. Формула — только
   незамкнутая проекция. Реальная задача:

   min Σi_k²  при  eᵀi = P,  1ᵀi = 0,  |i_k| ≤ I_max,  v ∈ V_adm(θ)

   При активном ограничении тока решение **не** является масштабированной проекцией e⊥.
2. **Ограничение по напряжению** — не статическое `|v_k| ≤ V_dc/√3`, а ограничение на
   траектории: `v = Ri + L·di/dt + e`. Допустимое множество в αβ — шестиугольник SVPWM
   (вписанный круг V_dc/√3, вершина V_dc/√2); требование к `di/dt` само становится
   ограничением и на высоких гармониках — определяющим.
3. **Полные потери ≠ потери в меди.** Функционал: R·Σi_k² + V_f·Σ\|i_k\| + потери в стали +
   коммутационные. Минимизация Σi² и Σ\|i\| дают разные оптимумы (второе — «разреженное»).
   Для BM1109 (Rs ≈ 13–15 Ω, I ≈ 2 А) инверторная часть — единицы процентов от меди, поэтому
   Σi² как прокси допустима, но это надо подтвердить числом, а не принять молча.
4. **Допущения, требующие проверки:** равные R; неявнополюсность (§6, гейт G3); схема
   соединения — звезда (§6, гейт G1); ЭДС при рабочей температуре и рабочем токе.

### 1.3 Нулевая последовательность — зависит от топологии

**Одиночный инвертор, звезда с изолированной нейтралью:** `1ᵀi = 0` выполняется всегда,
поэтому `eᵀi = e⊥ᵀi`, и 3-я с кратными гармоники ЭДС момента не дают. Удаление нулевой
последовательности здесь — не выбор оптимизатора, а физика. Практическое следствие: таблицу
можно строить по линейным ЭДС, не имея доступа к нейтрали. Для треугольника это неверно
(§6, G1).

**OEW (два инвертора, общая шина — если такая топология выбрана для конкретной машины): `1ᵀi = 0` НЕ выполняется.** Существует контур нулевой
последовательности через общую шину, `i₀ ≠ 0` возможен, и третья гармоника ЭДС даёт момент
(«zero-sequence torque»). Тогда ограничение `1ᵀi = 0` из задачи уходит, и оптимумом
становится проекция на **полный** вектор ЭДС, а не на `e⊥` (см. `docs/OEW_BRANCH.md`). Поэтому выводы
§1.1–§1.2 действуют только в оговорённой топологии и не переносятся на OEW автоматически.

## 2. Определение формы ЭДС для всех числовых результатов

### 2.1 Форма (обязательна к указанию при любом числе)

Фазная ЭДС — кусочно-линейная трапеция с полкой `F = 120°`, нулевыми площадками
`Z = 60° − 2R` и рампами шириной `R` (всего `2F + 4R + 2Z = 360°`). Амплитуда полки `E = 1`.
Три фазы сдвинуты на 120°, мгновенная нулевая последовательность удалена.
`R = 0` — идеальная трапеция (вертикальные фронты), `R = 30°` — сильно скруглённая.

Сравниваемые алгоритмы при **одинаковом среднем моменте**:

| Обозначение | Алгоритм |
|---|---|
| `L_optc` | оптимум при **постоянном мгновенном** моменте (без пульсаций) |
| `L_opta` | оптимум при заданном **среднем** моменте (пульсации допускаются) |
| `L_6st` | 6-step: две фазы с наибольшим \|e\|, знак по знаку ЭДС; угол коммутации оптимальный |
| `L_sin` | синусоидальный FOC: только основная гармоника, оптимальный угол сдвига |

Потери нормированы на `R·P²`; проверки схемы: для синусоидальной ЭДС `L_optc/L_opta = 1,0000`
и `L_opt = 2/3`; для идеальной трапеции `L_opt = L_6st = 0,5000`.

### 2.1.1 Условия сравнения (обязательны наравне с формой)

Число из §2.2–§3 действительно только при одновременном выполнении:

1. **равный средний момент** у всех алгоритмов (`eᵀi` усреднён по периоду);
2. **одинаковые определения угла**: все углы электрические, начало отсчёта — один и тот же
   переход ЭДС через ноль; пересчёт «об/мин ↔ эл. рад/с» с явным `p`;
3. **одинаковая нормировка токов**: фазные токи, действующие значения, звезда (для
   треугольника нормировка иная);
4. **одинаковое ограничение по току** (в идеальной границе — неактивное);
5. **заданная форма ЭДС на всём периоде**, включая фронты; допущение о равенстве
   сопротивлений фаз указано явно.

Поэтому 4,72 % / 9,66 % — **результат для рассмотренной формы и принятого сравнения**, а не
универсальная верхняя граница для «любой трапеции».

### 2.2 Замкнутые выражения для идеальной трапеции (R = 0)

Амплитуда основной гармоники трапеции 120°/60°:

**A₁ = 2√3/π = 1,10266·E**  (не `3/π` — это только синусный коэффициент)

| Величина | Формула | Значение |
|---|---|---|
| T/‖i‖, оптимум | √2 | 1,41421 |
| T/‖i‖, синусоидальный FOC | √1,5·A₁ | 1,35047 |
| Отношение (улучшение по току) | √2/(√1,5·A₁) | **1,04720** |
| Отношение потерь | (√2/(√1,5·A₁))² | **1,0966** |

### 2.3 Errata: откуда взялись ошибочные 21 % / 46 %

В первом разборе амплитуда основной гармоники была взята равной `3/π = 0,955` вместо
`2√3/π = 1,1027`. Ошибка в `(2/√3)² = 4/3` дала `1,46` по потерям и `21 %` по току.
**Корректные значения: 9,66 % потерь, 4,72 % по RMS-току.** Ошибка была в пользу
оптимизма и меняет оценку перспектив работы (§0, §9).

## 3. Полный электрический период: 6-step как точка сравнения

Точное интегрирование по всему периоду, включая коммутационные участки.

| R, ° | L_optc | L_opta | L_6st | L_sin | 6-step хуже оптимума | sine хуже оптимума (RMS-ток) |
|---|---|---|---|---|---|---|
| 0 | 0,5000 | 0,5000 | **0,5000** | 0,5483 | 0,0 % | +4,72 % |
| 5 | 0,4922 | 0,4909 | 0,5000 | 0,5230 | 1,9 % | +3,22 % |
| 10 | 0,4845 | 0,4821 | 0,5000 | 0,5019 | 3,7 % | +2,03 % |
| 20 | 0,4690 | 0,4655 | 0,5000 | 0,4705 | 7,4 % | +0,53 % |
| 30 | 0,4534 | 0,4500 | 0,5000 | 0,4510 | **11,1 %** | +0,11 % |

Выводы, обязательные к учёту:

1. **Тождество «оптимум = 6-step» верно только для кусочно-постоянной ЭДС** (R = 0), где
   ‖e⊥‖² = 2E² постоянно и третья фаза всегда несёт нулевой ток. На переходных участках
   ‖e⊥‖² меняется, ток получает третью ненулевую компоненту, и профиль перестаёт быть
   прямоугольным. Как «математический эталон на всём периоде» 6-step **не** используется.
2. **С ростом рампы 6-step проигрывает, а синусоидальный FOC — выигрывает.** При R = 30°
   6-step хуже синуса на 10,9 % потерь (5,3 % по RMS-току). Для реального мотора 6-step —
   не эталон, а один из трёх сравниваемых алгоритмов.
3. **Требование постоянного мгновенного момента почти бесплатно:** `L_optc/L_opta` =
   1,000–1,008 (0,3–0,8 %). Поэтому можно требовать нулевые пульсации, не платя потерями,
   и не ставить задачу «средний момент с допуском на пульсации».
4. Ширина рампы — сильнейший фактор результата. Все числа без указания формы ЭДС
   недействительны (§2.1).

## 4. Спектральная оценка: где работает, где нет

Первый порядок:

**L_opt/L_FOC ≈ 1 / (1 + Σ_{n≥2} (e_n/e₁)²)**  (n ≠ 3k)

Проверка по таблице §3: ошибка 1,4 % при R = 0 и 0,2–0,3 % при R = 10…30°. Это хорошая
**screening**-оценка, но она: (а) описывает оптимум по среднему моменту, а не по постоянному;
(б) требует ортогональности гармоник и не учитывает полосу контура, задержки и dead time.

**Основной метод прогноза — прямое численное интегрирование трёх измеренных сигналов**
(приложение), с их взаимным фазовым положением и с свёрткой на измеренную АЧХ контура.
Спектральная формула используется только для быстрой предварительной оценки и для отбраковки
заведомо бесперспективных вариантов.

| синусоида (THD → 0) | 0 % (метод = FOC) |

## 7. Рабочая точка: предварительно ~100 об/мин

Предварительный критерий воспроизводимости гармоники порядка n: `n·f_e ≤ f_c/3`,
`f_e = p·N/60`. При f_c = 330 Гц (5 кГц ISR, оценка G5):

**N_max ≈ 952 / p, об/мин**

| p | 4 | 6 | 7 | 8 | 11 | 12 |
|---|---|---|---|---|---|---|
| N_max, об/мин | 238 | 159 | 136 | 119 | 87 | 79 |

То есть весь измеримый эффект живёт около **100 об/мин** — там же, где базлайн протокола №8
(`rpm=100`). Ограничение признаётся заранее: при таких оборотах механическая мощность мала,
и точность оснастки (трение, датчик момента, пульсации нагрузки) начинает доминировать.

Это **предварительный** предел: он получен из оценки f_c ≈ f_s/15, а не из измерения.
Окончательная рабочая точка определяется по измеренной АЧХ замкнутого контура (G5);
повышение f_pwm/ISR сдвигает границу пропорционально.

## 8. Критерий go/no-go (формализованный)

Порог не назначается заранее — он следует из измерительной системы.

1. Измерить три линейные ЭДС на 3–5 скоростях (равномерный привод).
2. Восстановить электрический угол, выполнить спектральный анализ (амплитуды 5, 7, 11, 13 с
   учётом последовательностей).
3. Точный численный расчёт нижней границы потерь по измеренной форме (§3, §4).
4. Прогноз: `ΔP_ideal` = L_sin − L_opt при равных скорости и моменте.
5. Коэффициент реализуемости: `k_bw` = |W_closed(j·n·ω_e)| из измеренной АЧХ контура (G5)
   для целевых гармоник.
6. `ΔP_pred = ΔP_ideal · k_bw`.

**Парные сравнения (обязательная процедура вместо двух независимых наборов):**

1. Вывести двигатель на заданные обороты и нагрузку.
2. Зафиксировать тепловое состояние (тепловое равновесие, одинаковая T обмотки).
3. Серия измерений первым алгоритмом.
4. Переключить алгоритм, **не меняя** рабочую точку.
5. Повторить серию.
6. Менять порядок алгоритмов между сериями (A-B, B-A), чтобы исключить систематический
   температурный дрейф и дрейф нуля датчиков.
7. Для каждого сравнения считать **среднее разность** DC-мощности и её доверительный
   интервал по парным разностям; `σ_ΔP` берётся из этих разностей, а не из абсолютного
   разброса мощности.

Дополнительно по сопротивлению: `R_T` приводится к температуре обмотки **в момент самого
измерения**, а не к конечной. После остановки двигатель остывает, поэтому задержка между
остановкой и измерением `R` стандартизируется (фиксированное время, фиксированный ток
измерения) и записывается в протокол прогона.

**Решение:**

| Условие | Исход |
|---|---|
| `ΔP_pred ≥ 2·σ_ΔP` и все гейты G1–G8 закрыты | этап 3 имеет смысл |
| `ΔP_pred ≥ 2·σ_ΔP`, но полоса мала (`k_bw ≪ 1`) | сначала f_pwm/ISR, затем этап 3 |
| `ΔP_pred < 2·σ_ΔP` | **отрицательный результат фиксируется как результат**: «для данного BM1109 табличное профилирование не даёт измеримого выигрыша, Σ(e_n/e₁)² = …» |
| гейт не закрыт | этап 3 не начинается (результат не интерпретируется) |

Метрика сравнения: фиксированные обороты + неизменная механическая нагрузка → **разность
входной мощности DC-шины**. Датчик момента нужен для контроля неизменности нагрузки и
абсолютного КПД, но не как решающая метрика.

### 8.1 Исследовательская гипотеза BM1109 (формулировка для проекта)

**Гипотеза.** Табличное профилирование фазных токов по измеренной ЭДС может снизить потери в
меди относительно синусоидального FOC при одинаковых скорости и механическом моменте.

**Условия проверки (все обязательны):**

- подтверждённая схема соединения обмоток (G1);
- измеренная трёхфазная ЭДС (три линейные, одновременно, на 3–5 скоростях);
- проверенная зависимость индуктивности от положения ротора (G3);
- откалиброванный электрический угол (G4);
- измеренная полоса токового контура (G5);
- учтённые ограничения по напряжению и току (§1.2).

**Критерий перехода к реализации.** Прогнозируемый эффект должен превышать экспериментальную
неопределённость (§8, шаги 1–7). При недостаточном эффекте работа прекращается на этапе
оценки потенциала — без разработки неоправданно сложного алгоритма.

Величина ожидаемого выигрыша **не фиксируется** в требованиях: она определяется по измеренному
спектру BM1109 и подтверждается численным расчётом.

## 10. Открытые вопросы и непринятые допущения

1. **Конфигурация не сшита** (G8, G9). В частности: карта апертур 6×2 относится к стенду
   конкретной конфигурации, и называть этот стенд «OEW-стендом» без G9 нельзя;
   `motor_params.md` указывает лишь, что данные BM1109 нужны для проекта OEW-PMSM — это **не**
   доказательство ни числа выводов, ни топологии мотора. Ни один документ не связывает образ
   прошивки с конкретным экземпляром. До появления схемы ограничения стенда
   (5 кГц ISR, двухшунтовая реконструкция, dead time) не считаются относящимися к BM1109.
2. Errata первого разбора: утверждение «один шунт» **неверно** — в протоколе №8 калибруются
   два канала тока (`offset_i1`, `offset_i2`), телеметрия ведёт `I1=/I2=`, реконструкция
   двухшунтовая (6 секторов × 2 окна). Реальное ограничение — гейт карты, сузивший вектор
   модуляции до пояса r ≈ 8192 (амплитуда ≈ 0,25, покрытие ≈ 2,5 %), т.е. артефакт
   квалификационной кампании, а не физика измерения.
3. Не подтверждено: звезда/треугольник (G1), `p` (G2), неявнополюсность (G3), полоса (G5),
   остаток dead time (G6).
4. Не решено: как строится таблица ЭДС при рабочем токе (насыщение) и рабочей температуре
   (Ke магнитов ≈ −0,11 %/K); таблица «на холостом ходу» даст систематическую ошибку и в
   задании момента, и в feedforward.

## Приложение. Воспроизведение расчёта §2–§3

Вход: функция формы ЭДС `prof(θ)` с параметрами `F = 120°`, `Z = 60° − 2R`, `R ∈ [0, 30°]`,
три фазы со сдвигом 120°, мгновенное удаление нулевой последовательности.

```
для N = 7200 равномерных θ на периоде:
  e  = [prof(θ), prof(θ−120°), prof(θ−240°)] − mean
  E2 = Σ e²                       # ‖e⊥‖²
  L_optc  = P²·mean(1/E2)         # постоянный мгновенный момент
  L_opta  = P²/mean(E2)           # средний момент
  q6      = mean(Σ e_k·sign_k)    # две фазы с max|e|, знак по знаку ЭДС
  L_6st   = 2·(P/q6)²
  A1      = |mean(Σ e_k·e^{−j(θ−120k)})|
  L_sin   = 1,5·(P/A1)²
```

Проверки: синусоидальная ЭДС → `L_optc = L_opta = 2/3`, отношение 1,0000;
`R = 0` → `L_opt = L_6st = 0,5000`, `A₁ = 2√3/π = 1,10266`.
Расчёт выполнен на чистом Python без зависимостей; в репозиторий скрипт не добавлен.
